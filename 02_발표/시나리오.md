# 문제의식
- 어항 내 관상어의 폐사 사유는 배설물, 어류 스트레스 뿐아니라 그와 관련된 국소적 용존산소의 부족일 수도 있다

## 지금까지의 연구:
1. 양식장의 유속장과 그에따른 용존산소의 부족을 정량적으로 측정
2. 어항내 관상어의 폐사 사유분석 또는 건강상태 체크


# 우리의 프로젝트가 다른점:
- 현재까지는 없었던 용존산소의 구배를 관상어의 건강도/생존률(폐사율)과 연관지을 수 있다는 가능성을 제시

## 우리 프로젝트의 결과물:
- 용존산소의 구배를 실제로 측정하지 않고 알 수 있는 축소모델(ROM)구축
    - 기하인식
    - 축소모델
- 수온/탁도 센서 제작
- 각 요인을 종합적으로 분석하는 멀티모달 AI환경 구축

# 각 결과물 별 학술적 토의(전공 연계)
## 1. 국소적 용존산소의 부족을 실제로 측정하지 않고도 알 수 있는 방법(ROM)
### 논문 작성 범위
-우리 아이디어가 새로운 것임을 학계에 보고.

    1. 어항 내의 지배방정식 설계
        1. 유동장 (URANSE 비정상 레이놀즈 평균 나비에 스토크스 방정식)
        2. DO (UADE 비정상 이송 확산 방정식)
        3. BC 모든 어항에 적용되는 폭기(1Ω), 어항 벽/바닥면, free-surface만 적용
    2. 수치해석 기반 계산 방식(CFD)
        1. 격자 해석 — 3격자(84/96/108) 비단조 → GCI 대신 최대편차를 이산화 불확실도 상한으로 (W 4.81 % · 3-D K_La 7.22 %)
        2. 8core 병렬 pimpleFoam 비정상 해석
        3. 프로브 시계열의 시간평균 정착 확인 후 시간평균 (fieldAverage timeStart = 40 s)
        4. 폭기 위치 16개에 대한 모든 유속장 확보
    3. 용존산소장 확보
        1. CFD의 비정상 상태 시간평균(준정상결과)
        2. DO방정식에 대입하여 수치해석 -> 스칼라 공간장 생성
    4. 실측 어항 실험
        1. 폭기 위치 16개에대해서 용존산소 실측(공간 구배를 충분히 확보할 수 있는 수준)
        2. 방정식 기반 해석과 정량비교 후 오차분석

### 논문 제외 범위
-논문에 담기에는 기반이 부족.

    1. 논문이 시사하는 바: 방정식 기반 해석과 실측이 얼마나 차이가 나는지 분석
    2. 기하인식
        1. 사진 기반 기하인식
            1. 입력: 사진 두장(3D분석에서 1장은 무리)
            2. 출력: ROM에 사용할 경계조건(폭기 위치, 물고기 수(어체적), 구조물(바위, 수생식물))
                - 모든 어항에 적용되지 않는 경계조건 파악

        2. 축소모델
            1. 논문 작성 범위인 방정식 기반 해석과 실측 간의 보정치를 그대로 이용
                - 필수 BC는 모두 적용했기때문에, 추가 경계조건에 해당하는 내용만 추가

            2. CFD로 수 많은 경우의 데이터셋 생성 후 기계학습
            3. 실측 1개와 정량비교 후 추가보정

## 2. 수온/탁도 센서
    1. ROM에 사용할 경계조건에 수온 기반 조건이 존재.
    2. 탁도는 어류 건강도에 직결
    3. 센서는 수온과 탁도센서를 결합
        1. 데이터를 주기적으로 전송하는 프로토타입 필요.
        2. 구성요소
            1. 베터리
            2. wifi/bluetooth 등 무선 모델
            3. 아날로그-디지털 변환
            4. 수온,탁도
## 3. 멀티모달 AI환경
    1. do구배, 수온, 탁도를 종합 분석하는 AI
    2. 어류의 행동, 상황별 건강도에대한 논문/연구자료의 대규모 데이터셋 필요
    3. 관상어 사육에 있어서 사용자에게 유용한 정보 제공
        - 급이 시간, 어항 청소시간 등
