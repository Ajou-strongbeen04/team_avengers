# 원칙
## 화면
- 모두 애니메이션으로 역동적으로 구성
## 대사
- 빠르게 1분까지는 쇼츠식으로 정보전달
- 1분 부터 앱시연 + 시장조사 내용

# #1
## 화면 
- 물고기 잘 살고 있음 -> 죽어버림
## 대사
> 물고기를 키우던 사람들은, 완전히 멘탈이 나가버렸습니다. 어제까지 멀쩡하던 물고기가 오늘 갑자기 죽었기 때문입니다.

> 원인은 바로 눈에 보이지 않는 수중 환경이었습니다. 

> 그때 똑똑한 사람들은 기발한 생각을 했는데요.

# #2
## 화면
- 어항에 각종 센서가 달리는 모습
## 대사
> 수중환경을 측정하는 센서를 담아 스마트 어항을 만들었습니다.

> 이렇게 하니 눈에 보이지 않던 수치를 직접 볼 수 있게되었죠.

> 하지만 문제는 비싸다는 것이었습니다. 많은 고성능의 센서가 사용되니 제품이 비싸지는 건 당연한 것이었죠.

# #3
## 화면
- 수온/탁도 센서 보여주기
## 대사
> 그래서 저희는 기발한 생각을 했는데요.

> 수중환경을 측정할때 두가지 센서만 남기고 나머지 요인을 추론하는 방법을 떠올린 것이었죠.

# #4
## 화면
- 논문 표지, 실험 내용
## 대사
> 용존산소를 이용하여 수중환경을 구성하는 지배방정식을 세웠습니다.

> 그리고, 사용자마다 다른 환경을 사진을 통해 분석할 수 있게 했죠.

> 그렇게 하니 다양한 어항에서 같은 방법을 사용할 수 있게 되었습니다.

# #7
## 화면
-앱 화면 보여주기
<여기서부터 앱 시연(영상 html)>
1. 어항 사진 넣어서 경계조건 설정
2. 각종 파라미터 조절 보여주기
3. 센서 연결
4. 메인화면 연결
## 대사
> 이 측정값들은 자체 소프트웨어로 연결되는데요.

> 아까 보셨던 논문의 내용이 기반이 되는 하나의 시스템으로 작동하는 어플리케이션을 만들었습니다.

> 각 요소를 복합적으로 분석하여 물고기의 건강상태를 분석하는 물고기 전용 웨어러블이 되는 것입니다.
