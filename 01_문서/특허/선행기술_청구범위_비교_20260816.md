## 0. 우리 권리범위 요약

| 청구항 | 카테고리 | 핵심 한정 |
|---|---|---|
| **1** | 장치(독립) | 촬영부 + 영상 인식부 + 경계조건 자동설정부(**정량계수 배제**) + **수온·탁도만** 계측하는 센서부 + **2계층** 물리 추론부(제1계층 유동장·와점성 / 제2계층 복수 수동 스칼라 병렬 선형풀이) + 국소 산-염기 평형 + 융합 판정부 |
| 2~12 | 종속 | 공통 난류확산 / 오프라인 대리모델·와점성 생값 / 질산화 = TAN 포화함수 × DO 포화함수 / 알칼리도 무플럭스 / 저산소역·비이온암모니아 어긋남 표시 / 침강·퇴적 / **단일 해석좌표계** / 캘리브레이션·위험확률 / 기포체적분율 고정점 / 구역 조대화 / **프로브 물리구조** |
| **13** | 방법(독립) | (a)촬영 → (b)영상→BC → (c)수온·탁도 계측 → (d)계수·소스 확정 → (e)대리모델 유동장 → (f)스칼라 병렬 풀이 → (g)pH·비이온암모니아 → (h)통합 판정·배치 처방 |
| 14 | 종속 | 배치 처방 후보별 대리모델 재호출 → 개선량 비교 |
| **15** | 프로그램(독립) | 청13 방법의 기록매체 저장 컴퓨터 프로그램 |

청구항 1을 방어하는 축은 **세 개**다.

1. **입력 제한** — 영상 1장 + 수온 + 탁도, 이 3종뿐. DO·pH·암모니아 센서를 쓰지 않는다.
2. **경계조건 사상 + 정량계수 배제** — 영상 인식 결과를 BC 객체로 사상하되 물질전달계수·기포체적분율은 그 객체에 넣지 않는다.
3. **2계층 분할** — 유동장을 먼저 고정하고, 그 위에서 복수 스칼라를 **병렬 선형** 풀이한다.

이 세 개 중 어느 하나라도 선행에 이미 있으면 그 축은 무너진다. 아래는 각 축이 살아있는지의 대조다.

### 1.1 US12099047B1 / US20250012772 — Ecotech LLC

| 항목 | 내용 |
|---|---|
| 명칭 | Sensors, system and methods for monitoring and adjusting conditions of an aquarium |
| 권리자 | Ecotech LLC |
| 우선일 | 2020-02-10 (가출원 62/972,321) |
| 상태 | B1 등록 + 계속출원 US20250012772(2024-09-19 출원, 2025-01-09 공개) **패밀리 진행 중** |
| 독립항 | **청1** = 센서 어셈블리(하우징+센서+송신기+전원, **주기적으로 꺼졌다 켜지며 계측**) + 출력장치 + 메인시스템 + 사용자 인터페이스 / **청10** = 동일 구성의 방법항 |
| 센서 열거 | 온도, 전도도, pH, ORP, 수위, **탁도**, 습도, 조도·색도 |
| 출력장치 열거 | 히터, 쿨러, 워터펌프, 도징펌프 |

**겹치는 부분:** 우리 청구항 1의 구성요소 중 "수조에 거치되어 수온과 탁도를 계측하는 센서부" 하나. 온도·탁도 센서를 수조에 두고 무선 전송하는 것 자체는 이 문헌으로 공지다.

**겹치지 않는 부분:** 이 특허에는 촬영부·영상 인식부·경계조건 자동설정부·물리 추론부·융합 판정부가 **전부 없다**. 구조가 `센서 계측치 → 프리셋 범위 비교 → 액추에이터 on/off` 인 폐루프 제어이고, 계측되지 않은 항목의 공간분포를 산출하는 단계가 존재하지 않는다.

**판정:** 청구항 1 전체로는 신규성 확보. 다만 **청구항 12(프로브 물리구조)** 는 이 계열 + 일반 수조 센서 프로브 선행에 가장 취약하다. 브릿지·후크·2레그 구조는 공지 형상에 가깝고, 실질적 차별은 "제2 레그 팁을 폭기 플룸 외측·폭기축에서 가장 먼 코너 저층에 배치" 한정뿐이다. 이 배치 한정이 없으면 청12는 무너진다.

**정정 필요:** `05_경영.md` §7.4 는 이 문헌을 **US12099047B2** 로 적었으나 실제 등록번호는 **B1** 이다. 또 US20250012772 를 별건처럼 나열했으나 **같은 패밀리의 계속출원**이다. 표기를 고쳐야 한다.

### 1.2 US8542911B1 / US6912293B1 (동 패밀리 US8369610B1 · US8818080B1) — Korobkin

| 항목 | 내용 |
|---|---|
| 명칭 | Photogrammetry engine for model construction |
| 권리자 | Carl Phillip Korobkin (개인) |
| 우선일 | 1998-06-26 |

**시사점 — 청구항 8 삭제 권고:** 청8("영상 인식부·BC설정부·제1/제2계층·센서부가 **단일 해석좌표계를 공유하고 좌표 변환 단계를 두지 아니한다**")는
(a) 사진측량 선행 대비 진보성 기여가 거의 없고,
(b) `05_경영.md` §7.3 이 이미 경고한 대로 **실제 구현과 충돌**한다 — `기하인식/03_BC_출력스키마.md` §0 과 `00_운영/용어사전.md` §2-1 은 사진좌표 ≠ CFD좌표이며 어댑터가 2·3축을 변환한다고 명시한다.
청8은 명세서 뒷받침이 없는 청구항이 되므로, 정식출원 시 **삭제하거나 "인식 결과와 센서 배치가 공통의 해석좌표계로 사상된다"** 정도로 넓혀 보정하는 편이 안전하다.

## 2. 상용 제품 대조

### 2.1 Seneye (Home / Reef / Pond)

| 항목 | 내용 |
|---|---|
| 계측 항목 | **수온 · pH · 유리 암모니아(NH₃)** (Reef 모델은 LUX/PAR 추가) |
| 방식 | 수조 내 1개소 거치 + **소모성 슬라이드 교체**, 상시 감시 |
| DO | **측정하지 않음** |
| 출력 | 단일점 시계열 값과 경보 |

**주의할 겹침:** Seneye 는 **비이온 암모니아(NH₃)를 표시한다.** 우리 청구항 6 의 출력 항목과 이름이 같다. 다만
- Seneye 는 슬라이드 발색으로 NH₃ 를 **직접 계측**한 단일점 값이고,
- 우리 청6 은 이송된 TAN 공간장에 셀별 pH·수온을 적용해 **분율을 계산한 공간분포**이며, 나아가 **"저산소 위험구역과 비이온 암모니아 독성 위험구역이 서로 다른 위치일 때 합집합으로 안전측 판정하고 그 어긋남을 표시"** 라는 공간적 한정을 갖는다.

이 어긋남 표시 한정이 청6 을 지탱한다. 만약 보정 과정에서 이 한정을 빼고 "비이온 암모니아를 산출한다"로 넓히면 Seneye 및 다수의 NH₃ 계산기(공지 해리평형식)에 걸린다. **청6 의 공간 한정은 유지해야 한다.**

DO 를 측정하지 않는다는 점은 우리 포지션(비계측 항목의 공간 추정)에 유리하다.

### 2.2 Dangbei Smart Fish Tank 2S Ultra — **가장 위험한 상용 선행**

| 항목 | 내용 |
|---|---|
| 공개 | IFA 2025 공개 → 2026-04 출시 |
| 기능 | 카메라 + AI 영상 인식으로 **어종·크기·마릿수 식별** → 급이·조명·수류·살균을 자동 조절 / 고정밀 센서 기반 실시간 수질 모니터링 및 경보 / 암모니아·아질산 제거 여과재 |

**겹치는 부분:** 우리 청구항 1 의 영상 인식부가 인식하는 항목 중 **"어류의 개체수 및 크기"** 가 정면으로 겹친다. 게다가 공개 시점이 우리 출원일(2026-08)보다 **앞선다.**

**겹치지 않는 부분(공개 자료 범위):**
- 인식 결과를 **물리모델의 경계조건으로 사상하지 않는다.** 액추에이터 제어 파라미터로 쓸 뿐이다.
- 수질은 **센서로 측정한 값**이지, 측정하지 않은 항목의 **공간분포를 추정한 결과**가 아니다.
- 2계층 분할·수동 스칼라 병렬 풀이·산-염기 평형에 해당하는 기재가 없다.

**판정:** 청구항 1 은 위 두 한정으로 구별된다. 그러나 **청구항 1 에서 "어류의 개체수 및 크기 인식"만 떼어내면 Dangbei 로 공지**이므로, 이 요소를 단독 특징으로 내세우는 서술은 발표·논문에서 피해야 한다.

**즉시 조치 필요:** Dangbei(당배이) 명의의 **중국·PCT 특허 패밀리를 검색해야 한다.** 제품은 공개됐지만 청구범위는 아직 미확인이며, 2025년 공개 제품이면 2023~2024 출원이 존재할 가능성이 높다. 이것이 현재 **최대 미해소 리스크**다.

### 2.3 AQUA AI (aquaai.uk)

AI 어종 식별 · 질병 감지 · "water intelligence" · 마켓플레이스를 표방한다. 기술 상세가 공개되어 있지 않아(사이트가 JS 렌더링) **판정 보류**. 확인된 범위에서는 물리모델 기반 공간분포 추정의 근거가 없다. 재확인 대상.

### 2.4 모바일 앱군 (AquaCare:AI, TidyTank, AquaEstima PRO, TankSync 등)

2025~2026년 App Store 에 다수 등장한 어항 관리 어시스턴트다. 어종 식별·일정 관리·수치 기록이 중심이고, 물리 기반 공간 추정을 하는 것은 확인되지 않았다. 리스크 낮음. 다만 **"AI 어항 앱"이 이미 레드오션**이라는 사실은 `05_경영.md` §8 4순위(레드오션) 위험을 그대로 뒷받침한다.

## 3. 청구항별 리스크 판정

| 청구항 | 리스크 | 근거 |
|---|---|---|
| **1** | 낮음~중간 | 세 축(입력 제한 · BC 사상 + 정량계수 배제 · 2계층) 이 결합된 형태로는 대응 선행 없음 |

## 4. 미해소 사항

1. **KIPRIS 정식 검색 여전히 미수행.** `05_경영.md` §7.4 의 지적이 그대로 남아 있다. 이번 조사는 공개 웹 기반 예비 대조다.
2. **Dangbei 특허 패밀리 미확인 — 최우선.** 제품 공개는 확인했으나 청구범위를 못 봤다.
3. **Ecotech LLC 패밀리가 진행 중이다.** US20250012772 가 2024-09 계속출원이므로 청구범위가 확장될 수 있다. 정식출원 시점에 재확인해야 한다.
4. **미공개 출원(18개월) 리스크는 원리적으로 배제 불가.**
5. **논문 선행 2건**(vision-hypoxia · 팔각 양식수조 DO CFD)은 이번 대조 범위 밖이다. `05_경영.md` §7.4 의 기존 판정(각 "높음")을 그대로 둔다 — 특히 팔각 양식수조 DO CFD 때문에 **C4 단독 청구가 불가**했고 그래서 청구항 1 이 2계층 구성을 갖게 됐다는 경위는 유효하다.
6. **변리사 정식 FTO 가 필요하다.** 위 판정은 침해 판단이 아니다.
