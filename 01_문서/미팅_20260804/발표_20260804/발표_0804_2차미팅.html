1-1 · 1-2. 주제를 바꾼 물리적 이유

기존 주제 — 산업 양식장(가두리) 내부 유속 프로파일 기반 DO 3D 분포 예측
주제변경의 사유 ①

유속항이 지배적이라고 보았다

∂C/∂t + ∇·(UC) = ∇·(Deff∇C) + ΣS
  • 가두리 양식장 내부 유속 프로파일 확보가 목표
  • 유속장을 알면 DO 3D 분포를 알 수 있다고 판단
주제변경의 사유 ②

외부 유동이 안쪽에 닿지 않는다

  • 4×8 배치 · 10×10×10 m 케이지, 외부 균일유동 0.3 m/s
  • 외부와 직접 맞닿은 케이지만 영향을 받음
  • 안쪽 2×6 케이지는 유속이 거의 0에 수렴
  • 남는 것은 방향 없는 난류성 유동뿐
→ 고전 방정식 해석 실패 · 검사체적 해석 실패

방정식으로 되돌아가서 얻은 것

U ≈ 0 , ∂C/∂t = 0   ⟹   0 = ∇·(Deff∇C) + ΣS
  • 정상상태 케이지 내부 DO는 ΣS 하나로 결정된다 — 문제가 간단해졌다

…그리고 잃은 것

  • 이송항이 사라지면 공간구조도 사라진다
  • 공간구조가 없으면 "어디가 위험한가"를 물을 수 없다
  • AI융합 대회에서 다룰 대상이 남지 않는다

4-1. 센서 — 구성 요소와 개선점

(1) 시스템

  • 벽걸이 ∩ 2-레그 · IP68 wet / 생활방수 dry
  • 프로브 Φ10 mm · 침지 ≈200 mm
  • 장착벽 ↔ 프로브축 35 mm

(2) 수온 — DS18B20

  • 스테인리스 방수 프로브, 3선
  • 팁을 최저점에 노출 → 저층 수온
  • 포화 DO C*(T) + 탁도 온도보정 기준값

(3) 자체 제작 IR 탁도 센서

  • 능동부품 ESP32 1개 — OP앰프·커패시터 0개
  • GPIO 3비트 R-DAC(150/330/680 Ω) + Rsense 22 Ω, 신호처리는 소프트웨어 락인
  • 변조 510 Hz · 10 s 적분 → 50·60 Hz 동시 널링, S = Asig/Asense로 드리프트 소거

(4) 통신 — BLE

  • ESP32 → 네이티브 BLE → 앱
  • Capacitor 플러그인이 처리, 화면 코드는 그대로 재사용
  • 측정 주기 1시간 · 듀티 0.28 % (<5 mA)
개선점
  • 남은 개선점 — 차광 하우징 미장착으로 인한 미광 유입. 하우징 없이 공기 중에서 측정하면 미광(암 잔류) 신호가 전체 신호의 28 %를 차지한다(통과 기준 5 %) — 주파수 특성이 실제 신호와 거의 같아(−8 % vs −10 %) 빛이 광학 경로 밖에서 새어 들어오는 것으로 판정됐다. 차광 하우징을 장착하면 해결되는 문제다.

4-2. 어플리케이션 — Input → Output

사용자가 넣는 것과 센서가 넣는 것을 분리했다. 사용자는 어항 정보만 넣고, 나머지는 센서와 물리가 채운다

INPUT ① 사용자 입력

  • 어항 실측 치수 (가로·세로·깊이 cm) · 수위
  • 어항 정면 사진 1장
  • 어종 · 마릿수 · 이름 · 먹이 시간
  • 폭기 전력 P [W] · 에어스톤 침지 높이

INPUT ② 센서 입력 (BLE 자동)

  • 수온 [℃] — DS18B20, 1시간 주기
  • 탁도 [NTU] — 자체 IR, 락인 적분 10 s
  • 센서 고장판정 · 클리어워터 교정 내장
