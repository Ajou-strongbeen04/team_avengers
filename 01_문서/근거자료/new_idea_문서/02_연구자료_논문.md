# (2) 가정용 수조 연구자료·논문

> 대상 범위: 아쿠아리움(전시급)이 아니라 **일반 가정용 1m 이하 수조**.
> 결론: 수질·복지·IoT·컴퓨터비전 모두 학술적으로 성립. 우리 접근의 각 요소에 선행연구 백본이 있다.

---

## 1. 가정 수조 수질 정량 연구

**The Effect of Substrate on Water Quality in Ornamental Fish Tanks** (2022, PubMed/PMC)
가정 어항을 모사한 담수조에서 온도·산소·pH·총암모니아질소(TAN)·비이온화 암모니아·질산염·이온을 측정. 조건: 맨 수조 / 플라스틱 수초 / 자갈 / 모래. 결과: 자갈·모래 첨가 시 pH·TAN·질산염 상승, 기질에 세균 증가.
→ 시사점: **가정 수조의 수질은 세팅(기질·수초·배치)에 따라 정량적으로 달라진다** = 우리의 "배치 추천"이 과학적으로 근거 있음.

## 2. 관상어 복지(welfare) 연구

**The welfare of ornamental fish in the home aquarium** (ResearchGate)
관상어 복지는 정식 학술 주제. "취미가·판매자가 수질을 면밀히 관찰하지만, **가정 환경에서 어류 복지는 엄밀히 충족되기 어렵다**"는 지적. 공공 아쿠아리움이 자연 생태를 부분적으로 모사해 스트레스가 낮은 것과 대비.
→ 시사점: 개선 여지 자체가 연구/제품 명분. 우리의 "실시간 환경 유지"가 복지 향상으로 프레이밍 가능.

**Monitoring water quality changes and ornamental fish behaviour during commercial transport** (ScienceDirect)
수질 변화와 어류 행동을 동시 모니터링 → 수질-행동 연계의 선행연구.

## 3. IoT 기반 스마트 어항 (우리의 "센서 실시간 유지" 백본)

- **An IoT-Enabled Smart Aquarium System for Real-Time Water Quality Monitoring and Automated Feeding** (arXiv 2601.08484) — 실시간 수질 모니터링 + 자동급이. "수동 관리 = 매우 높은 폐사율, 자동화 = 24/7 관리로 노력↓·수질↑"이라는 문제의식 명시.
- **Solar powered wireless water quality monitoring system for ornamental fish** (ScienceDirect, 2023) — 관상어용 무선 수질 모니터링.
- IEEE 다수: An IoT-Based Smart Aquarium Monitoring System / Real-Time Smart Aquarium Monitoring Driven by IoT / NodeMCU+Blynk 기반 서식지 모니터링.
→ 시사점: 센서 모니터링 자체는 **이미 포화된 연구영역**. 우리는 여기에 얹을 "무엇"이 필요 → DO 구배·물리모델.

## 4. 컴퓨터비전 기반 어류 분석 (우리의 "사진/카메라 진단" 백본)

- **Deep learning-based computer vision for fish behavior recognition** (ScienceDirect 리뷰) — 섭식·스트레스·질병·번식·공식(cannibalism) 5대 행동 인식.
- **Computer vision based approaches for fish monitoring systems** (Springer, AI Review 2025) — 종합 리뷰.
- **Aquatic Toxic Analysis by Monitoring Fish Behavior Using Computer Vision** (PMC) — 행동으로 수질 독성 역추정.
- 질병 증상(출혈·유영저하·복부팽만) 탐지 프레임워크 존재. **난점: 반사·가림(occlusion), 대량 라벨 데이터 필요.**
→ 시사점: "사진으로 물고기 상태 판정"은 학술적으로 가능. 단 **반사·가림 처리**가 실무 난제 → 우리 제품의 기술 리스크로 미리 인지할 것.

---

## 종합 시사점

각 요소(수질 모니터링·복지·IoT·비전)는 개별적으로 성숙했다. **미개척지는 이들의 교차점, 특히 "물리(이송-확산) 기반 DO 공간분포 예측"과 "사진→배치 진단"의 결합.** 우리 논문/발표의 novelty는 개별 기술이 아니라 **결합과 물리 prior**에서 나와야 한다.
