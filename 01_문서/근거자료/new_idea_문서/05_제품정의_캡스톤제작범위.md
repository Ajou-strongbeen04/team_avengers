# (5) 제품 정의 & 캡스톤 제작 범위 (초안)

## 1. 한 줄 컨셉

**"자동으로 대신 키워주는 기계가 아니라, 당신이 키우되 물고기가 위험할 때만 알려주는 5만원짜리 건강지킴이."**

- 자동차의 **자율주행이 아니라 계기판 경고등** 포지션.
- 밥 주기·청소하기의 "손맛"(반려의 본질)은 사용자에게 남긴다. 기계는 **판정만** 한다: 위험 / 안전 / 건강.
- 경쟁사(Dangbei·Neptune·Aqua AI)는 "자동으로 다 해준다"로 감 → 우리는 **의도적 비(非)자동화 + 저가 + 검진 특화**로 차별화.

## 2. 타깃 · 가격

- 타깃: 관상어 입문자·1인가구("물멍" 수요). 프리미엄 관리기를 살 이유가 없는 층.
- 가격: **기본 세트(센서 다발) 1~3만원 / 카메라 모듈 +3만원 → 풀세트 약 5만원.**
- 차별화 축: 가격 접근성 + "검진만" 단순함 + (핵심) 물리 기반 DO 추정.

## 3. 차별화 해자 (왜 안 베끼나)

- 싼 센서 묶음만으로는 **"한 점, 한 값"** — dead spot(공간 저산소) 못 잡음 = 그냥 싼 Seneye.
- 진짜 DO 센서는 개당 수만~수십만 원 → **5만원 세트에 직접측정은 불가.**
- ⇒ **DO를 "직접 측정"이 아니라 "추정"**해야 하고, 그 추정 엔진이 곧 해자:
  **싼 프록시 센서 + 카메라(행동·배치) + 이송-확산 물리 → DO 구배 추정.**
- 즉 "싸게 검진만"이라는 시장 직관과 "물리 기반 DO 추정"이라는 기술 무기가 **같은 제품으로 수렴.** 비싼 센서를 못 쓰는 제약이 오히려 해자를 만든다.

## 4. 캡스톤에서 실제로 제작할 것 (4대 구성)

### ① 센서 다발 — DO 예측용 최소 센서
직접 DO 측정이 아니라 **DO를 추정하기 위한 최소 프록시**만 담근다.

| 센서 | 역할 | 개략 단가(원) |
|---|---|---|
| 방수 온도(DS18B20류) | C_sat(T) 결정, DO 용해도의 1차 변수 | 2,000~4,000 |
| pH (아날로그 모듈) | 수질 스트레스·질소순환 상태 | 15,000~25,000 ← **예산 스윙 변수** |
| TDS/EC | 오염·유기물 부하 프록시 | 5,000~10,000 |
| 탁도(turbidity) | 유기물·부패 프록시 | 5,000~8,000 |
| MCU(ESP32류) | 수집·통신 | 5,000~8,000 |

- **정직한 이슈**: pH 모듈이 "1~3만원" 목표의 최대 걸림돌. pH를 넣으면 3만원 초과 가능 → (a) pH 포함 프리미엄, (b) pH 빼고 온도+TDS+탁도+카메라로 추정 강화, 중 택1을 토요일 결정.
- 정확도 한계는 카메라·물리로 보완(단독 정확도에 목매지 않음).

### ② 카메라 모듈 — 싼 하드웨어를 CV로 재해석
저가 카메라(ESP32-CAM 등, 7,000~10,000원)를 쓰되, **소프트웨어로 하드웨어 이상을 뽑는다.**

- **어류 행동 = 공짜 DO 센서**: 수면 뻐끔(piping)·무기력·비정상 유영 → 저산소 조기신호.
- **배치 인식**: 수조 형상·장식물·기포기 위치 → 이송-확산 모델의 입력(구배 예측).
- **부가**: 어종/마릿수/크기(사육부하), 탁도·조류 시각 판정.
- "재해석"의 의미 = 4K가 아니어도 **행동 분류·배치 파악에는 충분**하다는 것.

### ③ 기포기 · 여과기 — 구매 후 연결
기성품 구매해 시스템에 연결. 자체 제작 대상 아님.

- 물리적으로는 **폭기 = DO 소스항(k_L·a 항), 여과 = 질소순환·질산화 싱크.**
- 초기엔 자동제어 없이 "상태 반영"만(비자동화 철학). 향후 옵션으로 폭기 on/off 추천.

### ④ 소프트웨어(앱)
파이프라인: **센서 + 카메라 → DO/건강 추정(프록시+행동+물리) → 판정 출력.**

- 핵심 출력: **위험 / 안전 / 건강** 한 줄 판정(+ 근거).
- 배치 처방: "이 구석에 저산소 위험 → 기포기 위치 조정" 등.
- UX: 물고기 상태를 보여주는 귀여운 애니메이션(채택 촉진용, 해자는 아님 — 가볍게).
- **최우선 신뢰성 요건**: "죽어가는데 안전으로 뜨는" 거짓 안전(false-safe)이 최악의 실패. 기능 수보다 판정 신뢰도.

## 5. DO 추정 파이프라인 (요소 연결도)

```
[온도·pH·TDS·탁도]  ─┐
                     ├─→ 데이터 융합 ─→ 이송-확산 물리모델 ─→ DO 공간분포 추정 ─→ 위험/안전/건강 판정
[카메라: 행동·배치] ─┘        (센서=점, 카메라=전역/행동, 물리=구배 예측)
```

## 6. 리스크 · 미결(토요일 안건)

- **BOM**: pH 포함 여부(1~3만원 목표 사수 vs 정확도).
- **판정 신뢰도 검증**: false-safe를 어떻게 막고 검증할 것인가(실측 대조 필요).
- **DO 실측 기준**: 검증용으로 실험실 DO미터 1대는 필요(양산품엔 미포함). 있는지 확인.
- **카메라 난제**: 반사·가림·조명. 데모 환경 통제.
- **실물 수조 구축**: 어종(금붕어 고정?)·마릿수·일정·예산·담당.
- **물리모델 충실도**: 0D 베이스라인 → Pe·Da로 공간해석 필요성 판정 → CFD/축소모델(사다리는 별도 논의).
