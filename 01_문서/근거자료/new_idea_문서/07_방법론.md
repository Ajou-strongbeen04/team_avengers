## 0. 한 줄 요약

**순방향 물리 모델(06번)은 고전적으로 검증된 식의 충실한 조립이며 학술적으로 타당하다.
프로젝트의 novelty는 식 자체가 아니라 (a) 가정용 수조 dead-spot 도메인, (b) 사진→Gemini 기하분석→BC 자동설정,
(c) 실험단계 고정밀 계측·CFD로 확보한 ground-truth를 저가 관측만으로 재현하는 역추정에 있다.**

---

## 1. 핵심 설계: 실험 → 저가제품 2단계

제품의 목표는 값비싼 DO 센서 없이 DO 공간분포를 추정하는 것이다. 이를 **두 단계**로 분리한다.

**1단계 — 실험(기준 확보).**
고정밀·다점 DO 계측 + CFD(06번 지배식)로 **DO 장(field)의 ground-truth**를 확보한다.
- 어항을 8분할, DO 센서 8~9점 다점 측정으로 DO 장 재구성.
- 각 측정 지점에 프록시 센서(온도·탁도·pH·TDS)를 **동시 부착** → "실측 DO ↔ 프록시" 짝지음 데이터 확보.
- CFD는 온라인 제품 연산이 아니라 **오프라인 ground-truth·축소모델(ROM) 생성기**로 사용.

**2단계 — 저가제품(재현).**
1단계에서 얻은 관계를 학습·캘리브레이션하여, **저가 관측만으로 DO 장을 재현**하도록 설계.
- "싼 관측"의 뜻: 저품질 센서가 아니라, **DO 센서만 고가**이므로 이를 비교적 저렴한 온도·탁도 등으로 대체한다는 의미.
- 추론 시점 입력: 프록시 센서 + 카메라(행동·배치) + 사진 기반 BC.

이 구조는 저가센서 학계의 표준인 **기준기 대비 캘리브레이션 전이(reference-based calibration transfer)** 방법론과 동일하며,
피벗의 명분이었던 **반증 가능성(falsifiability)**을 완성한다(실측 DO 장으로 모델을 반증 가능).

```
[1단계 실험]  다점 DO(8~9점) + 프록시 동시계측  ─┐
              CFD(06 지배식) ─ DO 장 ground-truth ─┼─→ ROM/대리모델 + 관계 학습
                                                    │
[2단계 제품]  사진→Gemini→BC  +  프록시센서 + 카메라 ─┴─→ DO 장 재현 → 위험/안전/건강 판정
```

## 2. 지배식 요약 (06번 본체 참조)

$$\frac{\partial C}{\partial t}+\nabla\cdot(\mathbf U C)=\nabla\cdot\big(D_\mathrm{eff}\nabla C\big)+\sum S$$

- **운동량 생성**은 $\sum\mathbf F$(폭기 부력 + 여과 제트), **산소 생성·소모**는 $\sum S$(폭기 계면전달 + 어류호흡 + 질화)에 집약.
- **재폭기·SOD는 체적소스가 아니라 경계 플럭스**(Robin/Neumann)로 처리 → 확장 시 기본식 불변, 소스/경계항만 추가.
- 폭기 플룸은 완전 2상 대신 **규정 플룸(단상 Euler + 규정 공극 + 부력 body force, "Route B")**로 축약.
- 정상상태 해석 시 $\partial C/\partial t=0$; dead-spot(공간구배)이 제품의 핵심 차별점.

세부 식·부호규약·계수는 `06_지배방정식_어항DO모델.md` 참조.

## 3. 문헌 대응 — "고전적으로 검증된 식인가?" → 예

방정식은 새로 만든 것이 아니라 **수십 년간 검증된 고전 구성요소의 조립**이다. 모든 항에 인용을 붙일 수 있다.

| 06번의 항 | 고전적 출처 / 표준 위치 |
|---|---|
| 이송-확산-반응(DO 균형) | **Streeter–Phelps(1925)** DO sag 모델의 3D 확장. 오늘날 CFD×수질모델 결합(폭기조 CFD+ASM2, 산화구 DO 2상 CFD)의 표준 골격 |
| 도메인 최근접 선례 | **팔각 양식수조 DO 장 CFD(2024)** — 동일 방법의 한 스케일 확대(선행연구 경고이자 타당성 근거) |
| 수면 재폭기 BC $-D\partial C/\partial z=k_L(C^*-C)$ | **Lewis–Whitman 2막 이론(1924)** |
| 포화농도 $C^*(T)$ | **Benson–Krause**(APHA Standard Methods) 표준 계수 |
| SOD 플럭스 + Arrhenius 보정($\theta_a\!\approx\!1.024,\ \theta_s\!\approx\!1.06\text{–}1.08$) | QUAL2K·EPA WASP류 표준 온도보정 |
| 단상 Euler + 규정 공극 플룸 + 부력 body force | 폭기 플룸 CFD의 정석("액상 유동장을 Euler 계에서 풀되 공극분포 추정 삽입") |
| 기포유발점성 $\mu_\mathrm{BI}$, $C_{\mu B}=0.6$ | **Sato & Sekoguchi(1975)** 원본, 상수 0.6까지 일치 |
| SST $k\text{–}\omega$ | **Menter(1994/2003)** |
| $D_t=\nu_t/Sc_t,\ Sc_t\approx0.7$ | Reynolds 유추 / 표준 스칼라수송 폐합 |

검산 결과 부호규약·정량계수 모두 문헌과 일치(포화 DO 룩업표, 선형근사 오차 ≤0.11 mg/L, 소스항 대표값, 폭기/여과 동력 등).
→ **심사에서 "물리 모델이 신뢰할 만한가"에 강하게 답함.**

## 4. Novelty의 위치 (심사 대비)

방정식이 전부 고전이므로, 심사위원은 "그럼 식 자체엔 새로운 게 없지 않나?"를 물을 것이다. 답은 **결합과 적용**에 있다.

1. **적용 도메인** — 가정용 수조의 **DO 공간구배(dead-spot)**. 소비자 제품이 다루지 못한 빈칸.
2. **사진 → Gemini 기하분석 → BC 자동설정** — 사용자 환경을 촬영하면 형상·기포기/여과 위치·배치·사육부하를 인식해
   경계조건·환경변수를 재설정. **기하·위상 일반화**를 소프트웨어로 확보(기존 CFD는 케이스별 수작업 세팅).
3. **저가 관측 기반 DO 역추정** — 고가 DO 센서 없이 온도·카메라를 백본으로 DO 장 재현(2단계 설계).

02·04번 문서의 결론("novelty는 개별 기술이 아니라 결합과 물리 prior")을 문헌 대조가 뒷받침한다.

## 5. 논의로 확정된 설계 보완점

**적용범위(envelope)의 정직한 표현.**
Gemini가 사진에서 잡는 것은 **기하·위상**(형상·소스 위치·배치)이며, PDE가 요구하는 **정량 계수**
(SOD₂₀, $k_L$, 플룸 $\alpha_g/d_b$, OCR)는 사진에 보이지 않는다. 또 식재+CO₂·해수·섬프여과는 base 가정을 깨는 **regime 전환**.
→ 주장 형태: **"담수·무식재 수조에서 기하학적 일반화 + 계수는 사전분포(prior) 범위 내에서 센서·행동으로 온라인 교정."**
(Gemini 기하 서술자는 ROM/대리모델의 입력공간으로 매핑되어야 함 — 사용자마다 풀 CFD는 못 돌림.)

**입력 백본의 재정리(관측성).**
- **온도**: "프록시"가 아니라 $C^*(T)$로 DO 포화상한을 결정하는 **물리적 인자** → 가장 강한 입력.
- **카메라 gasping(수면 뻐끔)**: 실제 저산소의 **생물학적 직독** → 두 번째로 강함.
- **탁도·TDS·pH**: 유기부하·질소상태의 **상관 프록시** → 소스항 prior로만 사용.

**다점 검증 계측 보완.**
- 8~9개 DO 프로브 **상호 교차보정**(동일 용액 공동보정, 드리프트 방지).
- **침입성(intrusiveness)**: 소형 수조에 프로브·케이블 다발이 유동을 교란해 인공 dead-spot 생성 가능 → 배선 최소화 또는 교란을 해석에 명시.
- 로깅 전 **정상상태 도달 확인**.

**수치 안정성.**
- 기본형 0차 소비는 dead-spot에서 $C<0$(비물리)을 낼 수 있음 → 최소한 **O₂ 제한 Monod항 $C/(K+C)$을 켜서 양positivity 보장**하거나 clip.

## 6. 잔여 리스크 · 검증계획

**관측성 가설(가장 중요).** "싼 관측이 DO 공간구배 정보를 담는가"는 **가정이 아니라 실험단계에서 검증할 가설**이다.
캘리브레이션은 없는 정보를 만들지 못한다. 1단계의 짝지음 데이터로 재구성 가능성을 **증명/반증**한다.

**식별성(identifiability).** 보정 파라미터가 많음(α_g, d_b, 플룸형상, OCR, SOD₂₀, r_nit, k_L). 물리 prior 정규화로 과소결정 완화.
false-safe(죽어가는데 안전 표시) 방지가 신뢰성 최우선.

**공간분해능.** 8~9점은 dead-spot vs 혼합역 구별·CFD 정성검증엔 충분하나 미세구배는 못 잡음(셀 평균 비교로 처리).

**소스항 불균질.** SOD는 바닥 잔여물·생물막에 따라 시변·불균질; 질화는 여과재뿐 아니라 기질(자갈)에서도 발생 → 저평가 주의.

**검증 순서(권고).** 0D 예산 베이스라인 → $Pe,\ Da$ 로 공간해석 필요성 판정 → CFD/ROM → 다점 실측 대조(반증) → 저가 재현 정확도 평가.

## 7. 발표·논문에 반드시 넣을 문장 (체크리스트)

- [ ] "순방향 물리는 고전(각 항 인용 가능), novelty는 도메인·Gemini BC·저가 역추정의 **결합**."
- [ ] 2단계 설계도(실험 ground-truth → 저가 재현)와 **CFD=오프라인 ROM 생성기** 명시.
- [ ] 적용범위를 **담수·무식재·좁은 운용역**으로 스코프.
- [ ] "싼 관측→구배 재구성"을 **검증 가설**로 프레이밍(카메라 보완 논리 포함).
- [ ] 다점 DO 계측 + 교차보정 + 침입성 고지.
- [ ] Péclet regime 정합성 한 줄(가두리 $Pe\!\to\!0$ vs 어항 $Pe=O(1)$).
