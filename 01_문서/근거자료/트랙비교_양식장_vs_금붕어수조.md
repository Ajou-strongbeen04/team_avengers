## 0. 한눈 비교표

| 축 | 양식장 (원트랙) | 금붕어 수조 (피벗) |
|---|---|---|
| **도메인** | 바다 가두리(10 m급), 다중배열 | 가정 수조(≤1 m) |
| **문제 명분** | 대량폐사·식량산업·기후변화 (사회적 임팩트 大) | 반려어 폐사·입문자 진입장벽 (친근·검증 용이) |
| **이송-확산 취급** | 유속항 **버림**(U≈0), ΣS 소스항 중심 | 유속항 **복원**(펌프·폭기로 유의미), 완전형 |
| **검증 가능성(ground truth)** | ✕ 실제 가두리 계측 불가 → "실험 무의미" 지적의 핵심 | ◎ 수조를 우리가 소유·계측 → 반증 가능 |
| **하드웨어 제작** | 실물 구축 사실상 불가 → 시뮬레이션 중심 | 실물 5만원 세트 제작 가능(센서·카메라·기포기·앱) |
| **데이터 확보** | 논문 시드에 의존, 현장 데이터 희소 | 직접 실측 수집 가능 |
| **시장·경쟁** | 블루오션 니치(고령 어가), 단 B2B 접근 난이 | 레드오션(스마트어항 多)이나 **DO 공간구배는 빈칸** |
| **캡스톤 스코프** | 과대범위 위험(지도교수 지적) | 좁히기 쉬움(비자동화·검진 특화) |
| **Novelty/해자** | 유체코어 위 LLM 추론 계층 | 물리기반 DO 추정(센서리스) × 멀티모달 |
| **팀 역량 정합** | 기계(CFD)·SW(AI)·경영(BM) 모두 활용, 난도 高 | 동일 역량 + **실물 제작 경험** 추가, 난도 中 |
| **성과물 인상** | 시뮬 데모(추상적) | 작동하는 실물+앱(직관적) |

## 1. 결정적 차이 세 가지

### (1) 검증 가능성 — 가장 큰 갈림
지도교수의 "실험이 의미없다"는 지적의 본질은 **모델이 틀렸다가 아니라 검증할 대상이 없다**는 것이다.
- 양식장: 실제 가두리 정상상태 DO장을 잴 방법이 없다 → 우리가 세운 가정을 우리가 시뮬레이션(반증 불가).
- 수조: 경계가 명확하고 우리가 계측 가능 → 모델을 **반증(falsify)**할 수 있다.
→ 이 한 축이 피벗의 최대 논거.

### (2) 이송-확산 방정식의 운명 — 역설적 반전
- 양식장 트랙은 최근 재정립에서 **유속항을 버렸다**(U≈0, ΣS 중심).
- 수조는 펌프·폭기로 **유속이 살아있고 측정 가능** → 이송-확산-반응 완전형이 *필요하면서 검증 가능*.
→ "이송-확산을 제대로 풀고 싶다"면 오히려 수조가 정공법. (원트랙은 유속항을 근사 제거한 상태)

### (3) 시장 포지션 — 임팩트 vs 실현성
- 양식장: 사회적 임팩트는 크나 B2B·현장 접근·검증이 어렵다.
- 수조: 시장은 이미 붐비지만(Dangbei·Aqua AI·FishKeeper.ai 등), **물리기반 DO 공간구배**만은 아무도 안 한다. 5만원 검진기 포지션으로 좁히면 빈칸이 뚜렷.

## 2. 피벗해도 **버리지 않는 공통 자산** (중요)

피벗은 전면 재시작이 아니다. 다음은 그대로 이어진다:

- **이송-확산 / DO 물리 코어** — 도메인만 바뀌고 방정식은 유지(수조에선 유속항 복원).
- **물리 prior + 데이터동화 아키텍처** — 4 Layer의 "예측+희소센서 교정" 원칙이 그대로.
- **어류 표층 행동(gasping)→DO 스트레스** 멀티모달 인식 — 양식 Data Layer의 Gemini 역할이 수조 카메라로 이식.
- **빠른/느린 루프 분리, 안전제어에 LLM 배제** 원칙.
- ΣS 항별 지식(호흡·폭기·질산화) — 수조 ΣS 캘리브레이션에 재사용.

→ 즉 **물리·AI 자산의 8할은 재사용**, 바뀌는 건 도메인 규모·하드웨어·시장 프레이밍.

## 3. 각 트랙이 요구하는 것 (선택 시 감당해야 할 것)

**양식장 유지 시**
- "어디까지 보일 것인가"를 스스로 좁혀 지도교수 지적에 답해야 함.
- 검증 부재를 우회할 논리(논문 대조·정성 타당성) 마련.
- 데모는 시뮬레이션 기반(ROM→데드존→Gemini 설명)에 집중.

**금붕어 수조 피벗 시**
- 실물 제작(센서·카메라·기포기·앱)과 물리 실험 일정이 들어옴 → 담당·예산·수조 스펙 확정.
- DO 실측 기준기(실험실 DO미터) 1대 확보(검증용).
- 레드오션에서 메시지를 "DO 구배 × 물리"로 좁혀야 차별화.
- false-safe(죽어가는데 안전 표시) 방지 = 신뢰성 최우선.

## 4. 팀회의(토) 결정 프레임

세 질문에 팀이 같은 답을 낼 수 있으면 결론이 선다:

1. **우리가 대회에서 "확실히 보일 수 있는 것"은 어느 쪽에서 더 명확한가?**
   (검증 가능성 · 실현성 관점)
2. **사회적 임팩트(양식) vs 완결성·실증(수조) 중 무엇에 베팅하나?**
3. **실물 제작을 감당할 수 있나?** (수조 선택의 전제 — 인력·예산·일정)

보조 판단축: novelty(둘 다 물리기반 DO가 핵심), 팀 역량 정합(둘 다 적합), 성과물 인상(수조=실물 유리).

---

## 5. 요약 한 줄

**양식장은 "임팩트는 크나 증명이 어려운 문제", 금붕어 수조는 "임팩트는 작지만 증명 가능한 문제".**
그리고 물리·AI 코어는 어느 쪽을 골라도 대부분 재사용된다 — 선택의 본질은
**"검증 가능성과 실현성"을 살 것인가, "사회적 임팩트와 스케일"을 살 것인가**이다.
