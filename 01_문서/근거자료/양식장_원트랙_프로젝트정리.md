# 양식장 원트랙 — 프로젝트 정리 (기존 방향)
---

## 1. 한 줄 컨셉

**"유체역학 × Multimodal AI 기반 스마트 양식 최적화 시스템(AquaMind)."**
바다 가두리(cage) 내부의 **용존산소(DO) 분포를 물리모델로 예측하고, 희소 센서로 교정**해
데드존·저산소를 조기경보·표적 개입하는, 고령 소규모 어가용 의사결정 지원 시스템.

## 2. 타깃 · 문제

- **타깃**: 한국 연안의 **소규모·고령 어가**(대형 양식기업이 아닌, AI·자동화 접근성이 낮은 층).
- **문제**: 남해안 양식어류 대량폐사(1998~2016 분석 자료 확보). 저산소·고수온·적조가 반복. 기후변화로 한국 해역 SST 상승이 글로벌 대비 2.6배(FAS 2023).
- **핵심 난점**: 가두리 내부 상태(특히 DO 공간분포)를 **직접 관측하기 어렵다**(표면 카메라만으로는 수중 미관측).

## 3. 핵심 물리 — ΣS 중심 (2026-07-07 재정립)

지배방정식은 이송-확산:

```
∂C/∂t + ∇·(U C) = ∇·(D_eff ∇C) + ΣS
```

**전환의 핵심**: 4×8 배열·10×10×10 m 케이지 + 외부유동 0.3 m/s CFD 결과, **외곽 케이지만 유동 영향, 안쪽 2×6 케이지는 유속 ≈ 0**. 따라서:

- 유속항 ∇·(U C) ≈ 0, 정상상태 ∂C/∂t = 0, 확산항은 완화 역할
- → **정상상태 DO 분포는 사실상 ΣS(소스/싱크 합)로 결정**

```
ΣS = + 표층 재폭기 + 역학적 폭기 − 어류 호흡 − 미생물 소비 − 부착생물 소비 − 기타(SOD·질산화)
```

과제: ΣS 항별 우선순위(정량화 가능성 × DO 기여도 × 제어 가능성) 선정 → 정상상태 ΣS 모델 → 센서 1점을 그린함수 기반 최적보간으로 전 분포 확장.

## 4. 접근 — 4 Layer 아키텍처 (AquaMind)

빠른 루프(물리·규칙·경량분류기, 실시간 안전제어)와 느린 루프(Gemini 추론·설명·보고)를 분리하는 것이 뼈대. **안전제어에는 Gemini를 넣지 않는다.**

| Layer | 빠른 루프 | 느린 루프(Gemini) |
|---|---|---|
| Data | 센서 스트림, 광학유동 | 영상→정형 데이터 변환(멀티모달) |
| AI(핵심) | 물리코어(ROM/Kriging), 데이터동화, 이상탐지 | 멀티소스 근본원인 추론(RAG+롱컨텍스트) |
| Control | 규칙엔진(네트진동·폭기, 2트랙 결합) | 액추에이션 정책 제안(사람 승인) |
| User | Looker Studio 대시보드 | 고령 어가용 일일보고·출하 자문 |

원칙 3가지: ①Gemini를 제어 루프에서 분리 ②표면관측=예측+희소관측 교정(데이터동화) ③2트랙 독립입력+결합 액추에이션(DO→유동장 역추론 ill-posed 회피).

## 5. 캡스톤 제작·데모 범위 (스코핑)

풀 FSI + 전조건 스윕 + ROM + LLM + 액추에이터를 2학기에 다 만드는 건 과대범위. 좁은 작동 데모 우선.

- **중간발표(8월)**: 대표 가두리 1형상 + 축소 조건집합 → **ROM → 데드존 예측 → Gemini 설명** 작동 데모.
- **최종/확장**: 풀 조건 스윕, 액추에이터 실증, ADCP 현장 캠페인은 "향후 과제".
- 물리 시드: 팔각기둥 가두리 항력계수(Cd≈1.37~1.76), 넙치 사육밀도·성장곡선(Animals 2023) 등 논문 실측 추출.

## 6. 시장 · 명분

- 양식은 국가 식량·수출 산업. 폐사 저감 = 직접적 경제효과(경영 파트가 비용절감·폐사저감 정량화).
- 공백 타깃: AQUA·AquaGPT 등이 "소규모 토착 양식 문헌 희소 → 일반 권고로 후퇴"한 바로 그 지점(한국 소규모 고령 어가).

## 7. 차별화 / Novelty

- **유체역학 코어 위의 추론 계층**: 기존 스마트양식 AI가 비워둔 "물리모델 + LLM 추론"의 결합.
- **물리 prior + 데이터동화**: 미관측 수중을 CFD 예측 + 희소 센서 교정으로 복원.
- ΣS 기반 정상상태 DO 해석: 유속을 못 구한 게 아니라 **무시가능함을 증명**하고 소스항으로 무게중심 이동.

## 8. 리스크 · 미결 (지도교수 지적 포함)

- **범위 광범위**: 지도교수 지적. "어디까지 보일 것인가"가 불명확(2026-07-07 미팅).
- **검증 가능성**: 실제 바다 가두리에 센서·계측 접근 불가 → 정상상태 DO장 **ground truth 부재**. "실험이 의미없다"는 지적의 본질.
- **조건 조합 폭발·비정상성·표면-only 가관측성** 등(검증 보고서 한계 1~6).
- 강점: **4 Layer 구조·기술 스택은 지도교수가 감탄, 건드리지 않겠다고 함.**
