# 이송-확산-반응 방정식 — 개념 정리 및 유도

> 팀명: 漁벤져스 · 팀 공유용 레퍼런스
> 목적: 용존산소(DO) 분포를 지배하는 이송-확산-반응 방정식을 개념부터 유도까지 정리한다.
> 대상: 전공 불문 팀 전원(기계·SW·경영). 기계(유체) 전공이 이미 배운 "열전달 에너지 방정식"과 같은 식임을 강조한다.

## 0. 한 줄 요약

이송-확산-반응 방정식은 **"어떤 양(C)이 흐름에 실려 이동(이송)하고, 농도 차로 퍼지고(확산), 내부에서 생기거나 없어지는(반응) 과정"의 질량보존 법칙**이다.
열전달의 에너지 방정식에서 온도 T 자리에 농도 C를 넣은 것과 완전히 같은 구조다.

```
∂C/∂t + ∇·(U C) = ∇·(D ∇C) + S
 (축적)   (이송)     (확산)      (반응)
```

---

## 1. 개념 — 세 개의 항이 뜻하는 것

대상량 C(x, y, z, t) = 관심 스칼라의 농도. 여기서는 **용존산소 농도** [kg/m³ 또는 mg/L].

| 항 | 이름 | 물리적 의미 | 익숙한 비유 |
|---|---|---|---|
| ∂C/∂t | 축적(비정상) | 한 점에서 시간에 따른 농도 변화율 | 통장 잔액의 변화 |
| ∇·(U C) | 이송(advection) | 유체가 C를 **통째로 실어 나름**. 방향성 있음 | 강물이 잉크를 하류로 밀고 감 |
| ∇·(D ∇C) | 확산(diffusion) | 농도 높은 곳→낮은 곳으로 **저절로 퍼짐**. 방향성 없음(등방) | 커피에 우유가 번짐 |
| S (= ΣS) | 반응(source/sink) | 그 자리에서 C가 **생기거나(+) 소모됨(−)** | 산소가 광합성으로 생기고 호흡으로 사라짐 |

**이송 vs 확산의 결정적 차이**
- 이송은 유속 U가 있어야 하고 **방향**을 가진다(쌍곡형, 이동).
- 확산은 유속이 없어도 일어나며 농도 구배만 있으면 **모든 방향으로 뭉갠다**(포물형, 평활화).
- 이 둘은 서로 대체되지 않는 별개의 수송 메커니즘이다. → 뒤의 페클레 수(§6)가 둘의 상대적 크기를 판정한다.

## 2. 기계공학 전공이 이미 아는 식 (개념 연결)

이 방정식은 새로운 것이 아니다. 열전달·유체역학에서 배운 식이 같은 틀이다.

**열전달 — 에너지 방정식 (온도 T의 이송-확산)**
```
∂T/∂t + U·∇T = α ∇²T + (열원)
```
→ T ↔ C, 열확산도 α ↔ 물질확산계수 D. 유속 U=0이면 순수 열방정식 ∂T/∂t = α∇²T.

**유체역학 — Navier-Stokes 운동량 방정식 (운동량의 이송-확산)**
```
∂U/∂t + U·∇U = ν ∇²U − (1/ρ)∇p + f
```
→ `U·∇U` 이송항, `ν∇²U` 확산(점성)항. 자기 자신을 이송해서 비선형일 뿐 구조는 동일.

결론: **DO 방정식 = 열전달 에너지 방정식의 "온도" 자리에 "용존산소"를 넣고, 반응항 ΣS를 붙인 것.**

## 3. 유도 — 검사체적 질량보존에서 출발

### 3-1. 보존 법칙의 서술

공간에 고정된 임의의 검사체적 V(표면 A)를 생각한다. V 안의 C 총량이 변하는 이유는 딱 두 가지뿐이다.

```
(V 안 C의 시간변화율) = − (표면 A를 통해 빠져나가는 순 유출) + (V 안에서 생성)
```

적분식으로:
```
d/dt ∫_V C dV = − ∮_A J·n dA + ∫_V S dV
```

- J : 총 질량 플럭스 벡터 [kg/(m²·s)] — 단위면적·단위시간당 지나가는 C의 양
- n : 표면 바깥 법선 단위벡터
- S : 단위체적·단위시간당 생성률(반응항)

### 3-2. 플럭스 J를 두 성분으로 나눈다

**(a) 이송 플럭스** — 유체가 속도 U로 C를 실어 나른다.
```
J_adv = U C
```

**(b) 확산 플럭스** — Fick의 제1법칙. C는 농도가 높은 쪽에서 낮은 쪽으로 흐르며, 그 세기는 구배에 비례한다.
```
J_diff = − D ∇C      (음(−)부호: 구배 반대방향으로 흐름)
```
> Fick 법칙은 열전달의 Fourier 법칙(q = −k∇T), 전기의 Ohm 법칙과 같은 형태의 "구배-구동 흐름" 법칙이다.

따라서 총 플럭스:
```
J = J_adv + J_diff = U C − D ∇C
```

### 3-3. 발산정리로 부피적분으로 환원

표면적분을 부피적분으로 바꾼다(발산정리):
```
∮_A J·n dA = ∫_V (∇·J) dV
```

검사체적 V가 고정이므로 시간미분을 적분 안으로:
```
d/dt ∫_V C dV = ∫_V (∂C/∂t) dV
```

대입하면:
```
∫_V (∂C/∂t) dV = − ∫_V (∇·J) dV + ∫_V S dV
```

이 식이 **임의의** V에 대해 성립해야 하므로, 피적분함수끼리 같아야 한다:
```
∂C/∂t = − ∇·J + S
```

### 3-4. J를 대입 → 보존형(divergence form)

```
∂C/∂t + ∇·(U C) = ∇·(D ∇C) + S       ······ (보존형)
```

이것이 이송-확산-반응 방정식의 **완전한 형태**다.

### 3-5. 비압축 가정 → 이송형(advective form)

비압축성 유동에서는 연속방정식이 ∇·U = 0. 이송항을 전개하면:
```
∇·(U C) = U·∇C + C(∇·U) = U·∇C        (∵ ∇·U = 0)
```

따라서:
```
∂C/∂t + U·∇C = ∇·(D ∇C) + S           ······ (이송형)
```

확산계수 D가 상수이면 ∇·(D∇C) = D∇²C 이므로 가장 단순한 형태:
```
∂C/∂t + U·∇C = D ∇²C + S
```

> 참고: **보존형(∇·(UC))** 은 수치해석(유한체적법)에서 질량보존을 정확히 지켜 선호되고,
> **이송형(U·∇C)** 은 해석적 이해에 편하다. 둘은 비압축 조건에서 수학적으로 동등하다.

## 4. 확산계수 D는 어디서 오나 — 분자확산 vs 난류확산

§3의 D는 원래 **분자확산계수**(브라운 운동 수준, 물속 산소는 D_m ≈ 10⁻⁹ m²/s로 극히 작음)다.
그러나 실제 수체에서는 난류가 훨씬 강하게 섞는다. 이를 유도로 보이면:

**Reynolds(앙상블) 평균**: 순간값을 평균+요동으로 분해.
```
C = C̄ + C',    U = Ū + u'
```
보존형에 대입해 평균하면(평균의 성질 이용):
```
∂C̄/∂t + ∇·(Ū C̄) + ∇·⟨u'C'⟩ = ∇·(D_m ∇C̄) + S̄
```
새로 나온 항 `⟨u'C'⟩` = **난류 스칼라 플럭스**(요동이 만드는 추가 수송). 이를 구배-확산 가정으로 닫는다:
```
⟨u'C'⟩ = − D_t ∇C̄        (D_t = 난류확산계수)
```
정리하면:
```
∂C̄/∂t + ∇·(Ū C̄) = ∇·(D_eff ∇C̄) + ΣS,     D_eff = D_m + D_t
```

**핵심 결론**: 평균 방정식의 확산계수는 **유효확산계수 D_eff = 분자확산 + 난류확산**이다.
수체에서는 D_t ≫ D_m 이므로 사실상 난류(그리고 우리 문제에서는 물고기 유발 요동)가 D_eff를 지배한다.

## 5. 우리 문제로의 축약 (DO 분포)

위 평균 방정식이 프로젝트의 출발점이다.
```
∂C̄/∂t + ∇·(Ū C̄) = ∇·(D_eff ∇C̄) + ΣS
```

단계별 단순화:

**(1) 정상상태** — 장시간 평균 분포에 관심 → 시간항 소거:
```
∇·(Ū C̄) = ∇·(D_eff ∇C̄) + ΣS
```

**(2) 내부 케이지(유속 무시 조건, 국소 Pe ≪ 1)** — 평균 이송항 소거:
```
0 = ∇·(D_eff ∇C̄) + ΣS         (정상상태 확산-반응, 타원형 경계값 문제)
```

**(3) 외곽 케이지** — 외부 유동의 영향으로 이송 유지 → (1)의 형태 그대로.

> 즉 하나의 방정식이 **공간적으로** 갈린다. 외곽은 이송+확산+반응, 코어는 확산+반응.
> 어디가 어느 영역인지는 §6의 국소 페클레 수 Pe(x)로 판정한다.

ΣS(용존산소 반응항)의 구체적 구성은 별도 문서 참조:

## 6. 무차원화 — 페클레 수와 담쾰러 수

방정식의 각 항 크기를 비교하려면 무차원화한다. 대표 길이 L, 대표 유속 U_0, 확산계수 D, 반응률 k.

**이송항 크기** ~ U_0 · C_0 / L
**확산항 크기** ~ D · C_0 / L²

두 항의 비 = **페클레 수(Péclet number)**:
```
Pe = (이송) / (확산) = U_0 · L / D_eff
```
- Pe ≫ 1 : 이송 지배 (흐름이 세게 밀고 감 → 외곽 케이지)
- Pe ≪ 1 : 확산 지배 (섞임만 남음 → 내부 케이지, ΣS 문제)
- Pe ≈ 1 : 둘 다 중요 (전이영역)

**반응이 얼마나 중요한가 = 담쾰러 수(Damköhler number)**:
```
Da = (반응률) / (수송률) = k·L²/D_eff   (확산 대비)   또는   k·L/U_0   (이송 대비)
```
- Da ≫ 1 : 반응이 빨라 수송이 못 따라감(국소 소스/싱크가 분포를 지배)
- Da ≪ 1 : 수송이 빨라 잘 섞임

> 실무 팁: CFD로 얻은 **잔류 평균유속 U_0**와 추정 **D_eff**를 넣어 Pe(x) 맵을 그리면,
> "이송을 무시해도 되는 영역"을 숫자로 정당화할 수 있다. 이게 유속항 근사의 방어 논리 핵심.

## 7. 경계조건 (문제를 닫으려면 필수)

확산이 있는 방정식(포물형/타원형)은 경계조건이 있어야 유일해가 정해진다.

| 종류 | 형태 | DO 문제에서의 예 |
|---|---|---|
| Dirichlet (1종) | C = C_s (값 고정) | 표층에서 포화 용존산소 농도로 고정 |
| Neumann (2종) | −D ∂C/∂n = q (플럭스 고정) | 바닥의 저서산소요구(SOD), 표층 재폭기 플럭스 |
| Robin (3종) | −D ∂C/∂n = h(C − C_∞) | 계면 물질전달(기체교환)처럼 값·플럭스 혼합 |

## 8. 방정식의 수학적 성격 (수치해석 시 주의)

- **확산 포함** → 포물형(비정상)·타원형(정상) PDE. 매끄러운 해, 안정적.
- **순수 이송(확산 무시)** → 쌍곡형 PDE. 특성곡선(characteristics)을 따라 정보가 전달됨. 불연속(충격)이 유지됨.
- 이송이 강한(Pe 큰) 문제를 단순 중심차분으로 풀면 **수치진동**이 생긴다 → **풍상차분(upwind)** 등 안정화 기법 필요.

참고 교재: Versteeg & Malalasekera, *An Introduction to CFD: The Finite Volume Method* (convection-diffusion 이산화 장).

## 9. 용어·기호 정리

| 기호 | 의미 | 단위(예) |
|---|---|---|
| C, C̄ | 농도(용존산소), 그 평균 | kg/m³, mg/L |
| U, Ū | 유속벡터, 그 평균 | m/s |
| u', C' | 유속·농도의 난류 요동 | — |
| D_m | 분자확산계수 | m²/s (물속 O₂ ≈ 10⁻⁹) |
| D_t | 난류확산계수 | m²/s (D_m보다 훨씬 큼) |
| D_eff | 유효확산계수 = D_m + D_t | m²/s |
| S, ΣS | 반응(생성/소멸) 항의 합 | kg/(m³·s) |
| Pe | 페클레 수 = U·L/D | 무차원 |
| Da | 담쾰러 수 = 반응/수송 | 무차원 |
