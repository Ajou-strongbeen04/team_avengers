## 0. 이 문서의 위치

방법론(`02_방법론.md`)의 **2단계(저가제품)** — 프록시 센서 + 카메라 + 물리로 DO 장을 재현하는 디바이스 — 중 **관측 하드웨어(프로브)**의 기구·전장 설계 사양이다. 본 프로브의 프록시 센서는 **수온·탁도 2종으로 한정**한다(TDS 등 여타 프록시 제외). 물리 엔진(지배방정식·BC·소스닫음)은 `03_논문/`이 단일 진실원이며 본 문서는 이를 **관측하는 장치**만 다룬다.

핵심 관측 요구: 단일 센서가 못 보는 **저산소역(최원코너 저층)의 프록시 신호**를 침입 최소로 계측 → 물리·ROM 입력으로 전달.

## 1. 설계 요구사항 (Requirements)

| # | 항목 | 요구 | 근거·비고 |
|---|---|---|---|
| R1 | 프로브 직경 | **Φ10 mm 내외 (OD)** | 사용자 확정. 침입성(유동교란) 최소화 — `../../03_기계.md` §7 intrusiveness |
| R2 | 형상 | **벽걸이(∩) — 상단 보드부 + 하향 센서 프로브** | 스케치 좌측(측면)·우측(단면) 대응. HOB(hang-on-back)형 |
| R3 | 수온센서 | **DS18B20 방수 프로브 [확정]** | 스테인리스 캡 Φ6 mm급, 3선 케이블. Φ10 mm 관 내부 삽입 |
| R4 | 탁도센서 | **IR(적외선) 방식 [미정·모듈 분리]** | 별도 광학 연구 진행 중 → 스왑 가능한 독립 모듈로 격리 |
| R5 | 센서 범위 | **수온·탁도 2종만** | TDS/EC 등 여타 프록시 제외(설계 단순·프로브 세경 유지) |
| R6 | 전원 | **배터리 [미정]** | 보드쪽 레그 내장. 후보·전력예산 §5 |
| R7 | 통신·연결 | **상단 보드=MCU, 유선 케이블로 프로브 연결** [확정] | 사용자 확정. 무선(WiFi/BLE)으로 앱 전송은 상단부에서 |
| R8 | 방수 | 센서 프로브 IP68(수중 상시), 보드부는 수면 위 dry | 수선(waterline)이 보드/센서 경계 |
| R9 | 배치 정합 | 프로브축이 장착벽에서 ≈0.035 m, 침지 z≈0.02–0.21 m | `상수_목록.md` D·E군. **플룸(Φ20 mm) 밖**에 두어 저산소역 계측 |
| R10 | 유지보수 | 탁도 모듈·배터리 교체/세척 용이 | 광학창 오염(생물막) 세척 고려 |

**설계 철학:** 물리적으로 젖는 부분(센서 프로브)과 마른 부분(MCU·배터리)을 **수선을 경계로 물리 분리**하고, 아직 미확정인 두 요소(**IR 탁도**, **배터리**)를 각각 독립 모듈·독립 베이로 빼서 나머지 설계를 먼저 동결(freeze)한다.

## 2. 시스템 아키텍처

스케치 대응: 좌측 그림은 **측면도**(상단 보드 = 가로 박스, 센서 = 하향 가는 관), 우측 그림은 **두 레그의 단면**(보드쪽=배터리, 센서쪽=온도/탁도/탐침).

```
          ┌───────────────┐  ← 상단 브릿지 (수조 테두리에 걸침, dry)
          │  MCU + 무선   │     · MCU / WiFi·BLE / 충전·전원관리
          │  (PCB)        │     · 케이블 글랜드(방수 관통)
          └──┬─────────┬──┘
   [보드쪽 레그]      [센서쪽 레그]
   (수면 위, dry)      (수중, wet, IP68)
   ┌────────┐         ┌────────┐  ← waterline ≈ z=0
   │        │         │  ▓▓▓▓  │   온도(DS18B20 팁 근처 상단 배선)
   │ 배터리 │         │  ┊IR┊  │   ← IR 탁도 광학존 (모듈·분리, 스케치 빨간 점선)
   │ [미정] │         │  ▓▓▓▓  │
   └────────┘         │   ▽    │   ← DS18B20 스테인리스 팁 (최저점 = 저산소역 계측)
    Φ TBD             └────────┘
                       Φ10 mm
```

- **보드쪽 레그(dry):** 배터리 베이. 수면 위에 위치하므로 방수 요구 낮음(생활방수). 배터리 미정이라 **치수 가변 베이**로 설계.
- **센서쪽 레그(wet, Φ10 mm):** 프록시 센서 스택. 상시 수중 → IP68 완전 밀봉/포팅. **이 관이 R1(Φ10 mm)의 대상.**
- **상단 브릿지:** MCU·무선·전원관리 PCB. 수조 테두리에 걸치는 후크 형상. 양 레그로 가는 배선의 방수 관통(케이블 글랜드).
- **연결:** 센서쪽 프로브의 센서 신호선은 프로브 상단 → 브릿지 내부 케이블 → MCU (유선, R7).

> **왜 U자 2-레그인가:** ① 배터리(무거움·미정 치수)를 젖지 않는 쪽에 두어 방수 난이도와 무게를 분리, ② 센서 프로브를 최대한 가늘게(Φ10) 유지, ③ 벽걸이 폭기와 같은 장착 기준(장착벽 이격 0.035 m)으로 프로브를 저산소역 좌표에 재현성 있게 위치(R9).

## 3. 기구 설계 (Mechanical)

### 3.1 전체 치수 (초안, 수조 47×21×21 cm 기준)

| 부위 | 치수(초안) | 산출 근거 |
|---|---|---|
| 센서 프로브 OD | **Φ10 mm** | R1 확정 |
| 센서 프로브 벽두께 | 1.0 mm (ID ≈ Φ8 mm) | 내부 부품 수용 + 강성 |
| 센서 프로브 침지 길이 | **≈ 200 mm** | 수심 0.21 m 전층 커버, 팁이 z≈0.19–0.20 m 저층 도달 (`상수_목록.md` E군) |
| 브릿지 테두리 걸침 | 유리두께 6–12 mm 대응 후크 | 일반 가정 어항 테두리 |
| 장착벽↔프로브축 | **35 mm** | `상수_목록.md` Ω_air: 벽걸이 축 0.035 m 이격과 동일 기준 |
| 보드쪽 레그 | 폭 TBD(배터리 종속) | §5 배터리 확정 후 |

> 프로브 팁은 **폭기 플룸(원기둥 r_p=0.01 m=Φ20 mm, 축이 장착벽 0.035 m) 밖**에 두어야 저산소역을 본다. 프로브를 최원코너 방향으로 오프셋 배치 → 플룸 상승류에 직접 노출되지 않게 함(R9).

### 3.2 Φ10 mm 센서 프로브 내부 배치 (bottom-up)

Φ8 mm 내경에 아래→위 순으로 적층:

1. **최하단 — DS18B20 팁:** 스테인리스 캡을 프로브 바닥에 노출(또는 열전도 충진재로 벽 접촉). 최저점 수온 = 저산소 위험판정(§8, 수온↑=저산소)에 직결.
2. **중단 — IR 탁도 광학존 [모듈·분리]:** 스케치의 빨간 점선 구간. 광학창(투명) 또는 개방 슬롯. 상세 §4.2.
3. **상단 — 배선 정리·케이블:** 3선(DS18B20) + IR 탁도 모듈 배선(≤4선)만 묶어 브릿지로 상향.
4. **팁 근처 배수/유동 슬롯(선택):** 정체수 갇힘 방지, 실제 본류 시료 유입.

> 센서는 **수온·탁도 2종으로 확정**(R5). Φ8 mm ID에 두 계통 배선만 통과하므로 예비 채널 여유가 커 밀봉·정렬이 단순해진다.

**적층 간섭 검토:** DS18B20 방수 프로브(Φ6 mm) + IR 소자(Φ3 mm 리드 LED 또는 SMD) 를 Φ8 mm ID에 세로로 나눠 배치하면 반경 간섭 없음. 단, **광학존과 온도 팁은 축방향으로 분리**(같은 높이에 두면 온도 프로브가 IR 광로를 가림). → 온도는 최하단, IR은 그 위 별도 구간.

### 3.3 상단 보드부 (dry)

- MCU 후보: ESP32 계열(WiFi/BLE 내장, 초저가, 1-Wire·ADC 지원) — R7 무선전송에 부합. *[제안·미확정, SW팀 협의]*
- 전원관리: 배터리 충전 IC + LDO/벅. 배터리 §5 확정 후 상세.
- 방수: 상단부는 수면 위 dry이나, 결로·물튐 대비 생활방수(IP54급) 하우징 권장.

### 3.4 브릿지·케이블 경로

- 수조 테두리 후크: 무게중심이 안쪽(센서쪽)으로 쏠리지 않게 배터리 무게로 균형. 필요시 반대편 카운터웨이트/클램프.
- 케이블 관통부는 **글랜드 또는 포팅**으로 방수. 센서쪽 관통부는 수선 근처이므로 IP등급 유지.

## 4. 센서 서브시스템

### 4.1 수온 — DS18B20 방수 프로브 **[확정]**

| 항목 | 값 |
|---|---|
| 부품 | DS18B20 방수 프로브 (스테인리스 캡 Φ≈6 mm, 케이블형) |
| 인터페이스 | 1-Wire (DQ 1선 + VDD + GND, 3선). 기생전원 시 2선 가능 |
| 전원 | 3.0–5.5 V |
| 분해능 | 9–12 bit (0.0625 °C @12 bit), ±0.5 °C(-10~85 °C) |
| 장착 | 프로브 최하단, 캡 수중 노출. 케이블은 관 내부 상향 → 브릿지 → MCU 1-Wire 핀 |
| 역할 | 운전 수온 T 실측 → C*(T)·k_L(T)·R_bio(T) 등 온도종속항 확정(`03_논문` §3, `../../03_기계.md` §10) |

> 수온은 물리 엔진의 온도종속 계수를 전부 구동하는 1순위 프록시. 룩업(담수·1 atm): 18–28 °C에서 C*≈9.5→7.8 mg/L로 감소 → **수온만으로도 저산소 위험의 큰 부분을 설명**(`../../03_기계.md` §10).

### 4.2 IR 탁도 센서 **[미정 · 모듈·분리]**

> **의도적으로 분리:** 적외선 기반 탁도 연구가 별도 진행 중 → 본체 설계를 막지 않도록 **독립 스왑 모듈**로 격리. 아래는 인터페이스·기구 제약만 동결하고, 광학 방식·부품은 연구 결과로 후속 확정.

**동결하는 인터페이스 제약 (모듈이 지켜야 할 경계):**

- 물리 봉입: Φ8 mm ID 내 **광학존 구간**(축방향 길이 TBD, 예 15–25 mm)에 수용.
- 전기 IF: 전원(3.3/5 V) + 아날로그 또는 디지털(I²C 권장) 신호선 ≤ 4선.
- 광학창: IR 투과 재질 필요(투명 PC/아크릴/유리). 창 오염(생물막) 세척 접근성(§4.4 유지보수).
- 교체성: 온도 프로브·배터리와 독립적으로 탈착.

**후보 방식 (연구용 트레이드오프 — 확정 아님):**

| 방식 | 배치 | 장점 | 유의 |
|---|---|---|---|
| 투과형(Transmission) | IR LED ↔ 포토다이오드 180° 대향, 광로에 시료 갭 | 구조 단순, 저농도 민감 | Φ10 관에 대향 정렬 공간 빠듯, 고탁도 포화 |
| 산란형(Nephelometric 90°) | LED와 검출기 90° | ISO 7027 표준 부합, 고탁도 선형 | 90° 배치가 Φ8 ID에 기구적으로 어려움 |
| 후방산란(Backscatter) | LED·검출기 동일면 | 소형·단면 배치 → **Φ10 관에 유리** | 교정 곡선 필요 |

> 파장은 통상 IR 근처(예 ~860 nm, ISO 7027 계열)를 검토 대상으로 두되 **연구에서 확정**. 본 사양서는 “후방산란형이 Φ10 mm 봉입에 기구적으로 가장 유리”라는 점만 설계 힌트로 남긴다.

### 4.3 유지보수·오염 관리

- 광학창·전극은 생물막(biofouling)으로 드리프트 → **세척 가능한 슬라이드 모듈** 또는 창 노출 구조.
- 2점 보정·교차보정 절차는 `../../03_기계.md` §7(이동·고정 프로브 교차보정) 계승.

## 5. 전원 — 배터리 **[미정]**

> 배터리는 보드쪽 레그(dry)에 **치수 가변 베이**로 두고, 아래 요구·후보를 확정 후 베이 치수를 동결한다.

**요구:**

- 공급: MCU(ESP32급, 무선 전송 시 순간 피크 큼) + 센서(DS18B20·IR) 구동.
- 위치: 수면 위 dry → 방수 부담 낮음, 무게는 브릿지 균형에 영향.
- 안전: 리튬계 사용 시 보호회로(PCM)·충전 IC 필수.

**개략 전력예산 (확정 아님, 규모감):**

| 블록 | 활성 전류(개략) | 비고 |
|---|---|---|
| ESP32 무선 송신 피크 | ~150–250 mA (순간) | duty-cycle로 평균 억제 |
| ESP32 유휴/딥슬립 | mA~µA급 | 측정 주기 사이 딥슬립 |
| DS18B20 변환 | ~1 mA(변환 시), 대기 µA | 저부하 |
| IR 탁도(LED 펄스) | LED 수십 mA(펄스) | 펄스 구동으로 평균↓ |

> 측정 주기(예: 수 분마다 계측+송신, 나머지 딥슬립)로 평균 소비를 낮추면 소형 셀로도 장기 구동 가능. **주기·목표 구동시간을 정하면 용량(mAh) 역산 → 셀 선정.**

**후보 (베이 치수 영향):**

| 후보 | 특징 | 베이 영향 |
|---|---|---|
| 18650 리튬이온 1셀 | 3.7 V, 2000–3500 mAh, 흔함·저가 | Φ18×65 mm — 레그가 굵어짐 |
| LiPo 파우치 | 형상 자유, 얇게 가능 | 보드쪽 레그를 납작하게 설계 가능 |
| AA×2~3 (교체형) | 충전회로 불필요, 유지보수 간단 | 홀더 부피 |

> **결정 필요:** 목표 구동시간 + 충전(USB) vs 교체 방식 → 후보 택1 후 보드쪽 레그 치수 동결(§3.1 TBD 해소).

## 6. 방수·밀봉 설계

| 구역 | 등급 | 방법 |
|---|---|---|
| 센서 프로브(수중 상시) | IP68 | 관 밀봉 + 내부 에폭시 포팅. DS18B20 팁은 자체 방수, 관통부 실링 |
| IR 광학창 | 방수 + IR투과 | 창 접합부 O-ring/접착 밀봉, 광학 성능 유지 |
| 브릿지 케이블 관통 | IP67+ | 케이블 글랜드 또는 포팅 |
| 상단 보드부(dry) | IP54급 | 생활방수 하우징(결로·물튐 대비) |

- **포팅 주의:** IR 광학존은 포팅 수지가 광로를 가리지 않게 국소 마스킹. 온도 팁은 열응답 위해 과도한 단열 포팅 회피(열전도 충진).
- 수선 표시: 프로브에 침지 깊이 마킹(재현성 있는 z 위치, R9).

## 8. 전개 위치·물리 정합

- 프로브축: 장착벽 이격 **0.035 m**(벽걸이 폭기와 동일 기준, `상수_목록.md` D군) → 위치 재현성.
- 침지: z≈0.02–0.20 m, 팁이 **최원코너 저층**(저산소역 1순위, `../../03_기계.md` §7, EX2 13지점 격자의 최원코너 저층)에 근접하도록 최원코너 방향 오프셋.
- 계측→판정: 수온 T(확정 프록시) → 온도종속항 → **위험판정 = 시간평균 DO장의 공간 최저값**(`../../03_기계.md` §6 시간성 규약). 프로브는 “계기판 경고등” 입력(위험/안전 판정용 프록시)이지 DO 절대장 직접계측이 아님(물리·ROM이 장을 재현).
- 침입성: Φ10 mm·배선 최소화로 인공 정체역 생성 억제(`../../03_기계.md` §7).

## 10. 미결 사항 (다음 단계)

1. **배터리 확정** — 목표 구동시간·충전(USB) vs 교체 → 후보 택1 → 보드쪽 레그 치수 동결.
2. **IR 탁도 모듈** — 광학 방식(후방산란 유력)·파장·부품 연구 확정 → 광학존 축방향 길이·창 규격 동결.
3. **MCU 확정** — SW팀과 ESP32 계열/핀맵/무선 프로토콜 협의(R7).
4. **CAD 착수** — 위 3개 동결 후 Φ10 mm 프로브·2-레그 브릿지 3D 모델링·간섭검토·프린트 시제.
5. **침지 위치 검증** — 프로브 오프셋이 플룸 밖·최원코너 저층에 오는지 CFD 좌표(`상수_목록.md`)와 대조.

> **동결 전략:** 확정된 것(Φ10 mm 프로브·DS18B20·유선·벽걸이 2-레그)으로 기구 골격을 먼저 굳히고, 미정 2요소(배터리·IR 탁도)는 각각 독립 베이/모듈로 빼서 병렬 진행 → 상호 대기 없이 설계 진척.
