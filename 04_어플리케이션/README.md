```
[사진 1장] ──(EX3/기하인식, VLM)──▶ 기하·BC 서술자(JSON)
                                        │
[프록시 센서: 온도·pH·TDS·탁도] ────────┤
                                        ▼
                    (EX3: 기하인식 → A층 → B층) ──▶ 저산소 확률맵
                                        │
[빅데이터 건강도] ───(03 어류건강도)────┤
                                        ▼
                          위험 / 안전 / 건강 판정 + 배치 처방
```

핵심 원칙(`../04_소웨.md` §1): 단일 센서(점)의 한계를 사진(전역)과 물리(구배 예측)로 메운다.
최우선 신뢰성 요건 = **false-safe 방지**(죽어가는데 "안전"으로 뜨는 것).

## 인터페이스 계약

- **03_어류건강도 → EX3 B층**: 어종별 저산소 임계 $C_\text{crit}$ 를 공급. 데이터셋은 임계-무관 원장이라 어종 추가 시 재생성 불필요.

## 데모 규격 (CFD와 동일)

- 수조: **47 × 21 × 21 cm ≈ 20.7 L** (`../03_논문/Experiment/상수_목록.md` 기준)
- 인식 대상: 물고기(마릿수·크기), 바위·장식물, 수생식물, 기포기/여과기 토출 위치
- 인식 결과가 ROM의 **경계조건·소스항 위치**($\Omega_\text{air}$, $\Omega_\text{filter}$, $\Omega_\text{fish}$)로 들어간다.
