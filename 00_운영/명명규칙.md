# 파일·폴더 명명규칙 (漁벤져스)

> 확정 2026-08-03. 결정 근거·선택지는 `명명규칙_결정목록_20260803.md`.
> **적용 제외 구역**: `_archive/` · `01_문서/근거자료/` · `01_문서/미팅_20260707/` · `01_문서/제출용_서식/`(대회 서식 원본).
> OpenFOAM 케이스 폴더(`0/`, `constant/`, `system/`, `processor*/` 등)는 솔버 규약이라 적용 제외.

---

## 1. 언어 (D01)

- 최상위 폴더·문서 폴더 = **한글**
- 코드/실행 폴더 = **영문** (`scripts`, `dataset`, `batch`, `pilot`, `template`, `firmware`, `flow`, `out`)
- **고정 예외**: `03_논문/Experiment/`, `03_논문/References/` — 논문 산출물·스크립트 경로에 깊게 박혀 있어 영문 그대로 둔다

## 2. 번호 접두사 (D02·D03)

- 읽는 순서가 있는 **문서 묶음**에만 번호를 붙인다 (`01_축소모델설계.md`, `02_A층_유동대리모델.md` …)
- 폴더 번호는 **최상위(`00_`~`05_`)에만**. 하위 폴더는 번호를 붙이지 않는다
  - 기존 예외: `03_논문/제출용/00_전략`~`04_그림_및_표` (투고 절차 순서라 유지)
- 자릿수는 **2자리 고정**. 중간에 끼울 때는 `05a_` 로 붙이고 **뒤 번호를 다시 매기지 않는다**

## 3. 날짜·기간 (D04·D05)

- 날짜는 **`YYYYMMDD`**, 위치는 **항상 접미**: `진행상황_타임라인_20260803.md`, `미팅_20260804/`
- 기간은 **`YYYYMMDD-YYYYMMDD`**: `활동보고서_1주차_20260704-20260710.docx`
- `~`, `2026-07-07`, `0707` 표기는 쓰지 않는다

## 4. 버전 (D06)

- **현행본(정본)에는 버전을 붙이지 않는다.** 정본 파일명이 바뀌면 링크가 깨지기 때문
- 과거본만 접미 `_v1`, `_v2`: `논문_초안_v2.md`
- 확정 전 설계안은 `이름_v3` 처럼 접미로: `논문_골격_v3.md`
- **보류 항목**: `GCP` ↔ `GCP_v2`, `firmware/demo_v1` ↔ `demo_v2` 는 구·현행 판정이 안 돼 있어 그대로 둔다. 담당자가 어느 쪽이 죽었는지 정하면 그때 정리한다

## 5. 폐기·보관 (D07·D08)

- 보관은 **`_archive/` 로 이동** 하나로 통일. 폴더명은 **`<이름>_폐기YYYYMMDD`**
- 제자리 보관 금지: `.bak_*`, `_backup`, `(구)`, `_DELETE_LOCALLY`, 언더스코어 접두 폴더
- 동기화 충돌 사본(`0 2/`, `postProcessing 2/`)은 즉시 `_archive/중복사본_폐기YYYYMMDD/` 로
- `_archive/` **내부는 원형 보존** — 이 규칙도, 용어 통일도 적용하지 않는다

## 6. 공백·문자 (D09)

- 파일·폴더명에 **공백 금지**. 언더스코어(`_`)로 붙인다
- 괄호 `()`, `~` 금지
- **예외**: `01_문서/제출용_서식/` 안의 대회 서식 원본, 그리고 대회에 그대로 내는 서류 파일명

## 7. 대소문자 (D10)

- **고유약어만 대문자**: `EX`, `CFD`, `ROM`, `GCP`, `ML`, `DO`, `VLM`, `CNN`, `POD`, `STL`
- 일반 폴더·스크립트는 **소문자**: `scripts`, `dataset`, `mac워치독`, `patch_cloudshell_spot전환.sh`
- 첫글자만 대문자(`Experiment` 꼴)는 쓰지 않는다 — 1절의 고정 예외 둘만 남는다
- **주의**: macOS/OneDrive는 대소문자를 구분하지 않는다. 대소문자만 바꾸는 개명은 반드시 임시 이름을 거쳐 2단계로 한다

## 8. README (D11)

- 폴더 안내 문서는 **폴더당 `README.md` 하나**
- 실행 절차 문서는 `실행_*.md` 로 분리: `실행_CNN_로컬.md`, `실행_cfd-pilot전환.md`
- `README_배치.md`·`QUICKSTART_*` 같은 변형은 쓰지 않는다

## 9. 실험 ID (D12)

- 실험 폴더는 **`EX1`, `EX2`, `EX3`** — 부제는 폴더명이 아니라 안의 문서명에 쓴다
- 어느 실험에 종속된 곁가지 검증은 **`EX2_X1`~`EX2_X5`** 꼴 (`EX2_예외검증/` 아래). 번호는 개설 순서
- `EX_exception`, `실험1`, `EX3_ROM` 표기는 폐기

## 10. 실험 문서 (D13)

- 실험 폴더마다 **`EXn_방법론.md`**, **`EXn_결과.md`** 를 고정 이름으로 둔다
- 그 외 부속 문서는 자유 (`EX1_설계.md`, `프로브_선정.md`, `이동안내_CFD.md` …)

## 11. 런·케이스 ID (D14)

- **이미 돌아간 케이스는 개명하지 않는다** (`S1`~`S5`, `e02`/`e08`/`e17`, `pos1`~`pos16`, `L0.20`, `case0008`, `su168`). 스크립트·CSV에 하드코딩돼 있음
- **신규 케이스부터** 적용: 정수 ID는 2자리 0패딩(`pos01`), 소수는 점 대신 `p`(`L0p20`, `T24p19`)

---

## 개명 시 절차

1. 문서 지도(`CLAUDE.md`, `03_논문/README.md`)를 **먼저** 실제와 맞춘다
2. `mv` 로 개명 (폴더 수정은 bash)
3. `.md`·`.html`·`.py`·`.sh`·`.csv`·`.txt`·`.json` 안의 옛 이름을 일괄 치환 — **`_archive/` 는 제외**
4. 치환 후 깨진 상대경로 링크 전수 검사
5. 대소문자만 바꾸는 개명은 2단계 `mv`
