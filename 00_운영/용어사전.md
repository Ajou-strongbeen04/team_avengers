## 1. 폐기된 용어 → 대체 표기

| 폐기 | 대체 | 적용 문맥 |
|---|---|---|
| dead-spot / dead spot / 데드스팟 | **정체역** | 유동 구조를 말할 때 — 시간평균 유동장의 저유속 구역. 유동 기하로 정의되며 DO와 무관하게 존재한다 |
| dead-spot / dead zone | **저산소역** | DO를 말할 때 — 임계 이하 또는 국소 최소가 되는 구역. 정체역에 생물 소비가 걸릴 때 나타나는 *결과* |
| 정체구역 · 정체 구역 · 정체영역 | **정체역** | 표기 통일 |
| 저산소 구석 · 저산소 구역 | **저산소역** | 표기 통일 |
| 축소차수모델 | **축소모델(ROM)** | 첫 등장 시 `축소모델(ROM)`, 이후 `ROM` |

**왜 나눴나.** 구 초안은 "dead-spot"이 유동(저유속)과 DO(저산소)를 동시에 가리켜, "저DO는 정체역의 결과이지 정의가 아니다"라는 논지를 문장이 스스로 흐렸다. v2는 원인(정체역)과 결과(저산소역)를 표기로 분리한다.

## 2. 물리 기호 표기

| 대상 | 표기 | 비고 |
|---|---|---|
| 국소 물질전달계수 | $k_L$ | 수면 재폭기·기포 계면 공통. 온도의존은 $k_L(T)$ |
| 국소 체적전달 | $k_L a$ ($a=6\alpha_g/d_b$) | 플룸 계면적 밀도 기반 |
| 유효(집약) 산소전달계수 | $K_L a_\text{eff}$ | 재폭기 시계열에서 추정하는 **관측 가능한 단일 집약량**. $\mathrm{Da}_\text{air}$·$\mathrm{Sh}_s$ 를 합친 값 |
| CFD–실측 보정계수 | $\kappa = K_La_{\text{eff,meas}}/K_La_{\text{eff,CFD}}$ | 조건의존 집약계수 |
| 유효확산 | $D_\text{eff}=D_\text{mol}+\nu_t/Sc_t$ | |
| 시간평균 유동장 | $\overline{\mathbf U}$ | 과도 URANS 결과의 시간평균 |
| 특성거리 | $L_c$ | 폭기(플룸)축 → 최원코너 수평거리 |

## 2-1. 좌표 규약 (2026-07-26 확정 — 두 계가 공존한다)

| | 사진좌표 (VLM 출력) | **CFD좌표 (기준)** |
|---|---|---|
| 1축 | $x_\text{img}$ 폭 | $x$ 길이 $L=0.47$ m |
| 2축 | $y_\text{img}$ **높이** | $y$ **폭** $B=0.21$ m |
| 3축 | $z_\text{img}$ **깊이** | $z$ **수심**(상향, 바닥 $z{=}0$) $d=0.21$ m |

$$x = x_\text{img}L,\qquad y = z_\text{img}B,\qquad z = y_\text{img}d$$

**2·3축이 서로 바뀐다.** $B=d=0.21$ m라 수치로는 안 드러나므로 놓치기 쉽다. 물리 문서·CFD 케이스는 **항상 CFD좌표**로 쓰고, 사진좌표는 VLM 출력에만 쓴다. 변환 강제 규칙은 `../03_논문/Experiment/EX3/기하인식/03_BC_출력스키마.md` §0.

> `CFD_method.md` 는 $z$-하향으로 정의돼 있고 EX2·EX3 실제 케이스는 $z$-상향이다(부호만 반전, 물리 동등 — `../03_논문/Experiment/EX2/CFD/docs/CFD_방법론.md` §3 델타 ①).

## 3. 시스템 구성 표기

| 대상 | 표기 | 정의 |
|---|---|---|
| A층 | **A층 ROM** (기하 → 유동) | 오프라인 CFD 스윕으로 학습한 기하→시간평균 유동장 연속 사상 |
| B층 | **B층** (유동 → 저산소 확률) | 유동장 위 이송확산 경량 선형 풀이 |
| 최종 출력 | **저산소 확률맵** | "위험맵"·"리스크맵"으로 쓰지 않는다 |
| 제품 포지션 | **계기판 경고등** | "자율주행"의 반대말로 쓰는 고정 비유 |
| 사진→BC | **사진→기하→BC 자동설정(VLM)** | "사진으로 DO를 읽는다"로 쓰지 않는다 |

## 4. 폐기된 설계 (문서에 되살리지 말 것)

- **인공 국소 산소싱크**(전기화학 ORR $I/4F$, 화학 싱크) — 2026-07-19 폐기. 원설계는 `../_archive/EX2_공간매핑_구주제/`.
- **다지점 공간 DO 매핑(12~16점 순차측정)을 핵심 검증으로 삼는 설계** — EX2는 **비정상 재폭기 시험 단독**. 공간 신뢰는 격자수렴(GCI) + 정성 유동검증 + ROM 위치 게이트가 담당한다.
- **생물 소비/생성 체적항 · 저서 SOD** — 지배방정식에서 제거, 제품 단계 B층 BC로 분리.

> Na₂SO₃ 는 폐기 대상이 아니다. 현행 재폭기 시험의 **표준 탈산소 시약**이자 프로브 0% 보정액으로 계속 쓴다.
