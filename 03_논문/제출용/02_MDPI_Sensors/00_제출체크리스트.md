## 1. 원고 (Manuscript)

- [ ] MDPI Word/LaTeX 템플릿 적용
- [ ] 섹션 구성이 Sensors 관행과 정합 (`02_본문_골격.md`)
- [ ] Abstract — MDPI 권장 길이 준수, 구조화 여부 확인
- [ ] Keywords 3~10개 — `low-cost sensing`, `soft sensor` 계열 반드시 포함
- [ ] 모든 Figure 300 dpi 이상, 별도 파일로도 준비
- [ ] Table은 이미지가 아니라 편집 가능한 표
- [ ] 참고문헌 MDPI ACS 스타일 변환 (`../../References/00_References.md` → 번호 인용)
- [ ] 수식 번호 부여, 미분기호 렌더 검증
- [ ] 영문 교정 완료 (native/전문 서비스)

## 2. 필수 진술 섹션 (MDPI 공통)

- [ ] Author Contributions (CRediT) — `../03_공통자산/저자정보.md`
- [ ] Funding
- [ ] Institutional Review Board Statement — 어류 사용 시 **동물 윤리 해당 여부 확인 필수**
- [ ] Informed Consent Statement — N/A
- [ ] Data Availability Statement — 특허 범위와 충돌하지 않는 선에서
- [ ] **Conflicts of Interest — 특허 출원 사실 명시**
- [ ] Acknowledgments

> ⚠️ **어류 윤리 심사**: 실험에 살아있는 어류를 사용했다면 IACUC/IRB 관련 진술이 요구될 수 있다. EX2 재폭기 시험은 Na₂SO₃ 탈산소 기반이라 해당 없을 가능성이 높지만, **사육부하 항이 실측 어류 기반이면 반드시 확인**. 이 항목 누락은 흔한 desk reject 사유다.
