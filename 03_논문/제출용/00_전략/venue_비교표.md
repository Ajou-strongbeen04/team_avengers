## 2. MDPI 저널 후보 비교 (왜 Sensors인가)

| 항목 | **Sensors** ✅ | Applied Sciences | Water |
|---|---|---|---|
| 스코프 정합 | 저가 센서·IoT·엣지 추론 선례 다수. 우리 연구의 "저가 관측 → 물리 역추정" 축과 직결 | 매우 넓음 — 거의 다 받음 | 수질·용존산소·폭기 도메인 정합 |
| 심사자 이해도 | 센서 융합·소프트센서 프레임 익숙 | 분야 잡거 → 리뷰어 매칭 불안정 | CFD·$K_La$ 는 잘 알지만 VLM·LLM 축은 낯섦 |
| 우리 약점 노출 | "센서가 부수적"으로 보이면 desk reject 위험 → 프레이밍으로 방어 | 낮음 | **AI 축이 부수적으로 보임** — 대회 정체성과 충돌 |
| 인지도·어필 | 높음 | 낮음 | 중간 |
| 선행연구 연결 | 저가 IoT DO 모니터링 선행(단일점 ML)이 실린 곳 → **직접 차별화 서술 가능** | 약함 | 폭기공학 계보와 연결 |
| 판정 | **1순위** | 보험 (desk reject 시) | 보험 (AI 축 포기 시) |

**결정 근거 한 줄:** 우리 차별점은 "선행 저가 IoT DO는 단일점·시간예측인데 우리는 공간·물리"다. **그 선행이 실린 커뮤니티에 내야 차별화가 성립한다.**

## 3. 배제한 경로와 이유

| Venue | 배제 이유 |
|---|---|
| arXiv | endorsement 리스크 → 대회 임계경로에 못 둠. Preprints.org 게시 후 여유 있으면 미러링 |
| *Computers and Electronics in Agriculture* | 스코프는 정중앙이나 **가정용 어항 = 비농업**으로 읽힐 위험 + 심사 기간 김. 확장판·후속 논문으로 보류 |
| *Aquacultural Engineering* | 산업 양식 전제. "가정용 어항"이 스코프 밖으로 읽힘 |
| 국내 학회 | 배제 아님 — **APC 실패 시 대안**이자 병렬 실적 경로. 축을 쪼개 기계(CFD/재폭기)·SW(VLM/ROM) 2건으로 내는 것이 유리 |

## 4. 병렬 제출 가능 여부

| 조합 | 가능? |
|---|---|
| 프리프린트 + Sensors | ✅ MDPI가 프리프린트 선공개 허용 |
| 프리프린트 + 국내 학회 | ✅ |
| Sensors + 국내 학회 (같은 내용) | ⚠️ 중복게재 소지. **축을 분리**하거나 학회 발표 후 확장판으로 명시 |
| Sensors + 타 저널 동시 | ❌ 절대 금지 |
