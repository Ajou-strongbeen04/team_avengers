## 1. 🔴 문서 충돌 2건 — 해소 기록

### 1.1 $z_\text{start}$ 분할축

| 출처 | 학습 | hold-out | 런 |
|---|---|---|---|
| `실험_SOP.md` §6 | 0.02 / 0.08 / **0.14** | 0.17 ×1 | 12 |
| `실험계획서_v2.md` §7.2 (07-30 "최종") | 0.02 / **0.05** / 0.08 | **0.14 + 0.17** | 11 |
| **본 문서 (채택)** | **0.02 / 0.08** | **0.17** ×1 | **7** (프로브 3점 포함) |

**채택 이유.** 계획서 v2 의 핵심 논거 — "학습을 넓게 잡으면 hold-out 외삽이 12 %p 밖에 안 남아
잔차가 작아도 *조건이 안 변했다*의 증거가 된다" — 를 그대로 따른다. 학습 0.02·0.08(레버 100→78 %),
hold-out 0.17(레버 36 %) → **외삽 42 %p**로, 재현성 CV 5–10 % 의 **4–8배**다.

계획서 v2 대비 줄인 것과 그 대가:

- **0.05 를 뺐다.** 학습이 2수준이 된다. $\kappa$ 를 *상수*로 주장하므로 학습셋은 추세 적합이
  아니라 평균 추정이면 되고(계획서 v2 §7.2), 2수준으로도 "학습 밴드 안에서 $\kappa$ 가 일치하는가"는
  확인된다. 잃는 것은 $\kappa$ 의 $z$ 의존성을 **곡선으로** 그릴 능력이다.
- **hold-out 0.14 를 뺐다.** 계획서 v2 는 hold-out 을 2개 두어 "실패 시 $\kappa$ 조건의존 vs 이상치"를
  구분하려 했다. 0.14 한 런이 3.9 h 라 이번에는 뺀다. **hold-out 이 미통과하면 0.14 를 추가 실행**해
  구분한다(조건부 8번째 런).
- **대신 프로브 3위치를 넣었다.** $t_\text{mix}$ 판정이 불성립(2026-08-01)이라 **위치는 이제
  "안 변하는 것을 확인하는 축"이 아니라 실제 산포가 예상되는 축**이다. 방법론 §6.1-3
  (위치교대 반복런)의 유일한 실측 근거이자, §6.1-1(체적평균 근접 위치 선정, CFD 미완)의
  실측 대체다.

## 2. 🔴 `fit_kla.py` 의 구조적 결함과 그 해결 — 종료기준을 정한 계산

### 2.1 무엇이 문제였나

v1 `fit_window()` 는 유효창 정규화 기준 $C_\text{ref}$ 를 **관측 말미 중앙값**으로 잡는다.

```python
c_plateau = np.percentile(c[-max(3, len(c)//20):], 50)   # ← 말미 중앙값
frac = (c - c_min) / (c_plateau - c_min)
```

평탄부에 못 닿은 런은 이 값이 참 $C^{*}$ 보다 낮다 → `frac` 이 부풀려진다 → 유효창(0.15–0.92)이
곡선 앞쪽으로 밀린다 → 초반 급경사 구간의 비중이 커져 **$K_La$ 가 과대평가**된다.
파일럿이 평탄부를 놓친 것은 단순한 "$C^{*}$ 미확정"이 아니라 **$K_La$ 오염**이기도 했다.

### 2.2 실측 편향 (파일럿 원자료 `pilot_deox.csv`, $t_0$=1730 s)

| 절단 | v1 자유피팅 | **v2 `--cstar-ref`** |
|---|---|---|
| 2.5$\tau$ | +8.45 % | **−0.22 %** |
| 3.0$\tau$ | +5.39 % | **−0.14 %** |
| 3.5$\tau$ | +3.43 % | **−0.14 %** |
| 4.0$\tau$ | +2.05 % | **−0.14 %** |
| 5.0$\tau$ | +0.75 % | **−0.14 %** |

기준은 전체기록(5.48$\tau$) 자유피팅 $K_La$=2.4169 /h.

**외부 $C^{*}$ 를 주입하면 절단 편향이 사라진다.** 유효창 상한 0.92 가
$-\ln(0.08)=2.53\tau$ 에서 닫히므로, 그 이후 데이터는 애초에 피팅에 안 쓰인다.
따라서 **3.3$\tau$(여유 30 %)면 충분**하고, 4$\tau$·6$\tau$ 는 낭비다.

### 2.3 🔴 대가 — $C^{*}_\text{ref}$ 오차가 3.1배로 증폭된다

$C^{*}$ 를 고정하면 그 오차가 $K_La$ 로 넘어간다. 실측 게인(3.3$\tau$ 절단 런):

| $C^{*}_\text{ref}$ 오차 | −2 % | −1 % | −0.5 % | +0.5 % | +1 % | +2 % |
|---|---|---|---|---|---|---|
| $K_La$ 오차 | +6.13 % | +3.08 % | +1.54 % | −1.56 % | −3.13 % | −6.34 % |

**게인 ≈ 3.1.** 이것이 운용 규칙 셋을 강제한다.

1. **기준런은 진짜 평탄부까지 간다.** 기울기 0.02 mg/L/10분에서 끊으면 잔여 갭
   $=$ 기울기$/K_La$ $=0.0138$ mg/L $=0.17\%$ → $K_La$ 편향 0.5 %. 허용.
   파일럿처럼 0.074 에서 끊으면 갭 2.2 % → **$K_La$ 편향 6.8 %**. 불허.
2. **$C^{*}_\text{ref}$ 는 같은 보정 프레임에서 나와야 한다.** 스팬 편향이 데이터와
   $C^{*}_\text{ref}$ 에 똑같이 곱해지면 $K_La$ 는 불변이지만(파일럿 §2.5와 정합),
   **다른 날 보정에서 가져오면 표류(|≤1.3 %|/3.5 h, 보정로그)가 그대로 3.1배로 증폭**된다.
   → **측정일마다 기준런 1회.**
3. **온도 전이는 Benson–Krause 비로.** `--cstar-ref-T` 가 자동 처리한다.
   1 °C 차이가 $C^{*}$ 2.3 % 이므로 이걸 빼먹으면 $K_La$ 가 7 % 틀어진다.

### 2.4 검증 (합성 곡선, 참값 대비)

| 파일 | 참 $K_La$ | 복원 | 오차 | 조건 |
|---|---|---|---|---|
| syn_R1 | 2.417 | 2.416 | **−0.03 %** | 6$\tau$ 완주, 자유피팅 |
| syn_R2 | 2.417 | 2.416 | **−0.04 %** | 3.3$\tau$ 절단 + 올바른 `--cstar-ref` |
| syn_R3 | 2.300 | 2.299 | **−0.06 %** | 3.3$\tau$ |
| syn_R4 | 2.550 | 2.548 | **−0.06 %** | 3.3$\tau$ |
| syn_R5 | 1.884 | 1.791 | −4.91 % | **$C^{*}_\text{ref}$ 를 일부러 +1.56 % 틀리게** |
| syn_R6 | 0.880 | 0.850 | −3.36 % | **$C^{*}_\text{ref}$ 를 일부러 +1.07 % 틀리게** |

R5·R6 의 오차는 게인 3.1 과 정확히 일치한다(+1.56×3.1=4.8, +1.07×3.1=3.3).
**도구는 정상이고, 위험은 $C^{*}_\text{ref}$ 관리에 있다**는 것이 이 시험의 결론이다.

하위호환: 파일럿 원자료를 v1 과 동일 옵션으로 돌리면 $K_La$=2.417 /h, $\tau$=24.8 min,
$C^{*}$=8.336, 유효창 $t$ 565–4424 s, RMSE 0.0290 — **v1 결과 완전 재현**.

## 4. 런 매트릭스 (7런 · 22.7 h · 3일)

$\tau$ 예측 = $60/(\kappa\cdot K_La_\text{CFD})$, $\kappa$=0.928(파일럿 잠정).
오버헤드 69분/런 = 탈산소 14 + 잔여아황산 안정 20 + 불응 5 + 물교체·세팅 30.

**설계의 핵심 — 기준런이 3역할을 겸한다.**

1. 그날의 $C^{*}_\text{ref}$ (§2.3 규칙 2)
2. **재현성 CV** — R1/R4/R6 는 동일조건 3반복. **날짜를 가로지르므로 보정 재현성까지

3. 절단 편향이 없는 자유피팅 값 → $\kappa$ 의 앵커

**조건부 8번째 런:** R7 hold-out 잔차가 미통과면 **$z$=0.14 (3.9 h)** 를 추가해

("총량은 로버스트하고 문제는 공간구조다")의 실측 근거가 된다.

## A.1 🔴 기존 자료는 $C^{*}_\text{ref}$ 로 못 쓴다 — 근거

`pulse1~4`(2026-08-01 02:08~03:48, **현행 보정 프레임**, 폭기 평형 수조)의 주입 전 baseline을
$C^{*}$ 관측값으로 보고 Benson–Krause(101.0 kPa)와 대조:

| 파일 | baseline [mg/L] | $T$ [°C] | B–K | 포화 % | 주입 전 표류 |
|---|---|---|---|---|---|
| pulse1 | 8.1865 ± 0.0165 | 24.82 | 8.265 | 99.05 | **+0.0156** mg/L/100s |
| pulse2 | 8.0718 ± 0.0184 | 24.73 | 8.278 | 97.51 | **+0.0185** |
| pulse3 | 8.1285 ± 0.0245 | 24.70 | 8.283 | 98.13 | **+0.0201** |
| pulse4 | 8.3089 ± 0.0157 | 24.63 | 8.293 | **100.19** | **+0.0136** |

- **산포 2.7 %p** (97.51–100.19). §2.3 게인 3.1배 → $K_La$ 불확도 **±8 %**.
- **네 런 모두 상승 중**이었다 = 수조가 평형에 도달한 적이 없다. 관측값은 전부 **하한**이다.
  (이것이 `tmix_결과` §4.1 「baseline 표류」의 정체이며, $t_{95}$ 산출을 무너뜨린 바로 그 원인이다.)
- 파일럿(07-31)은 더 나쁘다: 스팬 보정 후 $C^{*}$=7.959 mg/L = B–K의 **96.94 %**, 그나마 하한이고
  **다른 보정 프레임**이다.

**결론:** 필요 정밀도(<0.3 %)를 만족하는 기존 $C^{*}$ 관측이 없다.
$C^{*}_\text{ref}$ 는 **세션 첫 런을 평탄부까지 돌려** 만든다. 추가 비용은 **47분**뿐이고
(`--stop-on-plateau 0.02` 가 자동 종료), 이를 아끼면 전 런에 ±8 % 계통오차가 들어간다.

> 유일하게 건질 것: pulse4가 **100.19 %에서도 여전히 상승 중**이었으므로
> **$C^{*} > 1.002 \times$ B–K** 라는 하한이 서고, CFD 예측 $\Delta C^{*}\approx+0.3\,\%$ 와 정합한다.
> S1 의 $C^{*}$ 가 B–K의 100–101 % 로 나오면 정상, 98 % 이하면 보정을 의심할 것.

## A.2 🔴 재보정하지 말 것 — 예외 0x10 의 해석

`--calibrate 100` 이 **예외 0x10** 으로 거부된 것은 **버그가 아니다.**
2026-07-31 영점 거부와 같은 메커니즘으로, **센서가 현재 매질을 그 보정점으로 인정하지 않은 것**이다
(`보정로그.md` 「0% 영점 보정」). 배선·주소·보레이트 문제가 아니며 **기존 보정은 그대로 살아 있다.**

현행 프레임의 건강 상태는 이미 확인돼 있다 — 07-31 사후 재보정 직후 스팬 **99.78 %** · 영점 **−0.69 %**,
08-01 소급 다점 검증 **96.5–100.3 %**, 표류 **≤1.3 %/3.5 h**.

**따라서 세션 개시 절차를 이렇게 바꾼다.**

```
구:  --read 표류확인 → 재보정(100→0) → 기압 → verify
신:  --read 표류확인 → verify → (통과하면 재보정 안 함) → 기압 확인
                              └ 실패(밖 99–101 %)일 때만 재보정
```

근거: 07-31 스팬 편향 −4.52 %의 원인은 센서가 아니라 **불필요·부적절한 재보정**이었다.
정상 프레임을 건드리는 것이 가장 큰 단일 위험이다.
**§3.2-1(정식 표류 확인)은 그대로 필수** — `--read` 두 환경 판독만으로 충족되며, 이걸로 영점 표류도 닫힌다.

## B.2 🔴 $C^{*}_\text{ref}$ — 탈산소가 필요한가

**필요 없다.** $C^{*}$ 는 평형 포화농도이므로 **폭기만 해서 평형에 도달시키면** 측정된다.
탈산소는 $K_La$(상승곡선)를 위한 것이지 $C^{*}$ 를 위한 것이 아니다.

폭기만 하는 경우 소요(수조를 갈고 폭기 시작할 때 초기 포화도별):

| $z$ | $\tau$ [분] | 초기 97 % → 평탄 | 초기 99 % → 평탄 | 탈산소 0 % → 평탄 |
|---|---|---|---|---|
| 0.02 | 24.8 | 40분 | 13분 | 127분 |
| 0.08 | 31.8 | 43분 | 8분 | 155분 |
| 0.17 | 68.2 | 41분 | 0분 | 280분 |

**그럼에도 S1 은 탈산소-재폭기로 한다.** 이유는 두 가지다.

1. **S1 은 $C^{*}_\text{ref}$ 만을 위한 런이 아니다.** 학습셋 $\kappa$ 런이기도 하므로
   $K_La$ 를 뽑아야 하고, 그러려면 상승곡선이 필요하다.
2. **그게 더 싸다.** 별도 "폭기만" $C^{*}$ 런은 40분 + 물세팅 30분 = 70분이 통째로 추가된다.
   S1 을 3.3$\tau$(82분)에서 5.12$\tau$(127분)로 늘리는 것은 **+45분**뿐이다.

> **정리:** 탈산소-재폭기 맞다. 단 **별도 런이 아니라 S1 을 평탄부까지 끌고 가는 것**이다.
> `--stop-on-plateau 0.02` 가 자동 판정·종료한다.

### B.2.1 단일 $C^{*}_\text{ref}$ 의 잔여 편향 — $z$ 의존성

$C^{*}$ 는 플룸 기포가 겪는 평균 정수압만큼 대기평형보다 높다. $\bar h=(0.21-z_\text{start})/2$:

| $z$ | $\bar h$ [mm] | $\Delta P$ [kPa] | 완전평형 상한 | **실효 추정**¹ | $z$=0.02 대비 | → $K_La$ 편향 |
|---|---|---|---|---|---|---|
| 0.02 | 95 | 0.932 | +0.92 % | +0.157 % | — | — |
| 0.08 | 65 | 0.638 | +0.63 % | +0.107 % | −0.050 %p | **+0.15 %** |
| 0.17 | 20 | 0.196 | +0.19 % | +0.033 % | −0.124 %p | **+0.38 %** |

¹ 플룸 기여 85 % × 1패스 접근율 $\mathrm{Da}_\text{plume}$=0.20 (상수_목록 D 각주).
실효 추정 +0.16 % 는 **CFD 폐합의 $\Delta C^{*}$=+0.33 %** 와 같은 자릿수다.

**→ hold-out($z$=0.17)에 남는 계통편향은 $|K_La|\lesssim1\,\%$** 로, CV 하한 3 % 미만이다.
단일 $C^{*}_\text{ref}$ 로 충분하며, 논문에는 이 편향을 **부호까지 명시**해 보고한다

## B.4 🔴 단일 $C^{*}_\text{ref}$ 를 17 h 동안 지키는 법 — `--gate drift` (신규)

$C^{*}_\text{ref}$ 를 S1(t=1 h)에서 한 번만 재면 S5(t=12 h)까지 **S1 의 보정 프레임을 빌려 쓴다.**
프레임이 표류하면 그 오차가 **게인 3.1배**로 $K_La$ 에 실린다(§2.3).
측정된 표류는 ≤1.3 %/3.5 h 였고, 17 h 로 외삽하면 무시할 수 없다.

**해법: 런 사이 1분, 100 % 기준 비커를 재판독한다.**

```bash
# S1 직후 — 기준값을 잡는다 (100 % 비커에 프로브를 넣고)
python3 do_logger.py --port $PORT --read        # 예: 8.2110 mg/L @ 24.87 C  → 받아적기

# 이후 매 런 직전
python3 preflight.py --port $PORT --gate drift \
    --ref-do 8.2110 --ref-T 24.87 --pressure 101.0
```

출력:

```
표류 +0.32 %  ->  KLa 환산 -0.99 % (게인 3.1)
보정계수: fit_kla.py 에 `--scale 0.99681` 를 줄 것
```

원리: 100 % 비커의 참값은 B–K($T$). 센서 판독을 B–K로 정규화하면 프레임만 남는다.

$$\text{scale} = \frac{r_\text{ref}/C^{*}_\text{BK}(T_\text{ref})}{r_\text{now}/C^{*}_\text{BK}(T_\text{now})}$$

**표류가 나와도 재보정하지 말 것.** 재보정하면 $C^{*}_\text{ref}$ 프레임이 끊겨 이후 런을 전부 잃는다.
`--scale` 로 데이터를 S1 프레임에 되돌리는 것이 옳다. 표류가 **2 % 를 넘을 때만**
재보정 + $C^{*}_\text{ref}$ 재측정이 불가피하다.

# 부록 C — S1 기준런 실행 절차 (정확판)

> "$C^{*}_\text{ref}$ 를 위해 별도 런을 하지 않고 S1 을 평탄부까지 끌고 간다"의 물리적 실행법.
> **S1 은 끊기지 않는 하나의 런이다.** 로깅을 한 번 시작해 끝까지 안 끊는다.

## C.1 무엇을 왜 하는가

S1 하나의 곡선에서 **두 값**이 나온다.

```
DO
 |                                        ┌──────── 평탄부 ← 여기서 C*_ref
 |                                   ╱────┘
 |                              ╱───┘
 |                        ╱────┘      ← 이 지수 구간에서 K_La (유효창 0.15–0.92)
 |                  ╱───┘
 |            ╱───┘
 |     ┌─────┘
 |     │← 불응 5분 (잔여 아황산이 유입 O2 를 전량 소모)
 |─────┘
 |  ↑ 탈산소 14분 + 안정 20분        ↑ 폭기 ON = t0
 └────────────────────────────────────────────────────── t
```

- **$K_La$** ← 상승 지수 구간. 유효창 상한 0.92 가 **2.53$\tau$** 에서 닫히므로 그 뒤 데이터는
  $K_La$ 에 쓰이지 않는다.
- **$C^{*}_\text{ref}$** ← 평탄부. 이건 **5.12$\tau$** 까지 가야 나온다.

일반 런(S2~S5)은 $K_La$ 만 필요하므로 3.3$\tau$ 에서 끊는다. S1 만 5.12$\tau$ 까지 간다.
**차이는 44분뿐이다**(26.5 °C 기준 79분 → 123분).

`기록 길이 tau` 와 `말미10분 기울기` 를 먼저 보고, 실제로 평탄이었다면 스팬이 낮게 박힌 것이니
