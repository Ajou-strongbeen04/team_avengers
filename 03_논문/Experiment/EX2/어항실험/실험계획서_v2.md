## 1. 목표와 성립 조건

- **묻는 것:** 확정 기하·운전 폭기에서 CFD가 내포하는 산소전달률이 실측과 얼마나 이격되는가. 그 이격을 조건의존 보정계수 $\kappa$ 로 표현할 수 있는가.
- **산출물:** 조건별 $\{K_La_\text{eff,meas},\,C^*_\text{meas}\}$ · 대응 CFD $\{K_La_\text{eff,CFD},\,C^*_\text{CFD}\}$ · $\kappa=K_La_\text{eff,meas}/K_La_\text{eff,CFD}$ · $\Delta C^*$ · 피팅 잔차 · **hold-out 전이 잔차**.
- **얻지 못하는 것(정직):** 공간 DO장·저산소역 위치의 실측 앵커. 재폭기는 **총량(magnitude)**만 보정하고 **구조(structure)**는 해상된 CFD가 정한다.

0-D 물리 모델:

$$\frac{d\overline{C}}{dt}=K_La_\text{eff}\left(C^{*}-\overline{C}\right)
\quad\Longrightarrow\quad
\overline{C}(t)=C^{*}-\left(C^{*}-\overline{C}_0\right)e^{-K_La_\text{eff}\,t}$$

곡률이 $K_La_\text{eff}$ 를, **평탄부가 $C^{*}$ 를** 고정한다. 상승 전체 + 평탄부 진입까지 로깅해야 한다.

**예측 시간척도 ($z_\text{start}=0.02$ 기준):**

| 도달률 | 0-D 해석식 (2.785 /h) | **3-D 과도해 (2.604 /h) ← 이 값을 쓴다** |
|---|---|---|
| $\tau=1/K_La$ | 21.5 분 | **23.0 분** |
| 90 % | 49.6 분 | **53.1 분** |
| 92 % (유효창 상한 기본값) | 54.4 분 | **58.2 분** |
| 95 % | 64.5 분 | **69.0 분** |

→ 기준 런의 로깅 시간은 **70분**으로 잡는다(v1의 40분은 구 $K_La$ 기준이라 부족하다).

> **3-D 값의 출처 (2026-07-29 확정):** `../../EX2_X4/reaer_out/m21_T25/fit.txt`.
> medium 앵커 m21(생산 운전점) 동결 유동장 위에서 DO 스칼라만 과도적분 →
> $K_La_\text{eff,CFD}=2.604$ /h, $C^*_\text{CFD}=8.264$ mg/L(T=25 °C), 3D/0-D 비 **0.954**.
> **$\kappa$ 의 분모는 이 값이다** — $\kappa=K_La_\text{meas}[/\mathrm{h}]/2.604$.
> 0-D 해석식 2.785 /h 는 더 이상 분모로 쓰지 않는다.

## 3. $Q_\text{air}$ 재측정 (20분) — 값이 아니라 **불확도**를 얻는다

$Q_\text{air}=1.2$ L/min 은 이미 실측됐다. 다시 재는 목적은 다르다:

1. **개별 3회 시간이 기록되지 않아 ± 를 쓸 수 없다** (`../../실험후검토사항.md` §3.2). $a$ 는 $Q_\text{air}$ 에 거의 선형이므로 이 산포가 곧 $K_La$ 불확도다.
2. 측정이 **실제 수심 0.21 m 침지 상태**였는지 확인. 대기 중 토출이면 배압이 빠져 과대평가다.

**절차:** 눈금 용기를 물로 채워 수조 안에서 거꾸로 세우고, **에어스톤을 단 채로 스톤 전체를 용기 안에** 넣는다. 물이 500 mL 밀려나는 시간 $t$[s]를 잰다 → $Q_\text{air}=30/t$ [L/min]. **개별 시간 3회를 각각 적는다.**

> 재측정 결과가 1.2 L/min에서 **±10 % 이상** 벗어나면 §0 상수표 전체가 이동한다. 그 경우 `alpha_g_보정절차.md`로 고정점을 재수렴시킨 뒤 본시험에 들어간다(오늘 파일럿은 그대로 진행 가능).

## 7. 본시험 설계 — hold-out 축 = 에어스톤 침지 높이 $z_\text{start}$

### 7.1 축 선택 근거

| | 위치 축 | 수위 축 | **$z_\text{start}$ 축** |
|---|---|---|---|
| 레버 | ±9 % (재현성에 묻힘) | **+21 % (부호 반대)** | 100 → 17 % (해석추정) |
| $V$ | 고정 | 20.7 → 8.9 L | **20.7 L 고정** |
| 수면항 $k_{L,s}A_s/V$ | ×1.0 | ×2.33 (레버 상쇄) | **×1.0** |
| 실험 비용 | 물 교체만 | 물량·시약량 매번 재계산 | **0원 — 물량·시약량·보정 그대로** |
| CFD 비용 | — | `blockMesh` 재생성 | **`topoSetDict` z 한 줄** |

$z_\text{start}$ 는 플룸 길이 $H_p=0.21-z_\text{start}$ 를 직접 줄여 연행 $Q_p$ 와 $\mathrm{Da}_\text{plume}$ 을 함께 낮춘다.

### 7.2 수준별 예측 (신 $K_La$ 로 환산)

**해석추정이 크게 틀렸다 — 최대편차 35 %p.** 원인 셋:

1. **$W$ 가 단조가 아니다.** 0.2930 → **0.3023**(z05) → 0.2857 → 0.2696. 에어스톤을 바닥에서 3 cm 띄우면 no-slip 저항에서 벗어나 플룸이 오히려 빨라진다. 그래서 $\alpha_g$ 가 거의 안 움직이고, **위치 축을 죽인 자기조절이 여기서도 작동한다.**
2. **$Q_p\propto H_p^{5/3}$ 가 전달 폐합에 안 들어간다.** $Q_p$ 는 6.16→5.93 L/min, −4 % 뿐. 실제 전달항은 $(V_p/V)k_{L,b}a$ 라 **$H_p$ 에 선형**이다.
3. **수면항이 바닥이다.** $k_{L,s}A_s/V=0.444$ /h 가 $V$ 고정이라 전 수준 동일 — z02 의 **15.2 %**. 플룸을 0 으로 만들어도 그 아래로 못 간다.

> **이것 자체가 결과다.** 20 L 급 어항에서 $K_La$ 총량은 폭기 기하를 크게 바꿔도 좁은 대역에 머문다. **총량은 로버스트하고, 문제는 공간구조다** — 논문의 논지와 정합하며 $\kappa$ 를 조건 둔감한 단일 계수로 쓰는 근거이기도 하다.

**0.14 를 복원한 이유:** 1차에서 뺀 근거("90 % 도달 292분")는 해석추정 기반이었다. 실제 레버가 훨씬 약해 **105분**이라 충분히 돌 수 있다. 레버가 약하다는 나쁜 소식이 곧 "높은 수준도 빨리 끝난다"는 좋은 소식이다.

**0.14를 뺀 이유:** 90 % 도달에 **292분(≈5시간)**이 걸린다. 탈산소·세팅을 더하면 런당 6시간이라 반복이 불가능하고, 그동안의 수온 표류가 $C^*(T)$ 를 흔들어 오히려 불확도가 커진다. 레버는 0.02→0.11의 **100→29 %** 만으로도 위치 축(±9 %)의 3배 이상이다.

**분할 (2026-07-30 최종, CFD 6수준 완주 후):** $z_\text{start}$ = **0.02 / 0.05 / 0.08 학습** → $\kappa$ 산출 → **0.14 · 0.17 두 개를 hold-out** 으로 재피팅 없이 적용 → 전이 잔차.

- **학습 span 100→75.1 %**(얕은 쪽 3수준), **hold-out 51.1 % · 38.9 %** → 외삽 **24 %p · 36 %p**, 재현성 CV 5–10 % 의 **2.4–7배**.
- **왜 학습을 얕은 쪽으로 몰았나:** 학습을 넓게(0.02/0.08/0.14) 잡으면 hold-out 외삽이 **12 %p** 밖에 안 남아 잡음의 1–2배에 그친다. 그러면 hold-out 잔차가 작아도 "$\kappa$ 가 전이된다"가 아니라 "조건이 안 변했다"의 증거가 된다 — 위치 축을 탈락시킨 논리 그대로다. $\kappa$ 는 **상수**로 주장하므로 학습셋은 추세 적합이 아니라 평균 추정이면 되고, 좁은 밴드 3점으로 충분하다.
- **hold-out 을 2개 둔다.** 하나만 두면 실패 시 "$\kappa$ 가 조건의존인가 / 그 런이 이상치인가"를 구분할 수 없다. 0.17 은 2반복으로 이상치를 배제한다.
- **반복은 0.02 에 3회 몰아 재현성 CV(= 잡음 기준선)를 여기서 확정**한다. 이 값이 hold-out 판정선의 분모다.
- 0.11 은 **CFD 데이터로만 남긴다** — $\kappa$ 곡선의 내삽 확인용, 실측 런은 하지 않는다.

## 10. CFD 대조 → $\kappa$ (실측과 병행 가능)

> **선행 CFD 2건은 `../../EX2_X4/` 에 준비돼 있다.** 케이스 생성 완료(2026-07-29). 아래는 요약이고 상세·판정기준·기입표는 `../../EX2_X4/README.md`.

### 10.1 선행 CFD — $z_\text{start}$ 레버 ✅ **완료 (2026-07-30, 6수준)**

결과는 §7.2 표. 판정: 단조·자기일관·해석추정 교체·**레버 크기 전부 통과**(100→39.3 %).
1차 4수준에서 불합격(65 %)이던 것을 0.14·0.17 연장으로 뒤집었다. 상세 `../../EX2_X4/README.md` §4·§9.

- 얻는 것: **§7.2 해석추정 표의 CFD 실측 대체.** 수위 축에서 부호가 뒤집힌 전례가 있으므로 해석추정을 그대로 논문에 쓰지 않는다. 표가 바뀌면 **런당 로깅 시간(§7.4)도 다시 잡는다.**
- 수위 축 D군(0.21/0.18/0.15/0.12/0.09) 결과는 폐기하지 않는다 — **"수위는 레버가 아니다 / $1/V$ 증폭"**의 정량 근거로 논문 §4·§5에 쓴다.

### 10.2 $K_La_\text{CFD}$ 를 3-D 로 확정 — **실측 대조 전 필수**

현재 $K_La$ 값은 **전부 0-D 해석식**이다. $\kappa$ 의 분모이므로 그대로 쓰면 안 된다.

✅ **완료 (2026-07-30, 13케이스).** `../../EX2_X4/kla_3d.csv`.

- **$\kappa$ 분모 = 2.604 /h** (m21 medium 앵커). coarse $z_\text{start}$=0.02 는 2.703 으로 +3.8 % 높다 → **절대값은 medium, 상대(레버)는 coarse** 규약.
- **3-D 는 산포·레버를 바꾸지 않는다** — 3D/0-D 비 0.913–0.923 으로 거의 일정, 레버 차이 ≤0.5 %p. 0-D 해석식을 상대 스윕에 그대로 써도 된다는 뜻이고, 동시에 `../../EX2_X3/README.md` §5.2 의 "3-D 가 산포를 좁힌다"는 서술은 **틀렸다**(`../../EX2_X4/README.md` §9.2).
- **위치 CV 보존 통과**: 신 운전점 14.46 % ↔ 구 12.59 %, 차이 1.88 %p. 16위치 재실행 영구 종료.

- $\alpha_g$ 는 케이스별 실측 $W$ 되먹임으로 자동 계산된다. 앵커의 자기일관 고정점을 쓰려면 `--alpha-g 0.1785`.
- 격자 자동인식 패치 완료(종전 108×48×48·$L_z$=0.21 하드코딩은 coarse·수위가변에서 틀린 답을 냈다).
- 0-D 와 3-D 는 계통적으로 다르다: 0-D 는 $K_La\propto\alpha_g$ 라 되먹임 산포가 그대로 실리는 반면, 3-D 는 순환 $Q_p$ 증가가 상쇄해 산포가 좁아진다(위치 CV 12–13 % vs 5.1 %). **논문에 쓰는 값은 3-D 쪽이다.**
- ~~§10.2 가 끝나기 전에는 $\kappa$ 를 계산하지 않는다~~ → **분모 확정 완료.** 실측 $K_La$ 를 얻는 즉시 $\kappa=K_La_\text{meas}/2.604$ 로 계산할 수 있다.

### 10.3 가상 재폭기 → $\kappa$

1. 시간평균 유동장 $\overline{\mathbf U},\nu_t$ 는 **얼려 재사용**, DO 스칼라만 $C(\mathbf x,0)=0$ 에서 과도 적분.
2. 경계·소스는 실측 주입값 고정: 실측 수온 $T$ → $C^*(T)$(Benson–Krause [R14])·$k_L(T)$, $Q_\text{air}$ 실측값.
3. CFD 벌크평균 $\overline{C}_\text{CFD}(t)$ 를 **로거 CSV와 같은 열 형식**(`iso_time, t_sec, do_mgL, sat_frac, temp_C`)으로 내보내 **같은 `fit_kla.py`·같은 유효창**으로 피팅 — 피팅 규약을 강제로 일치시키는 것이 목적이다.
4. $\kappa=K_La_\text{eff,meas}/K_La_\text{eff,CFD}$, $\Delta C^*=C^*_\text{meas}-C^*_\text{CFD}$, 잔차 = 모델 불확실도.
5. hold-out($z_\text{start}$=0.11): 학습 $\kappa$ 를 **재피팅 없이** 곱해 전이 잔차 산출.

> 유동장은 준정상 평균장, DO는 과도 — 양쪽 모두 동일 규약이라 사과-대-사과다. 부력쪽 $\alpha_g$ 는 $Q_\text{air}$ 로 고정하고, 캘리브레이션 자유도는 전달쪽($a$·$Sc_t$)으로 국한한다(논문 §3.4).

## 12. 중단 기준

- **통신이 안 서면**(§4) 그날은 멈추고 어댑터·전원 문제를 해결한다.
- **보정 사전·사후 차이가 크면** 파일럿을 참고값으로만 쓰고 본시험은 보류한다.
- **DO≈0에 도달하지 않으면** Na₂SO₃를 추가 투입하되 투입량을 기록한다.
- **$Q_\text{air}$ 재측정이 1.2 L/min에서 ±10 % 이상 벗어나면** 고정점 재수렴 후 본시험 진입(§3).
- **$\tau_p>26$ s면** `fit_kla.py --tau-probe` 구현 전까지 본시험 데이터를 $\kappa$ 산출에 쓰지 않는다.
