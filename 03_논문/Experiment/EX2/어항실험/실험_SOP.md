## 0. ✅ 완료(2026-07-31) — $Q_\text{air}$ 물 치환 실측 (10분, 공짜)

> **✅ 완료 2026-07-31:** 500 mL, 3회 $t$=24.96 / 25.01 / 25.03 s(평균 25.000 s, SD 0.036 s) → $Q_\text{air}=1.200\pm0.002$ L/min. 확정값 등재: `../../상수_목록.md` D군. 아래 절차는 재현·재측정 시 참조용.

**다른 무엇보다 먼저 하십시오.** 현재 $Q_\text{air}\approx2$ L/min 은 "2.5 W 펌프" 스펙에서 어림한 값이지 실측이 아니다. 이 값 하나가 $\alpha_g$·$\mathrm{Su}$(CFD 부력원)·$a$·$K_La$ 를 전부 결정한다.

| 실제 $Q_\text{air}$ | $\alpha_g$ | Su | $a$ [1/m] | $K_La$ | 2 L/min 대비 |
|---|---|---|---|---|---|
| 1.0 | 0.150 | 1.47 | 1798 | 2.42 /h | 64 % |
| 1.5 | 0.205 | 2.02 | 2465 | 3.13 /h | 83 % |
| **2.0 (가정)** | 0.257 | 2.52 | 3082 | 3.78 /h | 100 % |
| 3.0 | 0.352 | 3.45 | 4220 | 4.94 /h | 131 % |

2.5 W급 실토출은 배압·수심에 따라 1.5–3.5 L/min으로 흔히 갈린다.

**절차 (물 치환법):**

1. 눈금이 있는 용기(계량컵, 또는 500 mL 눈금 표시한 페트병)에 물을 가득 채운다.
2. 입구를 막고 수조 안에서 **거꾸로 세운다**(공기 안 들어가게). 용기 안이 물로 꽉 찬 상태 유지.
3. 에어스톤을 뗀 **호스 끝**을 용기 입구로 밀어넣는다. 실제 운전과 같은 수심에서 할 것(배압이 토출량을 바꾼다).
4. 물이 **500 mL 밀려나는 시간** $t$ 를 스톱워치로 잰다. → $Q_\text{air} = 0.5\,\mathrm{L}/t\,[\mathrm{min}]$
5. **3회 반복**해 평균·산포. 오차 몇 % 이내면 충분하다.

> **주의:** 에어스톤을 단 채로 재면 스톤 저항이 빠져 과대평가된다. 반대로 스톤 없이 재면 실제 운전보다 배압이 낮아 과대평가된다. **가장 정확한 방법은 스톤을 단 채로 스톤 전체를 용기 안에 넣는 것.** 여의치 않으면 호스 끝으로 재고 불확도에 반영.

**후속:** 실측값을 `../../상수_목록.md` D군에 기입 → $\alpha_g$ 자기일관 재수렴 → $a$ 갱신. $W\propto\mathrm{Su}^{1/3}$ 이 `../CFD/flow/pos1_su235/` 로 검증되면 CFD 재실행 없이 산술 보정으로 끝난다.

1. **100 % 포화 환경:** 정제수를 비커에 담고 에어펌프로 **1시간 폭기 → 30분 정치**. (간이법: 밀폐용기에 물 조금 넣고 30초 격렬히 흔들어 수증기포화 공기를 만든 뒤, 형광막을 수면 **1 cm 위**에 두기 — 젖되 물방울은 없게.)

4. **영점 환경:** 정제수 190 g + **Na₂SO₃ 10 g**(5 % 용액) 완전 용해 → **1시간 정치**. CoCl₂ 미량 첨가 시 가속.
5. 프로브 담그고 가볍게 저은 뒤 정치. **실측이 ~0 로 안정된 뒤에만** → `--calibrate 0`

### 3.1 🔴 사후 표류 확인 — `--read` 를 먼저, `--calibrate` 는 나중

**`--calibrate` 는 쓰기 명령이다.** 표류 확인용으로 그냥 재실시하면 기존 보정을 덮어써서 **"전후 차이"를 영구히 잃는다.** 반드시 이 순서로:

```bash
# 1) 각 보정 환경에서 먼저 READ ONLY 로 읽어 기록  ← 이게 표류값이다
python do_logger.py --port COM3 --read     # 100% 환경
python do_logger.py --port COM3 --read     # 0% 환경

# 2) 기록한 뒤에야 재보정
python do_logger.py --port COM3 --calibrate 100
python do_logger.py --port COM3 --calibrate 0
```

**이 전후 차이가 곧 프로브 불확도**이며 방법론 §6 드리프트 관리의 입력이다.

> **소급 대안 (절차를 놓쳤을 때):** 폭기 중인 수조를 100 % 기준으로 삼아 서로 다른 시각의 포화 %를 비교하면 표류 **상한**을 뽑을 수 있다. 2026-08-01 적용 결과 |표류| ≤ 1.3 % / 3.5 h. 단 수조가 평형이라는 보장이 없으므로 **상한일 뿐**이며, 정식 절차를 대체하지 않는다.

> 2026-07-31 실패 사례: `--read` 없이 바로 `--calibrate` 를 돌려 표류값을 잃었다. 수조 재판독으로 우회 복구했으나 운이 좋았다.

## 5. ✅ 완료(2026-08-01) — 혼합시간 $t_\text{mix}$ (산소결손 펄스 추적법)

> **✅ 완료:** 결과 `tmix_결과_20260801.md`. **판정: $t_\text{mix}\ll 1/K_La$ 기준 불성립.** 위치 간 국소 DO 결손 산포 **2.0–3.5배**(프로브 지연 디컨볼루션 후 3.1–3.3배), **≥10분** 미수렴. 방법론 §2·§6.1-2 개정 반영 완료.
> **⚠ $t_{95}$ 는 못 뽑았다** — baseline 표류로 회수율 148–324 %. **재측정 1순위는 baseline 제어**(§5.4).

**식용색소를 확보하지 못해 염료법 대신 고안한 대체법.** 프로브 자체를 검출기로 쓴다 — 염료보다 우수하다(DO 자체의 혼합을 재고, 육안 판정이 없다).

### 5.1 원리

포화 수조(폭기 ON)에 Na₂SO₃ 슬러그를 한 점 주입 → Co²⁺ 촉매로 수 초 내 반응 종료 → 그 자리에 **국소 DO 결손** 생성 → 반응이 끝났으므로 결손은 **수동 스칼라**로 분산 → 프로브가 1 Hz 기록. 결손을 다시 채우는 재폭기($\tau$=24.8분)는 혼합(분 단위)보다 10배 느려 분리 가능하다.

### 5.2 설계값

| 항목 | 값 |
|---|---|
| 목표 균질결손 $\Delta C$ | 0.307 mg/L |
| Na₂SO₃ | **50 mg** ($20.7\,\text{L}\times0.307\times7.88$) |
| 용해 | 수조물 20 mL + CoCl₂ 용액 1방울 (**고체를 그냥 뿌리지 말 것** — 용해시간이 혼합시간에 섞인다) |
| SNR | 주입 전 실측 SD 0.005–0.019 대비 **9–16배** (지배 불확도는 1 Hz 노이즈가 아니라 런 간 재현성) |

| 0 | 🔴 **baseline 표류** — 주입 전 DO가 네 런 모두 상승 중(+0.012~+0.022 mg/L/100s) | **최우선.** 주입 전 기울기 < 0.002 mg/L/100s 확인 후 시작. 이것 하나가 $t_{95}$·$k_i$·회수율을 모두 되살린다 |
| 1 | **런 간격 부족** (27–38분 = 1.09–1.53$\tau$) | **≥3$\tau$ = 75분** |
| 2 | **기록 길이 부족** (<1$\tau$) | **≥40분 (1.5$\tau$).** 3-파라미터 자유피팅의 조건수가 무너져 $k_i$·$t_{95}$ 산출 실패 |
| 3 | **$t_\text{inject}$ 미기록** | 벽시계 기록. 신호 개시로 대체하면 이송지연만큼 과소평가되어 모든 시간값이 하한이 된다 |
| 4 | **칭량 오차** (저울 0.01 g → 50 mg에 ±20 %) | **stock 용액 분취**: 250 mg/250 mL 조제 후 50 mL씩 → 부피 오차 ~2 % |

추가로 반드시:
- **같은 주입점으로 전 위치를 측정할 것.** 2026-08-01은 pulse4 조건에서 장축 코너만 재서 순위 비교가 불가능했다.
- **프로브 위치를 좌표 (x, y, z) [m] 로 기록.** `플룸_장축_코너` 같은 상대 라벨로는 재현도 CFD 대조도 안 된다.
- **슬러그 반응 완료시간 별도 측정** (10분): 비커에 슬러그 + Co 투입 후 DO 소모 시간. "결손 = 수동 스칼라" 전제를 검증하는 유일한 방법이며, 미검증 시 결론에 경쟁 가설이 남는다.
- 위치당 **최소 2회**. `--note` 의 런 번호 확인(4파일 모두 `pulse1`로 오기).

### 5.5 판정 기준

$t_{95}/(1/K_La)$ < 0.10 성립 · 0.10–0.30 경계 · **> 0.30 불성립**. $1/K_La$=24.8분이므로 $t_{95}$ < 2.5분이면 안전, 7.4분 초과면 불성립.

$t_{95}$ 가 **75 s($3\tau_\text{probe}$) 미만**이면 혼합이 아니라 프로브 지연을 잰 것이다 — 상한만 주장하고 `--deconv` 로 재분석할 것.

## 6. 본시험

**분할축은 $z_\text{start}$(에어스톤 높이)다 — 위치가 아니다.** (2026-07-19 전환, 방법론 §6.2. 위치별 $K_La$ 산포가 CV 5.1 %로 실험 재현성에 묻히기 때문.)
$z_\text{start}$ = **0.02 / 0.08 / 0.14 학습 + 0.17 hold-out** × **반복 3회** = 12런. hold-out은 재피팅 없이 $\kappa$ 적용 → 전이 잔차.
**위치는 분할축이 아니라 강건성 축**이다 — 2–3위치에서 $\kappa$ 가 일치하는지만 본다.

> **⚠ 런당 소요 재추정(2026-07-31 파일럿):** $Q_\text{air}$=1.2 L/min 실측으로 $\tau$=**24.8분**(구 가정 13분의 1.9배). 탈산소 14분 + 안정 20분 + 불응 5분 + 상승 **150분** ≈ **런당 3시간.** 구 "런당 ~40분"은 폐기. 12런이면 **1일 4런 × 3일**.
> 파일럿은 상승 136분에 종료했는데도 기울기가 0.074 mg/L/10분(판정기준 0.02의 3.7배)이라 **평탄부에 못 닿았고 $C^{*}$ 를 확정하지 못했다.** 상승은 $\approx 6\tau$ 로 잡을 것.

각 런:
```bash
python do_logger.py --port COM3 --log run_pos3_rep1.csv --interval 1.0 \
    --note "pos3 rep1, z_start=0.02, Na2SO3 2.0g, Co 30mg, T=24.1C, P=101.0kPa"
```
1. 탈산소(§4 3–4단계) → DO≈0 안정 확인 후 **20분 대기**(잔여 아황산 안정)
2. **폭기 ON** — 이 시각의 `t_sec`를 메모(피팅 `--t0`). `--mark` 는 미구현이므로 **벽시계 수동 기록**
3. **평탄부까지 로깅** — 종료 기준은 시간이 아니라 **기울기 < 0.02 mg/L / 10분**($\approx 6\tau$ ≈ **150분**). **실시간으로 기울기를 확인할 것** — 파일럿은 0.074에서 끊어 $C^{*}$ 를 놓쳤다
4. 물 교체(코발트 잔류) 후 다음 런

**피팅 규약(파일럿 확정):** 유효창 **(lo, hi) = (0.15, 0.92)**. $K_La$ 는 유효창 피팅에서, **$C^{*}$ 는 실측 평탄부에서** 취한다(유효창 피팅의 $C^{*}$ 는 절단 때문에 2.5 % 과소평가된다 — `파일럿_결과_20260731.md` §3.2).

**`--note` 필수 기재:** $z_\text{start}$·폭기위치·수온·기압. 파일럿에서 에어스톤 기하를 안 적어 $\kappa$ 를 확정하지 못했다.

**반복 시 프로브 위치를 바꿔가며** 수행(방법론 §6.1-3).
**`--note` 에 $z_\text{start}$·폭기위치를 반드시 적을 것** — 파일럿은 이를 빠뜨려 $\kappa$ 를 확정하지 못했다.

분석:
```bash
python fit_kla.py "run_z*.csv" --t0 <폭기ON t_sec> --lo 0.15 --hi 0.92 --summary summary_meas.csv
```

## 7. CFD 대조 → $\kappa$

동결 유동(`../CFD/flow/posN/200/`) 위에서 DO 스칼라만 과도적분(가상 재폭기, 방법론 §5) → 벌크평균 곡선을 **같은 `fit_kla.py`로** 피팅 → $\kappa = K_La_\text{eff,meas}/K_La_\text{eff,CFD}$.
CFD 곡선을 로거 CSV와 같은 열 형식(`iso_time, t_sec, do_mgL, sat_frac, temp_C`)으로 내보내면 동일 스크립트가 그대로 돕니다 — **피팅 규약을 강제로 일치**시키는 게 목적입니다(사과-대-사과).

## 8. 안전

- **코발트는 독성.** 실험 후 물을 어류에 재사용 금지, 폐액은 분리 수거.
- Na₂SO₃ 분진 흡입 주의, 장갑·보안경 착용.
- 12V 전원과 수조 — 결선부는 수면에서 멀리, 드립루프 형성.
- 형광막 긁힘 주의(정확도 직결). 사용 전 검은 보호캡 제거, 보관 시 스펀지 습윤 유지.
