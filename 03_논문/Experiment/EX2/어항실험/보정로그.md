## ⚠ 규명 — 런 전 100 % 보정의 스팬 편향 −4.52 % (2026-07-31 사후 분석)

**결론: 위 "100% 재보정(온도 상승 후)" 항목이 실제로 −4.52 % 스팬 편향(과대판독 +4.74 %)을 만들었다.** 당시 메모("수온이 평평해진 뒤 재보정 권장")가 경고한 그대로 물렸다. 다만 당시 적은 "±4 % 이내"는 **실제 편향 4.74 %를 과소평가**한 것이다.

### 증거

| 시점 | 판독 포화 | 비고 |
|---|---|---|
| 런 전 보정 직후, 보정매질 | **103.7 %** | 방금 100 %로 맞춘 매질을 103.7 %로 읽음 → 스팬 오류 확정 |
| 런 시작 수조 (8.594 mg/L @ 24.91 °C) | 104.5 % | |
| 런 종료 수조 (8.547 mg/L @ 25.0 °C, 최종 300 s 평균) | 104.1 % | |
| **사후 재보정 직후 (24.87 °C 안정)** | **99.78 %** | ✅ 정상 |

원인: 100 % 스팬을 **수온 상승 중(27.07 °C)인 공기포화수**에서 앵커했다. 데워지는 공기포화수는 낮아진 $C^*$ 대비 과포화이므로, 이를 100 %로 고정하면 스팬이 그만큼 높게 박힌다.

### 보정계수

사후 2점 보정 후 **같은 수조·같은 온도**에서 재판독:

```
8.150 / 8.163 / 8.151 / 8.167 / 8.172 mg/L   (평균 8.1606, SD 0.0087) @ 24.98 °C
```

분모는 같은 수조의 **재보정 직전** 판독 = 로그 최종 300 s 평균 **8.5473 mg/L @ 25.00 °C**.

$$s = 8.1606 / 8.5473 = \mathbf{0.95476} \quad (-4.52\ \%,\ \text{구 보정이 } +4.74\ \% \text{ 과대판독})$$

**독립 검증 — Benson–Krause 대조:** 재판독 8.161 vs $C^*(24.98\,^\circ\text{C}, 101\,\text{kPa}) = 8.239$ → **99.1 % 포화.** 136분 폭기된 개방 수조로서 물리적으로 타당하다. [R14] *(단 평형 미도달이므로 이 대조는 $s$ 의 부호·자릿수 검증이며 ±1 % 정밀도는 보장하지 않는다 — `파일럿_결과_20260731.md` §2.4)*

> "로그 최종값 × $s$ = 재판독"은 $s$ 의 정의상 항등식이라 **검증이 아니다.** 유효한 독립 검증은 위 BK 대조 하나뿐이다.

### 표류 판정 — 없음

런 시작 104.6 % → 종료 104.1 %, 같은 온도. **136분간 −0.5 %p = 노이즈 수준.** 프로브 시간안정성 합격. 위 104 %는 표류가 아니라 최초 보정의 스팬 편향이다.

### 영향 범위

- **$K_La$: 영향 없음.** **시간불변** 아핀 보정오차 $C_m = sC + b$ 는 지수 감쇠율을 바꾸지 않는다(표류가 없었으므로 조건 충족). 상세 `파일럿_결과_20260731.md` §2.5.
- **$C^*$·절대 DO: $\times 0.95476$ 필요.**
- `pilot_deox.csv` 는 원형 보존하고 계수만 문서에 기록한다.

### 절차 교훈 (→ `실험_SOP.md` §3 반영)

1. **`--calibrate` 는 쓰기 명령이다.** 표류 확인용으로 쓰면 전후 차이를 잃는다. **`--read` 로 먼저 읽어 기록 → 그 다음 `--calibrate`.** 이번엔 수조 데이터로 우회 복구했으나 운이 좋았다.
2. **100 % 보정은 수온이 평평할 때만.** 판정 기준 **3분간 ΔT < 0.05 °C** 를 SOP에 명문화.

### 조치

1. **재보정하지 않는다.** 스팬 편향은 데이터와 $C^{*}_\text{ref}$ 에 같은 배수로 곱해져
   $K_La$·$\kappa$ 에서 상쇄된다(파일럿 §2.5, 실행계획 §2.3 규칙 2). 오염되는 것은
   절대 DO·$\Delta C^{*}$ 뿐이며, **S1 평탄부/B–K 비가 그 보정계수를 직접 준다.**
2. **이 판독은 `--gate drift` 의 `--ref-do` 로 쓰지 않는다** — 평형 매질이 아니라 기준물 자격이 없다.
   대신 **에어펌프를 계속 돌리는 소형 비커**를 세션 내내 표류 기준물로 둔다(온도 추종).
3. `--gate verify` 가 평형 도달한 수조에서 ~104 % 를 내면 그것이 스팬 오프셋이다.
   값만 기록하고 `--expect-sat 96,106` 으로 통과시킨다. **재보정 금지.**
4. 영점 표류: 0 % 환경 read-only 판독은 **미기록**. 세션 마감 시 함께 측정한다.
