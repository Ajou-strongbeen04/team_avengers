## 3. 기포 계면 전달 (신규 확정)

$d_b=0.5$ mm, $U_\text{slip}=0.055$ m/s → $\mathrm{Re}_b = U_\text{slip}d_b/\nu = 27.5$, $\mathrm{Sc}=\nu/D_\text{mol}=500$.

Frössling(구형 기포 표준식):

$$\mathrm{Sh}_b = 2 + 0.6\,\mathrm{Re}_b^{1/2}\mathrm{Sc}^{1/3} = 27.0 \quad\Rightarrow\quad k_{L,b} = \frac{\mathrm{Sh}_b D_\text{mol}}{d_b} = \mathbf{1.08\times10^{-4}\ m/s}$$

**이 $k_{L,b}$ 는 지금까지 문서에 없던 값**이다. 그동안 $a=6\alpha_g/d_b$ 만 있고 짝이 되는 $k_L$ 이 비어 있어서 플룸 전달을 수치로 못 냈다. 수면 $k_{L,20}=2.3\times10^{-5}$ 보다 **4.7배 크다** — 미세기포라 그렇다.

## 4. $K_La_\text{eff,CFD}$ 예측 (현행 $\alpha_g=0.29$ 기준)

계면적 $a = 6\alpha_g/d_b = 6(0.29)/(5\times10^{-4}) = \mathbf{3480\ m^{-1}}$
*(`상수_목록.md`의 3495는 반올림 잔차 — 3480이 맞음)*

**플룸 채널.** 플룸 체류시간 $\tau_\text{res} = H_p/W = 0.19/0.4153 = 0.458$ s, 국소 Damköhler

$$\mathrm{Da}_\text{plume} = k_{L,b}\,a\,\tau_\text{res} = 0.172 \quad\Rightarrow\quad \text{1패스 평형접근율}\ 1-e^{-\mathrm{Da}} = 15.8\,\%$$

즉 **플룸은 "국소 급속포화"가 아니다.** 물이 플룸을 한 번 통과할 때 포화까지 16 %만 다가간다. 따라서 전달은 $k_La$ 가 아니라 **순환 유량으로 제한**되며, 올바른 축약은

$$K_La_\text{plume} = \frac{Q_p}{V}\left(1-e^{-\mathrm{Da}_\text{plume}}\right) = \frac{1.42\times10^{-4}}{0.0207}\times0.158 = 1.08\times10^{-3}\ \mathrm{s^{-1}}$$

단순 체적비 축약 $(V_p/V)k_{L,b}a = 1.08\times10^{-3}$ 과 **0.1 % 이내로 일치** — $\mathrm{Da}$ 가 작아 두 극한이 만나는 영역이라 축약 방식이 결과를 좌우하지 않는다(방어에 유리).

**수면 채널.**

$$K_La_\text{surf} = \frac{k_{L,20}A_s}{V} = \frac{2.3\times10^{-5}\times0.0987}{0.0207} = 1.10\times10^{-4}\ \mathrm{s^{-1}}$$

## 5. ⚠ $\alpha_g$ 자기일관성 — 미해결 (pos1 재실행으로 확인 결정)

> **[2026-07-19 정정]** 이 절의 $\alpha_g\to0.239$(−18 %)는 **pos1 한 점** 기준이며, pos1은 코너 장착이라 16위치 중 $W$ 최대·자기일관 $\alpha_g$ 최소인 **극단값**이다. 16위치 전체 분석 결과 앙상블 고정점은 **$\alpha_g=0.257$ (Su 2.52, −11 %)**, pos1의 $K_La$ 예측은 3.64 → **3.48 /h**($\tau$ 17.2분)로 정정된다. 상세: `16위치_잔차분석.md`. 아래 본문은 이력 보존용으로 남긴다.

`상수_목록.md`는 $\alpha_g = U_{gs}/(W+U_\text{slip})$ 로 0.29를 정했고, 그때 $W\approx0.31$ m/s를 **가정**했다. 그런데 그 $\alpha_g$ 로 돌린 CFD가 내놓은 실제 값은 $W=0.4153$ m/s다. 실측 $W$ 를 되먹여 수렴시키면 ($W\propto \mathrm{Su}^{1/3}$, 부력플룸 이론):

$$\alpha_g \to \mathbf{0.239},\qquad \mathrm{Su}=\alpha_g g = \mathbf{2.35}\ (\text{현행 2.86}),\qquad W = 0.389\ \mathrm{m/s}$$

## 6. ⚠ 프로브 응답지연 — 실험 설계에 직접 영향

SEN0680 응답시간 사양 $\le 60$ s. 위 예측 $\tau=14$ 분(840 s)에 대해

$$\frac{\tau_p}{\tau} = K_La\cdot\tau_p = 0.024\ (\tau_p{=}20\,\mathrm{s}) \sim 0.072\ (\tau_p{=}60\,\mathrm{s})$$

ASCE 청수 산소전달 시험 관행의 "무시 가능" 기준은 $K_La\cdot\tau_p<0.02$ 이다. **현 조건은 이를 넘어선다** → 단일지수로 그냥 피팅하면 $K_La$ 가 수 % 과소평가된다.

**대응(비용 0):**

1. **$\tau_p$ 실측:** 프로브를 무산소액(5 % Na₂SO₃)에서 공기포화수로 **급히 옮기고** 응답곡선을 로깅 → 63 % 도달시간이 $\tau_p$. 3회 반복. (`do_logger.py --log probe_tau.csv --interval 0.5`)
2. $K_La\cdot\tau_p<0.02$ 로 나오면 무시하고 진행.
3. 넘으면 2-파라미터 지연모델로 피팅:
   $$C_m(t) = C^{*} - (C^{*}-C_0)\frac{\tau_p K_La\,e^{-t/\tau_p} - e^{-K_La\,t}}{\tau_p K_La - 1}$$
   → `fit_kla.py` 에 `--tau-probe` 옵션으로 추가 예정.

이건 **실측 $K_La$ 를 계통적으로 낮추는 편향**이라, 보정 안 하면 $\kappa<1$ 이 물리가 아니라 계측 아티팩트로 나온다. $\kappa$ 가 논문의 핵심 산출물이므로 반드시 처리해야 한다.
