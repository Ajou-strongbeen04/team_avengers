## 2. 프로브 스팬 편향 −4.52 % — 규명과 보정

### 2.1 증상

런 내내 폭기된 수조가 **포화 104 %** 로 읽혔다. 물리적으로 설명되지 않는다 — 수심 20 cm 정수압에 의한 과포화는 최대 +1.9 %뿐이다.

### 2.2 원인

`보정로그.md` line 29–32 (런 전 100 % 재보정):

> `--calibrate 100` 재실행. 직후 재확인: 8.224 mg/L, **103.7 %**, **27.07 °C**
> 조치: 더 정밀히 맞추려면 **수온이 평평해진 뒤** 100 % 재보정 권장

**100 % 스팬을 수온 상승 중인(27.07 °C) 매질에서 앵커했다.** 데워지는 공기포화수는 낮아진 $C^*$ 대비 과포화 상태이므로, 이를 "100 %"로 고정하면 스팬이 그만큼 높게 박힌다. 보정 직후 자기 자신을 103.7 %로 읽은 것이 결정적 증거다 — 방금 100 %로 맞춘 매질을 103.7 %로 읽을 수는 없다.

### 2.3 정합성

| 시점 | 판독 포화 |
|---|---|
| 런 전 보정 직후, 보정매질 | 103.7 % |
| 런 시작 수조 (8.594 mg/L @ 24.91 °C) | 104.5 % |
| 런 종료 수조 (8.547 mg/L @ 25.0 °C, 최종 300 s 평균) | 104.1 % |
| **사후 재보정 직후 (24.87 °C, 3회 평탄)** | **99.78 %** ✅ |

네 값이 한 가지 원인으로 설명된다. 또한 **런 시작 104.6 % → 종료 104.1 %** 는 136분간 −0.5 %p로, **시간 표류는 없었다.** 프로브 안정성은 합격이며 방법론 §6의 드리프트 관리 항목은 이번 조건에서 문제되지 않는다.

### 2.4 보정계수

사후 2점 보정 후 **같은 수조·같은 온도**에서 재판독:

```
8.150 / 8.163 / 8.151 / 8.167 / 8.172 mg/L   (평균 8.1606, SD 0.0087) @ 24.98 °C
```

같은 수조의 **재보정 직전** 판독은 로그 최종 300 s 평균 **8.5473 mg/L @ 25.00 °C**. 두 값의 비가 스팬 보정계수다:

$$s = \frac{8.1606}{8.5473} = 0.95476 \qquad (-4.52\ \%,\ \text{즉 구 보정이 } +4.74\ \% \text{ 과대판독})$$

> **분모 정의:** 로그 최종 **300 s 평균**(8.5473). 30 s 평균이면 8.5514 → $s$=0.95430. 차이 0.05 %는 잔여 상승분이며 이하 논의에 영향 없다.

**독립 검증 — Benson–Krause 대조:**

재판독 8.161 vs $C^{*}(24.98\ ^\circ\mathrm{C},\ 101\ \mathrm{kPa}) = 8.239$ → **99.1 % 포화.** [R14] 136분간 폭기된 개방 수조로서 물리적으로 타당하다. 구 보정에서는 같은 물이 **104 %** 로 읽혔다.

> **이 대조의 한계:** 수조가 평형에 도달하지 않았으므로(§3.2) 99.1 %가 곧 "정확하다"의 증명은 아니다. **이 검증이 보장하는 것은 $s$ 의 부호와 자릿수**이며(104 % → 99 %는 물리적으로 불가능한 값을 가능한 값으로 되돌린 것), ±1 % 수준의 정밀도까지는 보장하지 않는다.

> **주의:** "로그 최종값 × $s$ = 재판독" 은 검증이 아니다 — $s$ 의 정의상 항등식이다. **유효한 독립 검증은 위 Benson–Krause 대조 하나뿐**이며, 이것만으로도 충분하다(재판독은 로그와 무관하게 얻은 절대값이고 BK는 외부 표준이다).

### 2.5 $K_La$ 는 보정 편향에 영향받지 않는다

측정값이 참값의 아핀 변환 $C_m = s\,C + b$ (스팬 $s$, 오프셋 $b$)일 때,

$$C_m(t) = (sC^{*}+b) - \big[(sC^{*}+b) - (sC_0+b)\big]\,e^{-K_La\,t}$$

**지수 감쇠율 $K_La$ 는 불변이다.** $C^{*}$ 와 $C_0$ 만 아핀 변환을 받는다. 따라서

- **$K_La_\text{eff}$ = 2.417 /h 는 −4.52 % 스팬 편향과 −0.073 mg/L 오프셋에도 불구하고 유효하다.** 파일럿의 핵심 산출물은 훼손되지 않았다.
- $C^{*}$ 만 $\times s$ 보정이 필요하다.
- **본시험 재측정 불요.** 다만 절차는 §6대로 고친다.

> **성립 조건:** $s,b$ 가 **시간불변**일 때만 성립한다. 본 런은 표류가 없었으므로(§2.3) 충족된다. 표류가 있으면 $s(t)$ 가 되어 이 불변성은 깨진다 — 그래서 §6.1의 `--read` 선행 표류 확인이 필수다.
>
> 일반 결론: 재폭기 시험에서 $K_La$ 는 **시간불변** 프로브 보정오차에 대해 강건하고, $C^{*}$ 는 그렇지 않다.

### 3.3 잔차 구조

유효창 내 잔차는 랜덤이 아니라 U자 구조를 가진다(구간평균 −0.001 → +0.026 → −0.020 → −0.020 → −0.006 → +0.021 mg/L). 어떤 창을 잡아도 이 패턴이 남으므로 창 선택 문제가 아니라 **모델 형태의 계통 편차**다.

다만 진폭이 ±0.029 mg/L = $C^{*}$ 의 **0.35 %** 로 작고, 10분 비겹침 블록의 기울기 감쇠비가 **0.69** (1차 이론 $e^{-K_La\cdot 10\,\text{min}} = 0.67$)로 1차 지수와 잘 맞는다.

```
+21분 1.403 → 0.950 → 0.649 → 0.450 → 0.312 → 0.221 → 0.157 → 0.129 → 0.090 → 0.074  [mg/L / 10분]
```

**0-D 단일지수 축약은 유효하다고 판정한다.**

## 4. 불응 구간 (dead time) — 본시험 필수 반영

폭기 ON($t$=1730 s) 후 **약 320 s (5.3분) 동안 DO가 오르지 않았다.** 유입 O₂ 를 잔여 아황산염이 전량 소모하는 구간이다(방법론 §4 주의 ①).

- 유효창 lo=0.15가 이 구간을 자동 배제한다(유효창 시작 $t$=565 s > 320 s). 현행 규약으로 안전하다.
- 다만 **Na₂SO₃ 투입량을 줄이면 불응 구간이 짧아진다.** 2.5 g은 이론량 1.37 g의 1.8배로 방법론 §4 권장 범위(1.5–2배)의 **상한 근처**다. 본시험은 **2.0 g (1.5배)** 로 **확정**한다.
- 본시험 런당 소요 추정: 탈산소 14분 + 안정 20분 + 불응 5분 + 상승 **150분**(평탄부 도달까지, $\approx 6\tau$) ≈ **3시간.** SOP §6의 "런당 ~40분"은 $Q_\text{air}$=2 L/min·$\tau$=13분 전제였으므로 **전면 수정 필요**(§6). 12런이면 **1일 4런 × 3일**.

## 5. CFD 대조 — $\kappa$ (잠정)

`../../상수_목록.md` D-1 각주의 medium 앵커 **m21**:

$$K_La_\text{CFD} = 2.604\ \text{/h}\qquad (\tau = 23.0\ \text{분},\ C^{*}_\text{CFD} = 8.264\ \text{mg/L @ 25 °C})$$

$$\kappa = \frac{2.417}{2.604} = \mathbf{0.928} \qquad \kappa_{T\text{-corr}} = \frac{2.407}{2.604} = 0.924$$

**해석:** CFD가 실측보다 산소전달을 **7.7 % 과대예측**한다. $\kappa$ 가 1에 가깝다는 것은 전달 폐합($a = 6\alpha_g/d_b$, Frössling $k_{L,b}$, 수면항 $k_{L,s}A_s/V$)이 자릿수 맞추기 수준이 아니라 **정량적으로 옳은 방향**임을 뜻한다. 논문 §4.1의 캘리브레이션 주장에 유리한 결과다.

### 5.1 $\Delta C^{*}$ — 기준압 통일 필요

$C^{*}_\text{CFD}$=8.264는 **101.325 kPa(1 atm)·25.0 °C** 값이다. 서로 다른 기준압을 빼면 순수한 단위 규약 차이가 $\Delta C^{*}$ 에 섞여든다.

> **주의:** `fit_kla.py` 가 출력하는 `C* (B-K)` 는 기본값 $P$=101.325 kPa 에 **런 평균 수온 25.18 °C** 를 넣은 값(8.236)이다. 25.0 °C·101 kPa 값(8.237)과 수치가 비슷하지만 **다른 양이다.** 혼동하지 말 것.

101 kPa로 통일하면 $C^{*}_\text{CFD} \to 8.264 \times \frac{101.0 - p_w}{101.325 - p_w} = 8.237$ ($p_w$=25 °C 수증기압 3.17 kPa) 이므로

$$\Delta C^{*} = 8.161 - 8.237 = \mathbf{-0.076\ \text{mg/L}\ (-0.92\ \%)}$$

**단, $C^{*}_\text{meas}$ 가 하한이므로(§3.2) 성립하는 것은 부등식 $\Delta C^{*} \geq -0.076$ 뿐이다.** 참 $C^{*}$ 가 8.237을 넘으면 $\Delta C^{*}$ 는 양수가 되며, §3.2의 기울기 외삽(≈8.35)은 실제로 그 가능성을 시사한다. **$|\Delta C^{*}|$ 의 상한은 주장할 수 없다.** 통일 전 값(−0.100, −1.21 %)은 폐기한다.

> **근본 해결은 `--set-pressure`.** 현지기압을 입력하면 센서가 같은 기준으로 환산하므로 이 문제가 사라진다. 본시험 전 필수(§6.1).

### ⚠ 확정값으로 쓰기 전 확인할 것

1. ~~에어스톤 높이~~ **✅ 해소(2026-08-01):** $z_\text{start}$=**0.02** 로 측정했음을 확인. m21 앵커 조건과 일치한다. **다만 수평 위치(pos1 = 0.02, 0.035)는 여전히 미확인** — 위치별 $K_La$ 산포는 CV 5.1 %(방법론 §6.2)로 작으나 $\kappa$ 3자리 확정에는 영향한다.
2. **단일 런이라 불확도가 없다.** 피팅 표준오차 ±0.002 /h 는 곡선 적합도일 뿐 재현성이 아니다. 방법론 §3-6의 2–3회 반복이 필요하다.
3. **기압.** 파일럿은 `--set-pressure` **미실시** 상태로 로깅했고 $P$=101 kPa 를 가정했다. 설정은 2026-08-01에 완료(101.0 kPa)했으나 **파일럿 데이터는 설정 이전 프레임**이다. mg/L 은 이론상 기압 불변이나 펌웨어 확인이 필요하다(`보정로그.md`).
4. **m21이 3-D 과도적분 결과인지 확인.** D-1 표기상 3-D 열(2.703 @coarse)과 각주(2.604 @medium)가 병존한다. 방법론 §5가 요구하는 것은 **3-D 과도적분 곡선을 `fit_kla.py` 로 같은 창(0.15, 0.92)에서 피팅한 값**이므로 `../CFD/reaer/` 산출물로 조건을 확인해야 한다.
5. **$C^{*}$ 하한 문제(§3.2).** $\kappa$ 자체는 $K_La$ 비라 영향 없으나 $\Delta C^{*}$ 는 영향받는다.

### 6.2 확정 파라미터

- 유효창 **(0.15, 0.92)** — 모든 실측·CFD 피팅에 공통 적용
