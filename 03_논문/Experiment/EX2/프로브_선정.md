## 왜 SEN0680인가 — §12 요건 대조

| §12 요건 | SEN0680 사양 | 판정 |
|---|---|---|
| **센서 방식 = 광학식 필수** (저유속 정체역에서 갈바닉/Clark은 O₂ 소비·유속의존 → 가짜 저산소역) | **형광법(Fluorescence)** — O₂ 무소비·유속 무의존 | ✅ **핵심 통과** |
| 값 분해능 ≤0.01~0.05 mg/L | **0.01 mg/L** | ✅ (게다가 ΔDO 상향으로 요건 완화됨) |
| 절대정확도 ±0.1~0.3 허용(캘리브레이션 자유도) | ±3% FS (≈±0.6 mg/L) | △ 절대값은 2점보정·기준프로브 정규화로 흡수(§6) → 허용 |
| 로깅(≥1 Hz 목표) | RS485 ModBus-RTU, Arduino/PC 예제 제공 | ✅ 다지점 1버스 동시 로깅 |
| 예산 ₩50만(2개) | 2개+인터페이스 ≈₩33–48만 | ✅ |
| **팁 ≤4~5mm** (바닥 z=0.03 급구배) | 산업형 바디(약 Ø27mm급) | ❌ **미달 — 유일한 미충족(아래 대응)** |

**전기화학은 방식 자체가 배제**되므로 저가 갈바닉(예: DFRobot SEN0237)은 고정 기준용으로도 쓰지 않는다. 두 프로브를 동일 형광법으로 통일하면 기준↔이동 절대값 교차보정(§6)도 깔끔하다.

## 유일한 미충족(팁 크기) — 대응

팁 ≤5mm를 광학으로 만족하려면 **광섬유 마이크로센서**뿐인데(하단 참조) 리더기 포함 수백만 원이라 예산·대여 불가 조건과 충돌. 따라서 팁 크기는 양보하고 다음으로 상쇄한다.

1. **ΔDO 상향(사용자 방향):** 전류 $I$를 올려 목표 ΔDO를 §3 기준(0.5~1 mg/L)보다 크게(예 2~3 mg/L) 잡으면 큰 팁의 공간평균에도 저산소 신호가 살아남는다.
2. **CFD 동일-볼륨 비교:** 점대점 대신 프로브 감지영역과 같은 셀 묶음으로 CFD를 **볼륨평균**해 대조(§8의 프로브 유/무 CFD 케이스와 결합).
3. **격자 정합:** §4에서 이미 12점을 "잠정·CFD 후 재검토"로 둠 — 큰 팁으로 못 잡는 바닥 급구배 구간은 CFD로 보간하고, 저산소역 추가점은 CFD 뒤 확정.
4. **삽입 교란 정량화:** Ø27mm 2개는 국소 blockage가 있으므로 §8대로 CFD로 교란 크기를 정량하고 허용범위 명시.

## 로깅·운용 메모

- **2채널 1버스:** 두 SEN0680의 ModBus 주소를 서로 다르게 설정(공장 기본 모두 1) → USB-RS485 1개로 폴링. 폴링 간격·응답대기 ≥200 ms.
- **응답시간 ≤60s의 함의(중요):** §5의 "지점당 정착 1~2분"은 응답 수십 초 가정. SEN0680은 ≤60s이므로 **지점당 정착을 응답의 3~5배 = 약 3~5분**으로 잡아야 안전. → 이동 11점 1순회 ≈ **45~70분**(§5 추정과 정합, 상단). 장이 준정상이라 순서 무관.
- **전원:** DC10–30V 필요(아두이노 5V 직결 불가) → DC12V 어댑터 + 단자대.
- **보정(§6):** 0%(아황산나트륨 Na₂SO₃ 무산소액)·100%(충분폭기 평형)로 두 프로브 각각 2점보정, 측정 전·후 재실시로 표류 확인. 측정 중 고정 프로브로 벌크 드리프트 정규화.

## 예산이 열릴 경우 — 업그레이드 경로(이동 프로브만)

팁 크기·응답속도가 실제로 결과를 흔들면 **이동 프로브만** 광섬유로 교체:

- **PyroScience OXROB10** (fiber-optic, **Ø3mm·길이10cm**, REDFLASH, O₂ 무소비, 드리프트 무시) + **FireSting-GO2**(포켓형, 배터리·디스플레이·독립 로깅) 또는 FSO2-C1.
- 팁 ≤5mm·빠른 응답(초 단위)·저드리프트로 §12를 전부 충족. 단 **견적가 수백만 원(리더기 포함)**, 견적 문의 필요. 고정 기준은 SEN0680 유지.
