## 1. 무엇을 계산하나

**3케이스만 돈다.** 실측 5런이 쓴 에어스톤 높이가 세 개뿐이기 때문이다.

| case | $z_\text{start}$ | $H_p$ | 플룸 층수 | 대응 실측 |
|---|---|---|---|---|
| `e02` | 0.020 m | 0.190 | 43.4 | **S1 · S2 · S3** (생산 운전점, $n$=3) |
| `e08` | 0.080 m | 0.130 | 29.7 | **S4** |
| `e17` | 0.170 m | 0.040 | 9.1 | **S5** (hold-out) |

폭기축은 셋 다 **(0.035, 0.195)** — 실험이 실제로 쓴 자리다. 바뀌는 건 $z$ 뿐이며,
이는 실측의 분할축 설계와 정확히 같다.

**유동해는 수온과 무관하다**($\nu$ 고정). 그래서 동결 유동장 3개로 **실측 5런을 전부** 덮는다.
수온은 스칼라(재폭기) 단계에서 런별 실측값으로 들어간다.

### 재폭기 — 실측과 같은 프로토콜

$$\frac{\partial C}{\partial t} + \nabla\!\cdot(\overline{\mathbf U}C) = \nabla\!\cdot\!\big(D_\text{eff}\nabla C\big) + S_\text{plume} + S_\text{surf},\qquad D_\text{eff}=D_\text{mol}+\frac{\nu_t}{Sc_t}$$

- **$C(\mathbf{x},0)=0$ 전역** — 실측의 Na₂SO₃ 탈산소 상태에 대응. 요청하신 "산소 0에서 출발".
- $S_\text{plume}$ = 플룸 셀존 체적소스 $k_{L,b}a\,(C^{*}-C)$, $a=6\alpha_g/d_b$
- $S_\text{surf}$ = 표층 Robin $-D_\text{eff}\partial_n C = k_L(C^{*}-C)$
- 바닥·유리 4벽 무플럭스 (SOD·생물·국소싱크 전부 없음)
- $C^{*}(T)$ = Benson–Krause [R14] — 실측 `fit_kla.py` 와 **같은 함수**
- 피팅: 유효창 frac **(0.15, 0.92)**, 모델 $C^{*}$ 자유 — 실측 **규약 C** 와 같은 규약

## 2. ★ 새로 생긴 것 — 프로브별 국소곡선 피팅

**실측 $K_La$ 는 프로브 1점 판독에서 나온 값이다.** 구 CFD 는 체적평균만 냈으므로
$\kappa$ 를 만들 때 사과-대-오렌지였다. CFD 는 실측이 실제로 꽂았던 좌표에서
**국소 $C(\mathbf{x},t)$ 를 뽑아 체적평균과 같은 유효창으로 각각 피팅**한다.

그래서 $\kappa$ 가 두 벌 나온다.

| 기준 | 의미 |
|---|---|
| $\kappa_\text{bulk}$ = $K_La_\text{meas}/K_La_\text{CFD,체적평균}$ | 구 규약. 전달 총량 대조 |
| **$\kappa_\text{probe}$** = $K_La_\text{meas}/K_La_\text{CFD,같은좌표}$ | **진짜 1:1.** 프로브 편향이 상쇄된다 |

둘이 갈리면 그 차이가 곧 **프로브 위치 편향의 정량값**이다 —
$t_\text{mix}$ 불성립·2구획 응답·S5 비지수 구조를 설명하는 데 직접 쓰인다.

부수 소득으로 **미결 #10(위치 강건성 1.44 %의 CFD 대조군 부재)이 닫힌다.**
S1 해 하나에서 세 좌표를 동시에 뽑으면 수온·유동장이 같으므로 **순수 위치효과**다.

## 3. 실행

### 3.1 유동해 (OpenFOAM 필요)

```bash
cd 03_논문/Experiment/EX2/CFD
python3 gen_cases.py --list        # 목록·예상시간 확인
bash run.sh 2>&1 | tee run.log     # stage1 → 고정점 → stage2 → verify
```

`run.sh` 가 하는 일:

1. **stage1** — 3케이스를 시드 $\mathrm{Su}$=1.751 로 실행 (케이스당 ~89분, 합 ~4.5 h)
2. **고정점** — 각 케이스의 플룸 $W$ 를 재서 $\alpha_g = U_{gs}/(W+U_\text{slip})$ 를 수렴시킴
3. **stage2** — $\mathrm{Su}$ 이동이 3 % 를 넘는 케이스만 재실행
4. **verify** — 되먹임 잔차 ±3 % 검정

> ⚠ **폭기축을 옮겼으므로 구 $\alpha_g$ 표(`상수_목록.md` §D-1)를 그대로 쓸 수 없다.**
> 벽·코너 근접이 달라지면 $W$ 가 달라진다. 반드시 재수렴시킬 것.

### 스팬 오프셋이 $K_La$ 를 오염시키지 않는 이유 (검토 완료)

실측 프로브는 B–K 대비 **+3.10 %** 를 읽는다($C^{*}_\text{ref}$ 8.659 vs B–K 8.398).
그런데 유효창은 $\text{frac}=(C-C_\text{min})/(C^{*}_\text{ref}-C_\text{min})$ 로 잡으므로
**분자·분모에 같은 배율이 곱해져 상쇄**된다. 즉 실측의 창 (0.15, 0.92)는
참 포화도 기준 (0.15, 0.92)와 같고, CFD 의 창과 일치한다.
→ **$K_La$·$\kappa$ 비교에 스팬 보정($s$=0.9732)을 곱하지 않는다.**
(절대 DO·$\Delta C^{*}$ 에만 곱한다 — 종합분석 부록 D.3 유지.)

## 6. 이 폴더가 답하는 질문

1. **$\kappa$ 의 절대값은 얼마인가** — 미결 #9. 구 $\kappa$(0.952 / 1.060)는 실험과 다른
   폭기 위치에서 나온 분모라 위치별 산포 12~14 % 만큼 흔들렸다. 이제 같은 자리다.
2. **$z$=0.02 만 10 % 어긋나는 게 진짜인가** — 폭기축·격자·$\alpha_g$ 를 전부 실측에
   맞춘 뒤에도 남으면 그건 물리다. 사라지면 원인은 구 셋업이었다.
3. **위치 강건성 1.44 %의 CFD 대조군** — 미결 #10. §2 참조.
4. **곡선 모양(2구획 응답·S5 비지수)이 CFD 에서도 나오는가** — 프로브 국소곡선의
   단일지수 잔차로 직접 본다. CFD 는 선형계라 체적평균은 단일지수에 거의 완전일치한다;
   국소곡선에서 misfit 이 나오면 **그게 공간구조의 증거**다.

> ⚠ **이 폴더의 결과가 나오기 전까지 구 $\kappa$ 값(0.952 / 1.060)을 논문에 확정으로 쓰지 않는다.**
> 직접 실측인 $K_La_\text{meas}(25\,°\text{C}, z{=}0.020)$ = 2.479 ± 0.036 /h 는 **불변**이다 —
> CFD 를 경유하지 않은 값이라 여기 결과와 무관하다.
