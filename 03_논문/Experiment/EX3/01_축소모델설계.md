## 0. 이 모델이 하는 단 하나의 일

```
사진 → 구조물 배치 → [축소모델] → 국소 저산소역 확률맵
```

풀 CFD는 사용자 기기에서 실시간으로 못 돈다. 그래서 CFD로 (배치 → 유동/DO)를 **오프라인 대량 생성**해 두고, 그 데이터로 **온라인 추론기(ROM)**를 학습한다. 추론 시엔 사진에서 뽑은 배치를 넣으면 **어디가 저산소 위험 영역인지 확률로** 즉시 돌려준다.

포지션은 자율주행이 아니라 **계기판 경고등** — DO 절댓값 정밀 예측이 아니라, **저산소 영역을 공간적으로 확률 판정·표시**하는 것이 목적이다(`CLAUDE.md` 방향).

## 1. 핵심 구조 — 연산자 분할 2계층 (A층 / B층)

DO는 **수동 스칼라(passive scalar)**다. 이 농도대역에서 부력 되먹임이 없어 유동 $\mathbf U$ 가 농도 $C$ 에 의존하지 않는다. 그래서 지배식

$$\frac{\partial C}{\partial t}+\nabla\cdot(\mathbf U C)=\nabla\cdot(D_\text{eff}\nabla C)+\Sigma S$$

은 $\mathbf U$ 를 고정하면 $C$ 에 대해 **선형**이다. 이 성질이 파이프라인을 두 계층으로 깨끗이 나눈다.

| | **A층 — 기하 → 유동** | **B층 — 유동 → DO 확률** |
|---|---|---|
| 하는 일 | 구조물 배치에서 시간평균 유동장 $\overline{\mathbf U},\nu_t$ 예측 | 유동장 위에 소스·임계를 얹어 이송확산 풀이 → 저산소 확률맵 |
| 의존성 | **기하 + (고정)폭기·수온** 만. 생물·임계와 무관 | 생물 소스, $Sc_t$, 어종 임계 |
| 비용 | 비쌈(과도 URANS). 오프라인 대량생성·대리모델 학습 | 쌈(고정 유동장 위 스칼라 풀이) |
| 상태 | **★ 현재 작업 — `02_A층_유동대리모델.md`** | 협의·결정 후 착수 |

**왜 이렇게 나누나 — 장애물 격리.** A층은 (a) `기하인식/`의 미확정 출력 스키마, (b) 미결정 생물 소스, (c) 미결정 어종 임계 셋 모두와 **독립**이다. 그래서 지금 병렬 선행할 수 있는 유일한 계층이 A층이다. 세 인터페이스가 닫히면 얇은 어댑터·소스 항만 B층에 붙인다.

> `CFD = 오프라인 생성기, ROM = 온라인 추론기`. 비싼 것은 운동량(A층)이므로 그것만 미리 얼려 데이터화하면, 남는 B층은 싼 선형 스칼라 층에 갇힌다(생물항이 비선형이어도 비용 문제가 안 됨).

## 2. 추론 흐름 (3단계)

```
1. 사진 → 구조물(돌·식물의 개수·크기·위치)                      [기하인식]
2. 그 기하 → A층 ROM이 유동장(U, ν_t)을 예측(보간)              [A층 대리모델]
3. 유동장 + 소스 + 독립입력 → 이송확산 풀이 → DO장·저산소 확률맵  [B층]
```

**1단계** 사진에서 구조물 파악(`기하인식/`).

**2단계 — 조회가 아니라 예측이다.** 촬영 기하가 미리 계산해둔 케이스와 정확히 일치하는 일은 거의 없다. 따라서 저장고에서 "일치하는 유동장을 꺼내오는" 것이 아니라, **데이터로 학습한 A층 ROM이 촬영 기하에 대해 유동장을 예측(보간)**한다. 이 일반화가 ROM을 두는 이유다(상세 `02_A층_유동대리모델.md`).

**3단계 — 유동장 위에 소스와 독립입력을 얹는다.**

- 유동장 $\overline{\mathbf U},\nu_t$ (2단계 산출).
- DO 소스/싱크: 표면 재폭기(수면, $C^*(T)$ 의존), 어류 호흡(마릿수 비례 싱크), SOD(바닥 싱크), 식물 대사(광합성+/호흡−, 주야).
- 독립입력: 수온(→ $C^*$·대사율 $Q_{10}$), 물고기 마릿수, 주/야.

> **정합성 주의 — 식물 크기는 A·B 양쪽에 들어간다.** 식물 크기는 (a) 항력으로 **유동장**을 바꾸고(A층에 이미 각인), 동시에 (b) 대사로 **DO 소스**를 만든다(B층). 같은 식물 기술자를 두 층이 공유해야 하며, "작은 식물 유동장 + 큰 식물 대사" 같은 불일치는 금지. 반면 **돌은 고체라 대사 없음** → 유동장(A층)에만 영향, DO 소스 없음.

> **수온을 B층 독립입력으로 두는 것은 근사다(대체로 허용).** 수온은 엄밀히는 점도 $\nu$ 로 유동장(A층, 25 °C 고정)에도 영향을 준다. 그러나 가정 어항 작동대역(약 22–28 °C)에서 유동은 폭기 운동량 지배(고 $Re$)라 정규화 유동구조·저산소역 위치는 수온에 둔감하고, 수온의 1차 효과는 $C^*$·대사율이며 이는 B층에 들어간다. 온도성층(부력)이 폭기로 깨진다는 가정 하에 성립.

## 3. 출력 — 저산소 **확률**맵

**결정(2026-07-16): 출력은 분류 라벨이 아니라 셀별 저산소 확률이다.** 각 셀 $\mathbf x$ 에서

$$P_\text{hypoxia}(\mathbf x)=\Pr\big[\,\overline C(\mathbf x) < C_\text{crit}(\text{어종})\,\big]$$

을, 아래 §4의 불확실성 위에서 적분해 얻는다. 어항 단면/평면에 오버레이 → "여기가 위험" 경고등.

- **왜 확률인가**: 선형성 덕에 소스·연산자 불확실성이 필드 분포로 전파된다(§1). 저산소역 **위치**는 평균유동이 정해 강건하지만, 임계 **교차 여부**는 생물 레벨·재폭기에 달려 불확실 → 이 둘을 확률이 자연스럽게 분리 표현한다(위치는 자신있게, 레벨/경계는 확률로).
- 부가 스칼라: 최악 저산소역 위치, 저산소 기대 체적분율.
- **임계 재사용성**: 저산소 임계 $C_\text{crit}$ 는 어종마다 다르므로, 오프라인 데이터셋은 **임계-무관 원장**(전장 $\overline C$ 또는 그 분포)을 저장하고, 확률맵은 선택 임계로 후단에서 파생한다(`03_어류건강도` 정합). 데이터 한 벌로 여러 어종 커버.

## 4. 확률의 근원 — 불확실성 채널 (배분은 논의 후 확정)

| 채널 | 성격 | 근거 | 전파 방식 |
|---|---|---|---|
| $Sc_t$ 캘리브레이션 밴드 | 연산자(수송) | `03_논문`의 sim-현실 이격(0.7/0.85/1.0) | $D_\text{eff}=D_\text{mol}+\nu_t/Sc_t$ 곱셈 — **B층에서 URANS 재실행 없이 무비용 스윕** |
| 생물 소스 율 | 소스 | 어류 호흡·SOD·식물 대사 문헌 범위, 주/야, 마릿수 | 선형 중첩 → 해석적/저비용 몬테카를로 |
| 기하 입력 | 입력측 | 사진→BC 추정의 `unresolved_fields`·차단율 오차 | 입력 분포로 전파(보수적) |
| ROM 예측 오차 | 근사측 | A층 대리모델 자체 분산 | 앙상블/베이지안(선택) |

**물리적으로 가장 정당하고 `03_논문`과 직결되는 것은 연산자 채널($Sc_t$ 밴드) + 소스 채널(생물률)** 이다. 나머지 둘(입력·근사)은 성격이 달라 별도로 다룬다. 채널 조합·가중은 예비 데이터 후 확정.

> 선형성이 깨지는 지점(정직 표기): 실제 호흡은 저산소에서 O₂ 제한(Michaelis–Menten)으로 감속 → 임계 근처에서 $C$ 의존성이 살아난다. 자기제한 비선형이라 상수율 가정은 저산소를 **과대예측(보수적·안전)**. 경고등 포지션엔 상수율을 기준으로, M-M은 필요시 정밀 축으로 연다.

## 5. `03_논문` 상속과 EX2 캘리브레이션 전이

**전이되는 것 = 연산자 레벨 이격**($Sc_t$ 밴드, 메시/GCI, 위치를 정하는 평균유동). 저산소역 위치는 기하·운동량이 정하고 `03_논문`이 검증한 부분이라 강건 → A층이 이를 그대로 계승한다.

**전이되지 않는 것 = 절대 DO 레벨.** EX2 실측 앵커가 아직 없어(공간·실험설계 제약) 레벨은 문헌 조건부다. 현 단계 확률은 "문헌 생물률 + $Sc_t$ 밴드 조건부"로 정직하게 표기하고, EX2가 열리면 $n{=}0$ 지점이 밴드 중심을 실측 허용오차로 고정하는 앵커가 되어 밴드가 좁아진다.

## 6. 검증 (실측 공백을 대신하는 내부 게이트)

- **A층 데이터 게이트**: $n{=}0$ 회귀(구조물 없을 때 EX2 기준 재현), 격자수렴(GCI) 상속·재점검, 준정상·질량보존 잔차, 물리 sanity(후류 저유속·폭기근처 고유속). 통과 케이스만 채택.
- **평균장 근사 게이트(★ 03_논문 연장)**: 시간평균 유동장 위 정상 스칼라 풀이는 해상-비정상 와류의 분산을 놓친다. 고정소스 기준케이스에서 *비정상 공동풀이* vs *평균장 정상풀이*를 비교 → 저산소역 **위치 일치** 확인(위치 목적 검증), 레벨 차이는 $D_\text{eff}$/$Sc_t$ 밴드로 흡수. 상세 `02_A층_유동대리모델.md` §5.
- **A층 ROM 게이트**: 홀드아웃 기하에서 유동장 예측 오차·저산소역 위치오차, 학습곡선.
- **강건성 게이트**: $Sc_t$ 밴드 재현 → 저산소역 위치의 밴드 내 불변성.
- **최종(향후)**: EX2 실측이 열리면 blind 테스트로 레벨/임계 확정.

## 7. 기하인식·건강도와의 병렬 접합

- **↔ 기하인식(`기하인식/`)**: 출력 스키마 미확정. A층은 자체 기하 파라미터로 선행하고, 확정 시 **어댑터(01 출력 → 기하 파라미터)**만 붙여 잇는다 → 비싼 A층 데이터셋을 인터페이스 변동에서 격리(§1).
- **↔ 건강도(`../03_어류건강도`)**: 저산소 임계 $C_\text{crit}$·위험선을 공급 → §3 확률맵 임계로 사용. 데이터셋은 임계-무관 원장이라 어종 추가 시 재생성 불필요.
