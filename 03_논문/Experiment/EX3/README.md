# 02 · BC 축소모델 (ROM)

> 정합: `../../../04_소웨.md` §3 · 입력 계약 `기하인식/03_BC_출력스키마.md` · 특허 C4

## 개요
풀 CFD는 사용자 기기에서 실시간 불가 → CFD로 생성한 ground-truth로 **축소모델(ROM)/대리모델**을 학습.
추론 흐름: 사진 → 구조물 배치 → 유동장 예측 → 이송확산 → **저산소 확률맵**.
`CFD = 오프라인 생성기, ROM = 온라인 추론기`.

## 핵심 구조 — 연산자 분할 2계층 (`01_축소모델설계.md` §1)
수동 스칼라라 운동량이 DO와 분리 → 파이프라인을 두 계층으로 나눈다.

- **A층 (기하 → 유동)**: 비쌈·기하전용. 생물·임계와 독립이라 **지금 병렬 선행 가능한 유일 계층 → 현재 작업**. 상세 `02_A층_유동대리모델.md`.
- **B층 (유동 → DO 확률)**: 유동장 위 소스·임계를 얹는 싼 선형 스칼라 층. 협의·결정 후 착수.
