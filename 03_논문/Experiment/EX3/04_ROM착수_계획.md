## 1. 파이프라인 개요

```
[253 OpenFOAM 케이스]
    │  ① 후처리(리샘플·인코딩)
    ▼
[정렬 텐서]  X: 점유격자(occupancy+kind)   Y: 유동장(UMean, nut, phi)
    │  ② 분할 (층화 10 = test / 나머지 = train+val)
    ▼
[ROM 학습]  트랙 A: POD+회귀   ‖   트랙 B: CNN(U-Net)
    │  ③ 공통 지표로 비교
    ▼
[선정 ROM] → B층 핸드오프(동결 유동장 위 이송확산)
```

## 2. 단계별 계획

### Stage 0 — 후처리: 케이스 → 정렬 텐서 (선행 필수)

QC 문서 권고 1번. ROM 어떤 방법이든 공통으로 필요한 단 하나의 자산.

- **입력 X (기하 인코딩)** — 각 케이스 `topoSetDict`의 porosity cell-zone을 108×48×48(또는 리샘플) 격자에 투영:
  - 채널 1: 점유(0/1)
  - 채널 2: kind (rock=1 / plant=−1, 빈 셀 0) — 또는 별도 원-핫
  - (선택) 채널 3: plant 항력계수 C_F 값 (rock은 near-solid f=1000, plant f∈{2,5,15})
  - 병행: **파라메트릭 X**(`cases.csv`의 n_obstacles·pos·size·blockage_frac)도 조인 저장 — POD 회귀 헤드가 이걸 특징으로 쓴다.
- **출력 Y (유동장)** — `UMean`(3ch), `nutMean`(1ch), `phiMean`(면유량, B층 이송항용). `grid_spec.json` 규약대로 정규격자·정규화 좌표에 매핑.
- **해상 결정** — 우선 **native 108×48×48** 로 진행(리샘플 손실 0, 이미 정렬됨). 용량/속도 문제 시 grid_spec의 96×48×48 또는 저해상 64×32×32로 축소. 위치판정 목적상 저해상도 후보(학습곡선에서 검증).
- **산출물** — `training_dataset/fields/caseXXXX.npz`(X_occ, Y_U, Y_nut, Y_phi) + `labels.parquet`(case_id ↔ QoI·meta) + `grid_spec.json` v1 확정.
- **게이트(QC 권고 5):** 1케이스에서 `phiMean` 셀별 연속성 잔차 Σ_f φ ≈ 0 확인 — 동결 유동장 위 scalarTransport(B층) 질량보존 전제.

> 24 GB 원본은 리샘플·QoI 추출 후 `.tgz`만 남기고 디렉터리 정리 가능(현재 중복 보관 중).

### Stage 1 — 데이터 분할: 층화 테스트셋 10

**층화 축**(대표성 확보 — 특정 조건이 테스트에서 누락되지 않도록):

- n=1 : n=2 비율을 전체(60:192 ≈ 1:3)에 맞춰 → 대략 **n=1에서 2~3개, n=2에서 7~8개**
- kind(rock/plant) 양쪽 포함
- size class S/M/L 각각 최소 1개(S 편중 보정 겸)
- blockage 상·하위 구간 모두 포함
- Tier0(case0000, n=0 회귀 게이트)는 **train 고정**(테스트 아님 — 상속 검증용 앵커)

절차: cases.csv에 (n, kind, size, blockage-bin) 복합 라벨 부여 → 각 층에서 시드 고정 무작위 추출 10개 → `test_split.json`으로 동결(재현성). 나머지 243(=253−10)에서 val 20% 홀드아웃 또는 K-fold.

### Stage 2 — ROM 학습 (두 트랙 병행)

**트랙 A — POD + 회귀 (베이스라인, 경량·해석적)**

1. 전 학습케이스 UMean·nut을 평균 차감 후 스택 → SVD로 POD 모드 추출. 에너지 99% 커버 모드 수 r 결정(저산소역은 저유속 구조라 소수 모드로 잡힐 것 예상).
2. 기하 파라미터(파라메트릭 X 또는 점유격자 축소특징) → 모드계수 a_i 회귀. 회귀기: 우선 GPR/랜덤포레스트/얕은 MLP 비교.
3. 재구성 Ŷ = 평균 + Σ a_i·φ_i.
- 장점: 학습 수백 케이스로 충분, 추론 즉시, 기저 해석 가능. 파일럿 확정 우선순위.

**트랙 B — CNN / 3D U-Net (표현력)**

1. 입력: 점유격자(+kind/C_F 채널) 108³급 3D 볼륨.
2. 출력: UMean(3ch)+nut(1ch) 볼륨 회귀. Encoder-decoder(3D U-Net), skip-connection.
3. 손실: 유동장 MSE + (선택) 저산소역 마스크 가중 손실(저유속대 정확도 강조).
- 장점: 후류 간섭 등 비선형 상호작용 표현. 단점: 데이터·연산 더 필요 → 학습곡선으로 253개 충분성 판정.

두 트랙은 **동일 X/Y 텐서·동일 분할**을 공유하고 아래 §3 지표로 정면 비교한다.

### Stage 3 — 평가·게이트 (`02_A층_유동대리모델.md` §5 상속)

| 게이트 | 판정 | 통과선(잠정) |
|---|---|---|
| n=0 회귀 | case0000 재구성이 EX2 기준 재현 | 평균|U| 오차 ≤ 5% (파일럿 −4.2% 확인됨) |
| 유동장 정확도 | 홀드아웃 UMean 상대 L2 | — (학습곡선 기준) |
| **저산소역 위치오차** | 최저유속점 좌표 오차 | **≲ 1셀** (계기판 포지션의 핵심 지표) |
| nut 재현 | D_eff 재료 정확도 | 상대 L2 보고 |
| phi 연속성 | Σ_f φ ≈ 0 (B층 전제) | 잔차 O(1e-7) |
| Sct 밴드 강건성 | 0.7/0.85/1.0 스윕서 저산소역 위치 불변 | 위치 밴드내 불변 |

**주 지표 = 저산소역 위치오차.** 절대 DO 레벨이 아니라 "어디가 위험한가"를 맞히는 게 목적(계기판 경고등 포지션).

### Stage 4 — 학습곡선 (예산 배분 근거, QC 권고 2)

train 케이스 수 N(예: 50·100·150·200·243)에 대해 저산소역 위치오차 곡선. **포화 여부로 결론:**
- 이미 포화 → Tier3만 추가하면 n≥3 커버 완성.
- 미포화 → Tier2 보충도 필요 → GCP 추가 실행 우선순위 산정.

## 4. 리스크·미결

1. **[치명 완화] Tier3 외삽.** n≤2로 범위 한정해 회피. 시연 스코프 = 구조물 0~2개 명시. 학습곡선으로 Tier3 추가 필요성 정량화.
2. **[중] postProcessing/솔버로그 미보존.** 준정상 도달·평균창 충분성 사후검증 불가 → 해상 TKE 비율(중앙값 0.068) 간접근거로 대체. 재실행 시 `worker.sh`에 아카이브 포함(QC 권고 4).
3. **[경] 크기 S 편중** (rock S:M:L=96:79:53). 층화 분할·손실 가중으로 부분 보정, 근본은 Tier3 표집 시 M/L 상향.
4. **plant 유동효과 약함**(파일럿 소견: 성긴수초+저유속이면 항력 원래 작음). A층 유동엔 미미해도 B층 대사가 주역할 — 정합 유지(식물 크기 A·B 공유).
5. CNN 데이터 부족 가능 → 학습곡선에서 조기 판정, 부족 시 트랙 A 채택.

## 5. 즉시 실행 순서

1. **Stage 0 후처리** — `resample_encode.py`로 253케이스 → 텐서 + labels + phi 연속성 게이트 1케이스 확인.
2. **Stage 1 분할** — 층화 10 테스트셋 동결(`test_split.json`).
3. **Stage 2-A POD 베이스라인** 먼저(빠름) → n=0 회귀·저산소역 위치오차 확인.
4. **Stage 4 학습곡선**(POD로) → 포화 판정.
5. **Stage 2-B CNN** → POD와 정면 비교 → ROM 선정.
