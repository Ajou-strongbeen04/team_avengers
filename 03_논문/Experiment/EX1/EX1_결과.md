## 1. 실행 요약 (실제 구성)

- 솔버: **simpleFoam(정상 RANS)** — 유동+DO 동시 수렴. (DO 화학 시간척도가 ≈수시간이라 과도 대신 정상 채택.)
- 난류: SST k-ω + Automatic Wall Treatment. 격자: **250k셀 고정**(nx100×ny50×nz50, 큐빅셀 dx=L/100).
- 폭기: 바닥 중앙 20mm 원기둥 플룸, 상향 부력소스 α_g·g=0.196 m/s²(α_g=0.02 placeholder).
- DO: `scalarTransport` FO, D_eff=D_mol+ν_t/Sc_t. 재폭기·SOD는 **표층/바닥층 체적소스**(코드BC 회피, 윈도우 호환). 생물소비 **5 g/L**(선형화 Monod, Sp=−1.0e-4/s).
- 지표: DO 공간 변동계수 CV, 그리고 레짐 판정용 **난류 Péclet Pe_t=U₀·Lc/D_eff** (Lc=플룸→최원거리 코너=0.559L).
- 비율 고정 L:B:d=2:1:1, 스케일만 스윕. 25 °C 고정.

## 3. 분석

- **평균 DO는 크기와 함께 단조 하락**(7.91→7.34 mg/L, 포화 8.24 대비 결손 0.33→0.90). 고정 2.5W 펌프가 큰 부피를 균일 산소화 못 함 → 프로젝트 명제 확인.
- **레짐 판정(Pe_t):** L=0.2에서 67 → 급락(0.2~0.3, ΔPe≈−6) → **0.35부터 완만(ΔPe≈−2)** → ~49 평탄 수렴. **무릎 = L≈0.30~0.35 (7~11L).**
- Re는 0.2~0.4 구간 ~1700로 평탄 → 여기선 Pe_t가 레짐을 가르는 변수.
- 세 구간: ①L≤0.25(≤4L) 소형 잘-섞임(별종) ②L≈0.30(7L) 전이 ③**L≥0.35(≥11L) 자기유사 레짐**(Pe_t 49~53).

## 4. 결론 — 어항 크기 확정

- **물리적으로 대표성 있는(자기유사) 레짐 하한 = L≈0.35 (11L).**
- 가정용 현실성 + 격자 신뢰(대형은 플룸 저해상) 상한 = L≈0.8 (128L).
- **유의미 실험/구매 범위: L = 0.35~0.8 (11~128L).**
- **확정 규격: 47×21×21 cm, ≈20.7 L** (L=0.47, L:B:d≈2.24:1:1). EX2 정량실험의 기준 기하(`../상수_목록.md` E군).
  L=0.47은 유의미 범위(0.35~0.8) 내 자기유사 레짐이라 물리적으로 유효. (EX1 스윕은 2:1:1 비율이었으나 실제 제작 규격은 시판 어항 기준.)

## 5. 한계 · 가정 (후속 보정 대상)

1. **가벼운 사육(5 g/L)** → 저산소 신호 약함(CV<1%, 최저 DO도 >6 mg/L=안전). 뚜렷한 진단 시연엔 고밀도/약폭기 조건 검토.
2. **대형(L≥0.8) 플룸 저해상** (셀수 고정 → dx=L/100↑). 해당 구간 결론은 국부세분 재확인 필요. (경계 판정 구간 0.2~0.4는 고해상이라 신뢰.)
3. **정상 RANS p-잔차 미완전수렴**(~0.011) = 플룸 약한 비정상성. 스크리닝엔 무방.
4. **α_g=0.02, Cref, SOD·재폭기 절대값** = placeholder/캘리브레이션 대상. EX1은 상대 스윕이라 크기 경향엔 1차 무해.
