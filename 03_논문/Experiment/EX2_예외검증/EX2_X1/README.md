## 1. 왜 새 폴더가 필요한가

2026-07-28 폭기 유량이 실측됐다. **물 치환 500 mL / 25 s, 3회 평균 → $Q_\text{air}=1.2$ L/min.** 가정치 2 L/min의 60 %이고, `alpha_g_보정절차.md` §5③이 제시한 민감도 범위(1.5–2.5 L/min) 아래로 벗어난다.

여기에 수온이 25 °C로 고정되면서 $U_\text{slip}$ 이 0.055 → 0.0578 m/s로 바뀐다. 자기일관 고정점을 다시 풀면

$$U_{gs}=\frac{Q_\text{air}}{A_p}=0.0637\ \mathrm{m/s},\qquad \alpha_g=0.1717,\qquad \mathrm{Su}=\alpha_g g=1.684,\qquad a=\frac{6\alpha_g}{d_b}=2060\ \mathrm{/m}$$

**문제는 이것이다.** 기존 CFD(EX2 16위치 + EX3 253케이스)는 전부 $\mathrm{Su}=2.86$ 으로 돌아갔고, 재실행 면제는 "$\mathrm{Su}$ −12 %는 공간구조를 안 바꾼다"는 미검증 가정에 걸려 있었다(`alpha_g_보정절차.md` §4·§5②). 이제 필요한 섭동은 **−41 %** 다. 면제 논리가 커버하던 폭의 3.4배이므로, 논리를 그대로 끌어 쓸 수 없다.

준비돼 있던 검증 케이스 `../EX2/CFD/flow/pos1_su235/`(Su=2.35)는 **폐기**한다. 새 운전점이 아니고, $t\approx20$ s에서 중단됐고, medium 격자라 2.2 h가 든다.

## 2. 설계 — 41분에 판정하는 법

**대조군이 이미 디스크에 있다.** `../EX2/CFD/study/coarse_0.02` 는 GCI 연구로 완주된 coarse 격자 케이스다($\mathrm{Su}=2.86$, 플룸 x=0.13, 200 s, 시간평균장 보유). 여기에 **Su 한 줄만 바꾼 짝**을 하나 돌리면 끝난다.

| | 대조군 | 시험 |
|---|---|---|
| 경로 | `../EX2/CFD/study/coarse_0.02` | `case_su168/` |
| 상태 | **완주됨(재실행 불필요)** | 41분 |
| $\mathrm{Su}$ | 2.86 | **1.684** |
| 격자 | 84×37×37 = 114,996 | 동일 |

| controlDict·스킴 | — | 동일 |

격자·위치·수치가 전부 같으므로 **격자 편향이 정확히 상쇄**되고, 관측된 차이를 순수하게 부력 크기 탓으로 귀속할 수 있다.

$\nu$ 를 20 °C 값으로 붙잡아 둔 것은 의도적이다. 수온까지 같이 바꾸면 두 효과가 섞인다. 수온 효과가 궁금하면 `case_su168_T25/`($\nu=8.927\times10^{-7}$)를 추가로 돌려 3자 비교한다(+41분).

### 왜 coarse 격자로 판정해도 되는가

`../EX2/CFD/study/` 3격자를 QoI별로 재분석한 결과다(전부 $\mathrm{Su}=2.86$, 동일 플룸):

|---|---|---|---|
| 실행시간(8코어) | **41 분** | 2.24 h | 7.81 h |
| 플룸 셀수 | 330 | 688 | 1568 |
| mean\|U\| [m/s] | 0.03617 (−0.9 %) | 0.03578 (−1.9 %) | 0.03648 |

읽는 법:

- $W$·$Q_p$·mean$\lvert U\rvert$ 는 coarse가 medium과 동급(≤3 %)이다. **$\alpha_g$ 고정점과 $K_La$ 는 이 셋으로만 결정**되므로 coarse로 충분하다.
- 정체분율·centroid는 **coarse에서 수렴하지 않았다**(단조 증가 중, centroid $y$ 가 fine 대비 15.9 mm = 반폭의 15 % 어긋남). 따라서 **coarse의 정체역 절대값은 인용 금지**다.
- 그러나 본 게이트는 **coarse ↔ coarse 차분**만 쓴다. 계통 편향이 양쪽에 동일하게 실리므로 상쇄된다. EX1을 상대 스윕으로 정당화한 논리와 같다.

## 3. 판정 기준

### ① $W \propto \mathrm{Su}^{1/3}$ (고정점 반복의 유일한 자유 가정)

$$W_\text{pred}=W_\text{base}\left(\frac{1.684}{2.86}\right)^{1/3}=0.3752\times0.8382=\mathbf{0.3145}\ \mathrm{m/s}$$

**합격: 오차 ≤ 3 %.** 불합격이면 멱법칙 자체가 깨진 것이므로 $\alpha_g$ 고정점 산출 절차를 다시 세워야 한다.

### ② 정체역 공간구조 불변 (부력측 미보정 면제의 근거)

$\mathrm{Su}$ 가 내려가면 유동 전체가 느려져 절대임계 마스크($\lvert U\rvert<1$ cm/s)는 **기계적으로** 커진다. 이건 크기효과지 구조변화가 아니다. 그래서 두 마스크를 함께 본다.

| 마스크 | 정의 | 무엇을 보나 |
|---|---|---|
| 절대 | $\lvert U\rvert<1$ cm/s | 크기 + 구조 (참고) |
| **정규화** | 유속 하위 $p$ % 셀 ($p$ = 대조군 절대마스크 분율 = 6.16 %) | **구조만 (본 판정)** |

**합격: 정규화마스크의 centroid 이동 ≤ 1셀(5.6 mm) 그리고 IoU ≥ 0.80.**
1셀 기준은 EX3 QC 게이트("저산소역 좌표 ≲1셀", `../EX3/EX3_방법론.md`)와 같은 눈금이다.

### 4.1 판정 — **종합 불합격.** 부력측 미보정 면제는 성립하지 않는다

**①** $W\propto\mathrm{Su}^{1/3}$ 가 틀렸다. 두 CFD 점이 주는 실측 지수는

$$n=\frac{\ln(0.2869/0.3752)}{\ln(1.684/2.860)}=\mathbf{0.506}$$

즉 $W\propto\mathrm{Su}^{1/2}$ 에 가깝다. 이는 플룸 상승속도가 부력 스케일 $\sqrt{\mathrm{Su}\,\ell}$ 로 결정된다는 쪽에 부합하고, 부력플럭스 기반 $B^{1/3}$ 스케일링(플룸 유량이 고정일 때 성립)과는 다르다. 폐쇄수조에서 플룸 단면과 높이가 고정돼 있으니 후자가 안 맞는 게 자연스럽다.

$n=0.506$ 으로 자기일관 고정점을 다시 풀면

$$\alpha_g=\mathbf{0.1808},\qquad \mathrm{Su}=\alpha_g g=\mathbf{1.773},\qquad W_\text{pred}=0.2945\ \mathrm{m/s},\qquad a=\frac{6\alpha_g}{d_b}=\mathbf{2169\ /m}$$

→ 이 운전점이 실제로 자기일관인지 확인하는 것이 **`case_su177/` (확인런)** 이다.

### 4.2 확인런 결과 (2026-07-29 완주, 2057 s) — **$\alpha_g$ 확정**

**자기일관 달성.** 입력 $\alpha_g=0.1807$ → 실측 $W=0.2930$ 되먹임 $\alpha_g=0.1815$, **잔차 +0.4 %**(허용 3 %). 고정점 반복이 3회차에서 멈췄다.

$$\alpha_g=0.1807,\qquad \mathrm{Su}=1.773,\qquad W=0.2930\ \mathrm{m/s},\qquad a=\frac{6\alpha_g}{d_b}=2169\ /\mathrm{m}$$

> **2026-07-29 갱신 — 이 값은 coarse 기준이고 최종본이 아니다.** `../EX2_X3/` 의 medium 앵커(m21, 같은 운전점·같은 플룸)가 $W=0.3009$ 를 주어 최종 상수는
> $$\boxed{\alpha_g=0.1785,\quad \mathrm{Su}=1.751,\quad W=0.3009,\quad a=2142\ /\mathrm{m}}$$
> 이다. 아래 §7이 "coarse 기준 고정점은 $\alpha_g$ 를 약 −2 % 낮게 준다"고 적었으나 **부호가 반대**였다 — coarse 가 $W$ 를 −2.6 % 낮게 주므로 $\alpha_g$ 는 **+2.1 % 높게** 나온다. 상세는 `../EX2_X3/README.md` §5.3.

**지수는 안정하다 — 단, 판정식을 고쳐야 했다.** 애초 합격선으로 잡은 "쌍별 $n$ 산포 $\Delta n\le0.02$"는 $\Delta n=0.110$ 으로 실패했는데, **기준 자체가 잘못 설계된 것**이었다. 쌍별 지수의 조건수는

$$\Delta n=\frac{\delta(\ln W)}{\ln(\mathrm{Su}_b/\mathrm{Su}_a)}$$

이고 su168↔su177 은 $\mathrm{Su}$ 간격이 5.3 %($\ln$비 0.052)뿐이라 **$W$ 오차 0.3 %가 $\Delta n$ 0.058로 증폭**된다. 이 쌍의 $n=0.407$ 은 물리가 아니라 조건수다.

전체 3점 log-log 최소제곱으로 다시 재면:

| | $\mathrm{Su}$ | $W$ 실측 | 적합 잔차 |
|---|---|---|---|
| coarse_0.02 | 2.860 | 0.3752 | +0.03 % |
| case_su168 | 1.684 | 0.2869 | +0.25 % |
| case_su177 | 1.773 | 0.2930 | −0.28 % |

$$W=0.2178\,\mathrm{Su}^{0.511},\qquad \text{최대 잔차 }\mathbf{0.28\%}$$

**세 점이 단일 멱법칙 위에 0.3 % 안으로 올라간다.** $n=1/2$ 로 봐도 무방하다(MTT 부력플룸 $1/3$ 이 아니라 운동량 지배 컬럼). `compare.py` 는 이 결과를 반영해 쌍별 산포 대신 **전체점 LSQ 잔차 ≤1 %** 로 판정하도록 2026-07-29 수정했고, 단폭 쌍에는 조건수 경고를 찍는다.

**② 는 재확인 불합격.** IoU 0.587(su168의 0.597과 사실상 동일), centroid $z$ 이동 1.20셀로 오히려 su168보다 나빠졌다. 즉 ②의 실패는 통계 잡음이 아니라 **재현되는 실제 구조 이동**이다.

**②** 정체역이 Su에 따라 움직인다. 정규화마스크로 크기효과를 제거한 뒤에도 IoU 0.597로, 겹치지 않는 부분이 40 %다(centroid 이동 자체는 0.94셀로 아슬아슬하게 기준 내). 크기효과가 아니라 **구조가 바뀐 것**이다.

따라서 §6 분기표의 "② 불합격" 줄이 발동한다 — 16위치 재실행 + EX3 253케이스 재생성. 그 비용(≈173 h)을 깎을 수 있는지 묻는 후속 게이트가 **`../EX2_X2/`(simpleFoam 정상해 대조)** 다.

> 실행상 사고 2건(재발 방지): Windows OpenFOAM 창에 `diff` 가 없어 대조군 동일성 검사 6건이 전부 헛돌았고(에러 없이 `[ok]` 만 찍힘), 판정 단계의 `python3` 가 Windows Store 스텁에 잡혀 `Permission denied` 로 죽었다. `case_su177/Allrun` 은 `cmp` 폴백과 numpy import 확인으로 둘 다 막아 뒀다.

## 5. 실행

```bash
cd 03_논문/Experiment/EX2_X
bash run.sh              # 필수 케이스만, ≈41분
bash run.sh --all        # + 수온 분리 케이스, ≈82분

cd case_su177 && ./Allrun # 고정점 확인런 Su=1.773, ≈33분 (3점 판정까지 자동)
```

수동 재판정:

```bash
python3 compare.py ../EX2/CFD/study/coarse_0.02 case_su168
python3 compare.py ../EX2/CFD/study/coarse_0.02 case_su168 case_su177
python3 compare.py ../EX2/CFD/study/coarse_0.02 case_su168 case_su168_T25
```

인자를 2개 이상 주면 쌍별 실측 지수 $n$ 과 그 $n$ 으로 다시 푼 고정점을 출력한다.

`compare.py` 는 blockMeshDict에서 격자, fvOptions에서 $\mathrm{Su}$, transportProperties에서 $\nu$, topoSetDict에서 플룸축을 직접 읽으므로 하드코딩 불일치가 없다.

## 7. 미결 · 주의

- **$Q_\text{air}$ 불확도 미상.** 3회 평균만 있고 개별 관측시간이 없어 ±를 못 쓴다. $a$ 는 $Q_\text{air}$ 에 거의 선형이므로 이 산포가 곧 $K_La$ 불확도다. 개별 3회 시간 기록 필요.
- **측정 조건 확인 필요.** 물 치환을 실제 수심 0.21 m에 담근 상태에서 했는지. 대기 중 토출이면 배압이 빠져 과대평가다.
- **coarse의 $W$ 는 fine 대비 +2.5 % 편향.** 게이트 판정에는 상쇄되지만, `../상수_목록.md` D군에 올릴 **최종 $\alpha_g$ 는 medium/fine 보정된 $W$ 로 확정**해야 한다. coarse 기준 고정점은 $\alpha_g$ 를 약 −2 % 낮게 준다.
- **본 폴더는 `../상수_목록.md`·`../CFD_method.md`·`../../논문_초안_v2.md` 를 아직 수정하지 않았다.** 게이트 판정이 나온 뒤 일괄 반영한다.
