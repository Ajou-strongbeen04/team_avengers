## 1. 왜 $z_\text{start}$ 인가 (①의 배경)

`../EX2_X3/README.md` §5.1 이 **수위 축을 무효화**했다 — 해석추정은 0.21→0.09 m에서 $K_La$ 100→53 %를 예상했으나 CFD 실측은 **100→121 %**로 부호가 반대였다. 원인은 $V\propto d$ 라 수면항 $A_s/V=1/d$ 가 ×2.33 로 커져 플룸항 감소(×0.859)를 압도하는 것.

$z_\text{start}$ 축은 **$V$ 가 고정**이라 그 $1/V$ 증폭이 없다.

| | 위치 축 | 수위 축 | **$z_\text{start}$ 축** |
|---|---|---|---|
| 레버 | ±9 % (재현성에 묻힘) | **+21 % (부호 반대)** | **100 → 39.3 %** (CFD 실측 6수준, §4.1) |
| $V$ | 고정 | 20.7 → 8.9 L | **20.7 L 고정** |
| 수면항 $k_{L,s}A_s/V$ | ×1.0 | ×2.33 (레버 상쇄) | **×1.0** |
| CFD 비용 | — | `blockMesh` 재생성 | **`topoSetDict` z 한 줄** |
| 실험 비용 | 물 교체 | 물량·시약량 매번 재계산 | **0원** |

**같은 함정을 두 번 밟지 않기 위해** 해석추정을 논문에 쓰지 않는다 — 그리고 실제로 이 축의 해석추정도 **32 %p 틀렸다**(§4.3).

## 2. 만드는 것 — 1차 3케이스(완주) + 2차 2케이스(§8)

```

z02    0.02    0.19   84x37x37   114,996    1.773    ← ../EX2_X1/case_su177 재사용
z05    0.05    0.16   84x37x37   114,996    1.773      41 분
z08    0.08    0.13   84x37x37   114,996    1.773      41 분
z11    0.11    0.10   84x37x37   114,996    1.773      41 분   ← 여기까지 1차(완주 1.79 h)
z14    0.14    0.07   84x37x37   114,996    1.773      41 분   ← 2차 연장(§8), 완주
z17    0.17    0.04   84x37x37   114,996    1.773      41 분   ← 〃 완주 (플룸 7셀이나 문제 없었음)
```

**바뀌는 것은 두 파일뿐이다.**

- `system/topoSetDict` — 플룸 원기둥 `point1` 의 z 를 $z_\text{start}$ 로 (수면 z=0.21 고정)
- `system/fvOptions` — $\mathrm{Su}=\alpha_g g$ (stage1 시드 1.773 → stage2 자기일관값)

**안 바뀌는 것:** 격자(`blockMeshDict`)·`controlDict`·스킴·물성·수심 0.21·플룸축 (0.13, 0.035)·반경 0.01 m. 격자가 `case_su177` 과 **동일**하므로 z02 를 그대로 대조군으로 쓴다.

### 2.1 왜 coarse 인가

`../EX2_X1/README.md` §2 가 3격자 재분석으로 답해 놨다 — "$W$·$Q_p$·mean$|U|$ 는 coarse 가 medium 과 동급(≤3 %). **$\alpha_g$ 고정점과 $K_La$ 는 이 셋으로만 결정**되므로 coarse 로 충분."

본 폴더의 QoI 는 전부 $K_La$ 다. **정체역 절대값은 어느 케이스에서도 인용하지 않는다**(coarse 는 정체분율·centroid 가 미수렴).

### 2.2 왜 수준마다 $\alpha_g$ 를 다시 푸나

$$\alpha_g=\frac{U_{gs}}{W+U_\text{slip}},\qquad U_{gs}=\frac{Q_\text{air}}{\pi r_p^2}=0.0637\ \mathrm{m/s}$$

$U_{gs}$ 는 $z_\text{start}$ 와 무관하게 고정이다(같은 에어스톤·같은 $Q_\text{air}$·같은 반경). 반면 $z_\text{start}$ 가 올라가면 $H_p=0.21-z_\text{start}$ 가 짧아져 $W$ 가 줄고, 따라서 **$\alpha_g$ 는 커진다.** d=0.21·$z_\text{start}$=0.02 에서 확정한 Su=1.773 을 전 수준에 그대로 쓰면 높은 에어스톤에서 부력을 과소평가한다.

`fixedpoint.py` 가 멱법칙 $W\propto\mathrm{Su}^{n}$ ($n=0.511$, 3점 LSQ 잔차 0.28 %)로 수준별 고정점을 풀고, `gen_cases.py --stage 2` 가 Su 이동이 3 % 를 넘는 수준만 갱신한다.

> $n$ 은 $z_\text{start}$=0.02 에서 Su 를 흔들어 얻은 지수다. $z_\text{start}$ 를 흔든 것이 아니므로 **국소 스케일 가정**이며, `fixedpoint.py --verify` 의 되먹임 잔차(허용 ±3 %)가 그 가정의 검정이다.

### 2.3 1차에서 $z_\text{start}$=0.14 를 뺐다가 되돌린 경위

1차 설계는 "해석추정으로 90 % 도달 292분(≈5시간)이라 반복 불가"를 이유로 0.14 를 뺐다. 그런데 그 추정이 **35 %p 틀렸고**(§4.3), CFD 실측 레버로는 **~105분**이다. 레버가 약하다는 나쁜 소식이 곧 "높은 수준도 빨리 끝난다"는 좋은 소식이라 **0.14·0.17 을 복원**했다(§8).

**판정 B가 2차 연장으로 뒤집혔다.** 1차 4수준에서 불합격(64.7 %)이던 것이 0.14·0.17 을 붙여 **39.3 %** 로 통과했다. 그리고 §8.2 선형모델의 사전 예측(50.4 / 36.4 %)이 실측(51.5 / 39.3 %)을 **2.9 %p 이내**로 맞췄다 — z17 의 플룸 7셀 해상도 우려는 근거 없었다.

**왜 레버가 안 나왔나 — 원인 셋.**

1. **$W$ 가 단조가 아니다.** 0.2930 → **0.3023** → 0.2857 → 0.2696. z05 가 z02 보다 **+3.2 %** 높다. 에어스톤을 바닥에서 3 cm 띄우면 바닥 no-slip 저항에서 벗어나 플룸이 오히려 빨라진다. 그래서 $\alpha_g=U_{gs}/(W+U_\text{slip})$ 가 거의 안 움직이고($a$ 2178→2333, +7 %), **위치 축을 죽인 자기조절이 여기서도 작동한다.**
2. **해석추정의 $Q_p\propto H_p^{5/3}$ 가 전달 폐합에 들어가지 않는다.** $Q_p$ 는 실제로 6.16→5.93 L/min, **−4 %** 밖에 안 줄었다. CFD 전달항은 $K_La_\text{plume}=(V_p/V)\,k_{L,b}\,a$ 이고 $V_p\propto H_p$ 라 **$H_p$ 에 선형**이다. 0.19→0.10 은 ×0.53, $a$ 가 ×1.07 → 곱 **0.57**. 관측 플룸항 비 0.585 와 일치한다.
3. **수면항이 바닥(floor)을 만든다.** $k_{L,s}A_s/V=0.444$ /h 로 **전 수준 고정**($V$ 가 고정이니 당연). z02 의 **15.2 %**. 플룸을 0 으로 만들어도 $K_La$ 는 여기 아래로 못 간다 → **어떤 플룸 기하 축이든 100→15 % 가 이론 상한**이고, $H_p$ 를 반으로 줄이는 정도로는 100→65 % 가 최선이다.

**hold-out 로서의 함의.** 학습 0.02/0.05/0.08 이 100→75.6 % 를 덮고 hold-out 0.11 이 64.7 % 다. 외삽 거리 **11 %p** 인데 실험 반복 재현성이 CV 5–10 % → 신호가 잡음의 **1–2배**밖에 안 된다. 위치 축(±9 %)을 탈락시킨 것과 **같은 실패 양식**이다. 전체 span 35 %p 도 3.5–7배에 그친다.

→ **축을 폐기하지 않고 연장한다.** §8 참조.

### 9.2 예상과 달랐던 것 셋

**① 3-D 는 산포를 좁히지 않는다 — `../EX2_X3/README.md` §5.2 의 설명이 틀렸다.**

그 문서는 "0-D 는 $K_La\propto\alpha_g$ 라 되먹임 산포가 그대로 실리는 반면, 3-D 는 순환 $Q_p$ 증가가 상쇄해 산포가 좁아진다"고 적고, 근거로 `../EX2/어항실험/16위치_잔차분석.md` 의 CV 5.1 % 를 들었다. 본 배치는 둘 다 반박한다:

- 3D/0-D 비가 **0.913–0.923 으로 거의 일정**(z군 6수준). 3-D 는 0-D 를 ~8 % **균일 축소**할 뿐이고, 레버는 0-D 100→39.3 % vs 3-D 100→38.9 % 로 **차이 ≤0.5 %p** 다.
- 위치 3점 CV 도 0-D 13.33 % → 3-D 14.46 % 로 **좁아지지 않고 넓어졌다**.
- `16위치_잔차분석.md` §4 의 CV 5.1 % 는 **3-D 가 아니라 0-D 해석식**이다(그 문서 §4 표 제목이 "위치별 $K_La_\text{eff,CFD}$ 예측 … 각 위치 자기일관 $\alpha_g$"). 애초에 3-D 값이 아니었다.

**따라서 5.1 % 와 14.5 % 는 서로 비교 대상이 아니다.** 전자는 16위치 **전수** 산포, 후자는 $W$ 분포를 일부러 **span 하게 고른 3점**(pos15 최소 / pos4 중앙 / pos1 최대)이라 구조적으로 부풀려져 있다. `gen_cases.py` 주석이 그 선정 이유를 적어 뒀다.

> **실무 함의(좋은 소식):** 0-D 해석식을 **레버·상대 스윕에 그대로 써도 된다.** 3-D 는 절대값 보정만 담당한다. 다만 보정계수는 **격자 의존**이다(coarse 0.913–0.923 vs medium 0.951–0.966) → "0.92 를 곱한다"로 일반화하지 말 것.

**② 3D/0-D 비가 약하게 드리프트한다.** 0.9232(z02) → 0.9130(z17), −1.1 %. 플룸이 짧아질수록 3-D 가 0-D 보다 더 뒤처진다 — 소스가 좁은 체적에 집중되면 이송 제한이 커져 벌크 평균이 늦게 따라온다. 작지만 계통적이며, 이것이 **0-D 축약이 유효한 범위의 상한**을 알려준다.

**③ coarse 가 3-D $K_La$ 를 +3.8 % 높게 준다.** z02 coarse 2.703 vs m21 medium 2.604. 방향은 $W$ 편향(coarse 가 −2.6 % 낮음 → $\alpha_g$ 높음 → $a$ 높음)과 일치한다. **절대값은 medium 앵커, 상대는 coarse** 규약을 지킬 것.

### 9.3 판정 F 통과의 정확한 의미

$\kappa$ 위치 무의존성 검정은 "CV 값이 작다"가 아니라 **"두 운전점에서 CV 가 보존된다"**(14.46 % ↔ 12.59 %, 차이 1.88 %p ≤ 2 %p)다. 이로써 16위치 medium 스윕(33.3 h, Su=2.86)의 **상대 산포 결론을 새 운전점에 인용**할 수 있고 재실행은 영구 불필요하다.

**논문에 CV 숫자를 쓸 때 주의:** ① 3점 span 기준 **3-D 14.5 %(신)/12.6 %(구)**, ② 16위치 전수 기준 **0-D 5.1 %** — 둘을 섞지 말고 어느 기준인지 명시할 것. 또한 pref 군은 Su=2.86 유동장에 새 $U_{gs}$(=$Q_\text{air}$ 1.2 L/min) 폐합을 적용한 값이라 **자기 부력 입력과 불일치**한다. 상대 산포 비교에는 유효하나 절대값은 인용 금지.

### 9.5 논문에 쓸 결과 문장

> 20 L 급 가정 어항에서 폭기 기하를 크게 바꿔도($H_p$ 0.19→0.04 m, 79 % 단축) $K_La$ 총량은 2.70→1.05 /h 에 머문다. 두 기제가 레버를 눌렀다 — (i) 플룸이 느려지면 holdup $\alpha_g=U_{gs}/(W{+}U_\text{slip})$ 이 커져 계면적 $a$ 가 보상하는 **자기조절**($a$ 2178→2923 /m, +34 %), (ii) 수면 재폭기항 $k_{L,s}A_s/V=0.444$ /h 가 체적 고정 하에서 **제거 불가능한 바닥**(기준 조건의 15.2 %)을 만든다. **총량은 로버스트하고, 진단해야 할 것은 총량이 아니라 공간구조다.**

이는 논문의 논지(단일 센서가 못 보는 공간구배)와 정합하며, $\kappa$ 를 조건 둔감한 단일 보정계수로 쓰는 정당화이기도 하다.
