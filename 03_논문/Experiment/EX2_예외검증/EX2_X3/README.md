## 1. 16위치 재실행을 하지 않는 이유

`../EX2_X` 게이트 ② 불합격의 청구서는 "16위치 재실행 + EX3 253케이스 재생성"이었다. 그런데 문서를 다시 읽으면 **16위치는 이미 설계에서 내려와 있다.**

| 근거 | 내용 |
|---|---|
| `../EX2/EX2_방법론.md` §6.2 (2026-07-19) | 폭기 위치를 **hold-out 분할축에서 폐기**. "신호(±9 %)가 실험 반복 재현성(통상 CV 5–10 %)에 묻히므로 leave-one-position-out은 잔차가 작게 나와도 전이성의 증거가 되지 못한다" |
| 〃 | 위치의 새 역할 = "**$\kappa$의 위치 무의존성을 보이는 강건성 축**. **2–3위치**에서 $\kappa$가 일치하면 —" → 16개가 아니다 |
| `../../실험후검토사항.md` §1.2 (2026-07-28) | hold-out 축을 **수위**로 확정. "**수위별 CFD가 새로 필요하다. $V$와 격자($L_z$)가 바뀌어 16위치 유동장을 못 쓴다.**" |

세 번째가 결정적이다. **Su 문제와 무관하게** 16위치 유동장은 새 hold-out 설계에 못 쓴다. Su=1.773으로 재실행해봐야 쓸 데가 없다.

기존 16위치 medium 스윕(33.3 h, Su=2.86)은 **버리지 않는다.** `../EX2/어항실험/16위치_잔차분석.md`의 결론은 위치 간 **상대** 산포(CV 5.1 %)이고, 이번에 확정된 $W\propto\mathrm{Su}^{0.511}$(3점 LSQ 잔차 0.28 %)은 Su가 유동장을 매끄럽게 전역 스케일한다는 뜻이다. 상대 산포가 새 운전점에서도 보존되는지를 **3위치로 확인**하면 33 h짜리 스윕을 그대로 인용할 수 있다. 그것이 아래 P군이다.

### 2.1 왜 coarse인가

`../EX2_X1/README.md` §2가 3격자 재분석으로 이미 답해 놨다 — "$W$·$Q_p$·mean$\lvert U\rvert$는 coarse가 medium과 동급(≤3 %). **$\alpha_g$ 고정점과 $K_La$는 이 셋으로만 결정**되므로 coarse로 충분."

D군·P군의 QoI는 둘 다 $K_La$다. 정체역 절대값이 필요한 곳은 논문 §4 그림뿐이고 그건 medium인 EX3 데이터셋이 낸다. coarse는 정체분율·centroid가 미수렴이므로 **본 폴더의 어느 케이스에서도 정체역 절대값을 인용하지 않는다.**

M군 1케이스를 medium으로 두는 이유는 두 가지다. (i) 최종 $\kappa$에 들어갈 **절대** $W$를 medium 급으로 확보(§7의 "coarse 기준 고정점은 $\alpha_g$를 약 −2 % 낮게 준다"), (ii) coarse↔medium 편향이 **Su에 불변인지** 확인. 불변이면 단일 보정계수로 D·P군 전체를 medium 급으로 환산할 수 있다.

### 2.2 왜 수위마다 $\alpha_g$를 다시 푸는가 — 놓치기 쉬운 지점

$$\alpha_g=\frac{U_{gs}}{W+U_\text{slip}},\qquad U_{gs}=\frac{Q_\text{air}}{\pi r_p^2}=0.0637\ \mathrm{m/s}$$

$U_{gs}$는 **수위와 무관하게 고정**이다(같은 에어스톤·같은 $Q_\text{air}$·같은 플룸 반경). 반면 수위가 낮아지면 플룸 길이 $H_p=d-0.02$가 짧아져 $W$가 줄고, 따라서 **$\alpha_g$는 커진다.** $d=0.21$에서 확정한 Su=1.773을 전 수준에 그대로 쓰면 얕은 수조에서 부력을 과소평가한다.

그래서 D군은 2패스다.

1. **stage1** — 전 수준 Su=1.773 시드런 → $W_\text{seed}(d)$ 측정
2. **고정점** — `fixedpoint.py`가 $W(\mathrm{Su})=W_\text{seed}(\mathrm{Su}/1.773)^{0.511}$ 로 수준별 자기일관 $\alpha_g(d)$·$\mathrm{Su}(d)$ 산출
3. **stage2** — 각 수준을 자기 $\mathrm{Su}(d)$로 재실행 → 잔차 ≤3 % 확인

지수 $n=0.511$은 `../EX2_X1/README.md` §4.2에서 3점 LSQ로 확정된 값이고, 그 절차가 `case_su177`에서 실제로 1회 반복만에 잔차 +0.4 %로 수렴한 것을 확인했다. 수준별 이동이 전부 3 % 이내로 나오면 `fixedpoint.py`가 stage2 생략을 권고한다.

### 2.3 왜 그 3위치인가

기존 16위치 medium의 $W$ 분포를 **span** 하도록 골랐다.

| | $W$ [m/s] | 되먹임 $\alpha_g$ |
|---|---|---|
| pos15 (0.035, 0.075) | **0.3201** (최소) | 0.1685 |
| pos4 (0.075, 0.035) | 0.3786 (중앙) | 0.1459 |
| pos1 (0.015, 0.035) | **0.4153** (최대) | 0.1346 |
| 16위치 전체 | 0.3735 ± 0.0292 (CV 7.8 %) | CV **7.0 %** |

$\alpha_g$ CV 7.0 %는 `16위치_잔차분석.md`의 값과 일치한다(되먹임 폐합이 재현됨을 확인). 처음에 pos1/pos12/pos13을 고르려 했으나 이 셋은 전부 $W$ 상위권이라 CV가 0.5 %로 뭉개진다 — 산포를 재는 실험에서 산포가 없는 표본을 고르는 셈이라 폐기했다.

## 3. 판정 기준

| # | 무엇을 | 합격선 |
|---|---|---|
| **A** | 수위별 $\alpha_g$ 자기일관 | 잔차 ≤3 % (전 수준) |
| **B** | 수위 레버 | $K_La(0.09)/K_La(0.21)$ 가 `../../실험후검토사항.md` §1.2 해석추정(53 %)과 정합. 큰 이탈은 해석추정 쪽 갱신 |
| **C** | $\kappa$ 위치 무의존성 | 3위치 $K_La$ CV가 Su=2.86의 동일 3위치 CV와 **≤2 %p** 차이 |
| **D** | coarse 편향의 Su 불변성 | coarse/medium $W$ 편향이 Su=2.86일 때와 **≤1 %p** 차이 |

C가 합격이면 16위치 medium 스윕(33 h)의 상대 산포 결론을 새 운전점에서 인용할 수 있다 → **16위치 재실행 영구 불필요.**
D가 합격이면 단일 보정계수로 coarse 결과를 medium 급 절대값으로 환산할 수 있다.

$K_La$는 `collect.py`가 해석 0-D 식으로 즉시 계산한다(`reaer_solver.py`의 "해석예측" 줄과 동일 식). 3-D 과도해가 필요하면 케이스별로:

```bash
python3 ../EX2/CFD/reaer/reaer_solver.py --case d15 --T 25 --alpha-g <fp_result.csv 값>
```

> 2026-07-29 `reaer_solver.py`에 격자 자동인식을 추가했다. 종전에는 `NX,NY,NZ=108,48,48`·`LZ=0.21`이 하드코딩돼 coarse·수위가변 케이스에 쓸 수 없었다. 케이스의 `system/blockMeshDict`에서 읽고, 읽기 실패 시 기존 기본값을 유지한다(하위호환).

|---|---|---|---|

> **⛔ 정정 (2026-07-30, `../EX2_X4/README.md` §9.2).** 아래 문단의 "5.1 % 는 reaer_solver 3-D 값"은 **틀렸다.** `16위치_잔차분석.md` §4 표는 각 위치 1-step 자기일관 $\alpha_g$ 를 쓴 **0-D 해석식**이다. 그리고 "3-D 가 순환 $Q_p$ 상쇄로 산포를 좁힌다"는 기제도 반박됐다 — EX2_X4 가 실제로 3-D 를 돌려보니 3D/0-D 비가 0.913–0.923 으로 거의 일정해 **레버·산포를 바꾸지 않는다**(위치 3점 CV: 0-D 13.33 % → 3-D 14.46 %). 5.1 %(16위치 전수)와 14.5 %(W 분포 span 3점)는 애초에 비교 대상이 아니다.
>
> **주의 — 이 CV 를 그대로 인용하지 말 것.** 여기 12–13 %는 `collect.py`의 **0-D 해석식** 값이고, `16위치_잔차분석.md`의 **CV 5.1 %** 는 `reaer_solver.py` 3-D 과도해 피팅 값이다. 0-D 식에서 $K_La\propto\alpha_g$ 라 되먹임 산포가 그대로 실리는 반면, 3-D 는 순환 $Q_p$ 증가가 상쇄해 산포가 좁아진다(그 문서가 지적한 자기조절). **본 항의 주장은 "CV 값"이 아니라 "두 운전점의 CV 차이가 1.0 %p"** 다. 3-D 지표로도 보존을 주장하려면 6케이스에 `reaer_solver.py`를 돌리면 된다(케이스당 수분).
