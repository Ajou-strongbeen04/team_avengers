## 5. 문서 역할 규칙

1. **방정식·BC는 `CFD_method.md`에만 적는다.** 실험 문서는 참조 + 자기 델타만.
2. **계수 값은 `상수_목록.md`에만 적는다.** 다른 곳은 인용.
3. **서지는 `References/00_References.md`에만 적는다.** [R#] 번호는 여기서만 부여.
4. 폐기된 설계는 지우지 않고 `../_archive/` 로 옮기고, 남은 문서에 폐기 사실을 한 줄로 남긴다. 폴더명은 `<이름>_폐기YYYYMMDD`.
5. **파일·폴더 이름은 `../00_운영/명명규칙.md`를 따른다.**
5. **(2026-07-28 추가) A층 성능 보고는 `253 전량 5-fold CV`로 통일한다.** 동결 test 10 수치는 표에 남기더라도 "과대평가"임을 각주로 명시한다(근거 `EX3/09` §3). 지표는 **anomL2 · IoU · cdist · top1 · top1-Q** 다섯 개로 고정하고 늘리지 않는다.
