## 1. 가제 · 논지

**가제(안):** 사진기반 물리모델로 추론하는 가정용 어항 용존산소 공간분포 — 자동 경계조건, 물리기저로 보호한 LLM 추론, CFD–실측 이격의 캘리브레이션

*(Photo-driven Physics-based Inference of Dissolved-Oxygen Spatial Distribution in Home Aquaria: Automated Boundary Conditions, Physics-Basis-Constrained LLM Inference, and Calibration of the CFD–Measurement Discrepancy)*

**한 문장 논지:** 사진 한 장에서 세운 경계조건 위에서, CFD가 만든 물리 기저가 LLM 추론의 출력을 물리적으로 가능한 공간에 가두고, 그 결과를 실측으로 보정한 유효 산소전달계수와 함께 **저산소 위험 구역**으로 낸다.

**연구 질문 3개(§1 도입에 그대로 배치):**

1. 사진 한 장으로 물리모델의 경계조건을 세울 수 있는가? → §3.2 / §4.2
2. 그 물리를 사용자 기기에서 실시간으로 대체할 때, **범용 멀티모달 LLM이 전용 학습 대리모델을 대신할 수 있는가?** → §3.3 / §4.3·§4.4
3. 물리엔진과 현실의 이격을 어떻게 정직하게 다룰 것인가? → §3.5 / §4.1

## 2. 절 구성 · 각 절이 주장할 한 문장

**§1.1 관련연구** — v2의 4갈래(① 양식 DO-CFD ② 재폭기 $K_La$ ③ 사진→BC 디지털트윈 ④ 저가 IoT DO 단일점) 유지 + **⑤ LLM/VLM의 물리·공간 추론** 신설.

### §2 System Overview

v2 구조 유지, 3·4단계만 교체.

```
사진 → ① VLM 기하·위상 인식 → ② 정규화 BC(JSON)
     → ③ Gemini in-context 추론 → POD 계수 a_1..a_r
     → ④ CFD POD 기저로 유동장 재구성(발산 0 보장)
     → ⑤ 이송확산 + 소스·임계 → ⑥ 4×9 조대 위험맵 / 저산소 확률
검증·캘리브레이션 경로: 격자수렴 · 정성 유동검증 · 재폭기 시험(κ·잔차)
```

- **그림 1**(신규 필요): 위 파이프라인 도식. ③④가 v2 대비 유일한 변경 지점임을 색으로 구분.
- 포지션 문장은 v2 그대로: 자율주행이 아니라 **계기판 경고등**.

### §3 Methods

**§3.1 물리 엔진 — 지배방정식.** v2 그대로 승계(URANS·SST $k$–$\omega$, 에어리프트 부력플룸 $\mathbf{F}_\text{air}$, rigid-lid·free-slip, 정상상태 이송-확산, $S_\text{air}=k_L(T)a(C^{*}(T)-C)$). 진실원은 `Experiment/CFD_method.md`.

**§3.2 사진 → 기하 → BC 자동설정 (VLM).** v2 그대로 승계. 정직한 범위(사진은 기하·위상만, 정량 계수는 센서·사전분포), 사진좌표↔CFD좌표 변환을 강제하는 BC 스키마가 §3.2와 §3.3의 **계약**.

**§3.3 물리기저로 보호한 LLM 추론 (v2 §3.3 전면 교체) — 본 논문의 핵심 신설 절**

- 주장: **LLM이 아무리 틀려도 물리적으로 불가능한 유동장은 나오지 않는다.**
- §3.3.1 **발산-0 보장.** 스냅샷 $\mathbf{U}_k$ 가 모두 $\nabla\cdot\mathbf{U}_k=0$ 이면 POD 모드 $\varphi_i$ 는 스냅샷의 선형결합이므로 $\nabla\cdot\varphi_i=0$ 이고, 재구성장 $\mathbf{U}\approx\overline{\mathbf{U}}+\sum_i a_i\varphi_i$ 도 선형결합이라 **어떤 계수를 넣어도 발산이 0**이다. → 격자장 직접 출력(08 A안)을 기각하는 근거이자 본 방법의 정당화.
- §3.3.2 **in-context 계수 추론.** 질의 케이스의 기하(또는 사진) + $k$개 근접 케이스의 (기하, 계수) 쌍 → 계수 $a_1..a_r$ 예측. $k\in\{0,4,8,16,32\}$ 스윕이 곧 결과. 가중치 갱신 없음.
- §3.3.3 **출력 차원 축소 — 조대 위험맵.** 셀 단위 장 대신 $4\times9$(36구역, 5.2 cm 블록)로 낸다. 근거: **장 과제는 $N$=202에서도 미포화지만 조대 과제는 $N$=60에서 포화**한다(`09` §1). 지표는 **top1**(최위험 구역 적중)·**top1-Q**(예측 1위가 실제 하위 25% 안).
- §3.3.4 **비교군(baseline).** ⓐ 평균장 ⓑ 최근접 조회 ⓒ POD 투영 ceiling ⓓ POD+Ridge/RF/MLP ⓔ 3D CNN ⓕ 후류 라이브러리 선형 중첩 ⓖ 중첩+잔차 POD+RF 하이브리드. → §4.3에서 **동일 표의 행**으로 비교.
- §3.3.5 **B층(유동→저산소 확률).** v2 유지: 소스·독립입력·$Sc_t$ 밴드·어종 임계를 얹은 선형 풀이, 출력 $P_\text{hypoxia}(\mathbf x)=\Pr[\overline C(\mathbf x)<C_\text{crit}]$, 임계-무관 원장 저장.

**§3.4 무차원화·전이.** v2 그대로($Pe$, $\mathrm{Da}_\text{air}$, $\mathrm{Sh}_s$, $Sr$; $\alpha_g$ 는 $Q_\text{air}$ 로 고정, 캘리브 자유도는 $a$·$Sc_t$).

**§3.5 CFD–실측 이격 캘리브레이션 · 검증.** v2 그대로($K_La_\text{eff}$ 집약, $\kappa=K_La_{\text{eff,meas}}/K_La_{\text{eff,CFD}}$, $\Delta C^{*}$, 잔차 → 확률 채널). **hold-out 축만 갱신**: 폭기 위치가 아니라 **에어스톤 침지 높이 $z_\text{start}$**(위치는 $K_La$ 산포 CV 5.1 %로 너무 약함 → 위치는 $\kappa$ 의 **강건성 축**으로 역할 변경). 근거 `Experiment/EX2/EX2_방법론.md` §6.2.

**§3.6 재현성 규약 (신규, 짧게).** temperature 0 고정, 모델 버전·프롬프트 전문은 부록, 동일 질의 $N=5$ 반복의 분산 보고. 이걸 안 쓰면 심사에서 반드시 걸린다(`08` §4-3).

### §5 Discussion

- **§5.1 시스템 종합.** 각 층의 기여를 ablation으로 분해.
- **§5.2 무엇이 성립하고 무엇이 안 되는가 (신설·핵심).**
  - 성립: 조대 위험맵(top1-Q 1.000 — 정확한 한 칸을 틀려도 위험한 동네는 틀리지 않는다), 식물 구성의 선형 가법성.
  - 불성립: **바위 후류의 비가법성.** 강한 차단은 전역 순환을 재편해 중첩이 깨지고, 이것이 CNN이 무너진 영역과 정확히 겹친다. → 데이터가 부족했던 것이 아니라 **그 영역만 본질적으로 어렵다**는 해석.
  - **이 절이 v2에 없던 가장 큰 학술적 추가분**이다. 음성 결과를 숨기지 않고 물리로 설명하는 구조.
- **§5.3 한계(정직).** v2의 5개 유지 + 신규 3개:
  - (vi) LLM 추론의 비결정성 — temperature 0·$N=5$ 분산으로 관리하되 완전 제거 불가.
  - (vii) POD 기저는 253케이스가 덮은 기하 범위 안에서만 유효 — 범위 밖 기하는 외삽.
  - (viii) 발산-0은 보장되나 벽면 no-slip·상면 rigid-lid는 재구성에서 근사(표 9로 보고).
- **§5.4 일반화.** v2 유지.
