### 1.1 ⛔ 게이트 불합격의 처리 — 최상위

**사실.** 대조군(Su 2.86) vs `case_su168`(Su 1.684), coarse 84×37×37 동일 격자·동일 플룸(x=0.13):

| | 대조군 | 시험 | 판정 |
|---|---|---|---|
| 플룸 $W$ | 0.3752 | **0.2869** | 예측 0.3145 대비 **−8.8 %** ❌ (허용 ±3 %) |
| $Q_p$ | 7.90 L/min | 6.04 | |
| mean\|U\| | 0.03617 | 0.02781 | |
| 정체분율 | 6.16 % | **10.66 %** | +73 % |
| 정규화마스크 IoU | — | **0.597** | ❌ (기준 0.80) |
| 정규화 centroid 이동 | — | 0.94 셀 | 기준 1셀 이내이나 IoU 실패 |

**① $W\propto\mathrm{Su}^{1/3}$ 이 깨졌다.** 실측 2점으로 역산한 지수는

$$n=\frac{\ln(0.2869/0.3752)}{\ln(1.684/2.86)}=\mathbf{0.507}$$

**1/3이 아니라 1/2**이다. MTT 부력플룸 상사가 아니라 운동량 지배 컬럼 쪽 거동. 이 지수가 `EX2/어항실험/alpha_g_보정절차.md` 고정점 반복의 **유일한 자유 가정**이었으므로 그것으로 얻은 $\alpha_g$ 계열 값이 전부 무효다.

**새 고정점 (n=0.507 기준):**

$$\alpha_g=0.1807,\qquad \mathrm{Su}=1.773,\qquad W=0.2945\ \mathrm{m/s},\qquad a=2169\ \mathrm{/m}$$

**② 전달측 영향은 작다.** $K_La$ 는 3.13 → **3.29 /h**(+5 %). $a$ 상승과 $W$ 하강이 상쇄. $\tau$ = **18.2분**, 95 % 도달 **55분**. → **7/29 실측 예측치는 그대로 사용 가능.**

**③ 부력측 영향은 크다.** 정체역이 이동하므로 Su=2.86에서 만든 유동장은 새 운전점을 대표하지 못한다.

**결정해야 할 것:**

- [ ] **Su=1.773 확인런** (41분) — 지수를 1.684 런으로 적합했으므로 자기참조가 남아 있다. 한 번 더 돌리면 수렴 확인 + 지수 검증이 동시에 된다. **권장**
- [ ] **EX2 16위치 재실행 여부** — coarse 기준 16×41분 ≈ **10.9 h**(하룻밤). medium 앵커 3점(pos1/7/13) 추가 시 +6.7 h

## 2. 방법이 정의되지 않은 것

### 2.1 ⛔ 불확실도 전파 — 논문 최종 출력물의 생성 방법 (초록 A11 · §3.3 E4)

**문제.** 논문은 출력을 $P_\text{hypoxia}(\mathbf x)=\Pr[\overline C(\mathbf x)<C_\text{crit}]$ 로 쓴다. 그런데 CFD를 한 번 풀면 $\overline C(\mathbf x)$ 는 **숫자 하나**다. 확률이 아니라 0 아니면 1이 나온다.

확률이 되려면 $\overline C$ 가 **분포**여야 하고, 그 분포는 입력 불확실성에서 온다: $\kappa$ 잔차 · 생물 계수 밴드([R46]) · $Sc_t$ 밴드 · $\alpha_g$ · $d_b$. **입력 분포 → 출력 분포로 옮기는 절차가 "전파"** 이고 논문·설계문서 어디에도 없다.

| 방법 | 내용 | 비용 | 가정 |
|---|---|---|---|
| **(a) 몬테카를로** | 입력을 $N$회 샘플링해 B층을 $N$번 푼다 | B층이 선형·경량이라 $N$=수백도 쌈 | 적음. **권장** |
| (b) 선형화(delta method) | $\partial\overline C/\partial\theta$ 로 분산 전파 | 1회 풀이 | 국소 선형 |

- [ ] 방법 선택
- [ ] 입력 분포 정의(각 계수의 분포 형태·폭)
- [ ] $C_\text{crit}$ 자체의 불확실성 포함 여부([R29]는 범위로 줌)

### 2.2 §4.2 사진→BC 평가 설계 (G5·G6)

- [ ] **참값(ground truth) 생성 절차** — 실제 어항 사진의 참 기하·차단율을 무엇으로 정하는가. 실측? 수동 라벨링? 특히 차단율은 실측 자체가 어렵다. (SW팀 자료 대기)
- [ ] **표본 수** — 사진 몇 장. 미정이면 §4.2는 측정 가능한 절이 아니다
- [ ] "위험 미탐지"(구 false-safe) 판정 기준 — 무엇을 미탐으로 세는가

### 2.3 §5.1 ablation 설계 (H1)

- [ ] 무엇을 제거하고 무엇과 비교하는가. 층 경계(사진→BC / A층 / B층)가 코드·문서 어디에 대응하는지 먼저 명시

## 4. 미수행 검증

### 4.1 평균장 근사 게이트 (§3.5 F7) — **EX2_X2**

논문 §3.5(iv)가 "평균장 근사 게이트(비정상 공동풀이 vs 평균장 정상풀이의 위치 일치)"를 검증 항목으로 적어놨다. 이것이 **§3.1의 "$\overline{\mathbf U}$ 로 얼려도 된다"를 정당화하는 유일한 검증**이다.

검토 회신: "simpleFoam이랑 pimpleFoam 직접 비교, 200 s 중 40 s부터 St 감소 확인, 160 s 시간평균 후 정량비교한 적 있음."

**EX2 문서 전체를 검색했으나 해당 기록을 찾지 못했다.** 있는 것은 `EX2/CFD/docs/CFD_방법론.md` L89·L96뿐인데 내용이 다르다 — Strouhal은 "`fieldAverage`의 `timeStart` 채택 시점 판정"과 "CFD **내부 수렴·정상성 진단용**"으로만 쓰인다고 명시. 즉 **timeStart=40을 고르는 근거**이지 평균장 근사의 타당성 검증이 아니다. EX1은 simpleFoam을 썼으나 기하가 다르고 $\alpha_g$=0.02 placeholder라 비교 대상이 못 된다.

목적("사용자 조건에서 발생하는 위험 조기탐지")상 **문헌값으로 시뮬레이션해 DO 구배가 실제로 발생함을 보이는 것**이 필요하다는 데 합의됨([R46] 확보).

- [ ] **범위:** 단일 케이스 데모보다 **사육밀도 × 폭기(또는 수위) 조건 스윕**이 훨씬 강하다 — "어떤 조건에서 위험이 발생하는가"의 조건 경계가 곧 기여가 된다. B층이 선형이라 거의 공짜

### 5.4 공간정확도 주장의 범위 (H4)

검토 회신: "공간분포를 미리 시뮬레이션한 테스트 데이터셋으로 정량비교하면 공간분포 추정이라고 쓸 수 있겠지"

**부분적으로만 성립한다.** CFD로 만든 테스트셋과의 비교가 보이는 것은 "**ROM이 CFD를 재현한다**"이고, "**CFD가 현실의 공간분포를 재현한다**"는 나오지 않는다. 후자는 실측 공간 데이터가 필요한데 EX2가 그것을 폐기했다(공간매핑 → 재폭기 단독).

- [ ] 주장 가능한 문장은 "**ROM이 CFD 공간장을 O(mm) 오차로 대리한다**"까지. §5.3(ii)의 정직한 한계는 유지할지 결정
